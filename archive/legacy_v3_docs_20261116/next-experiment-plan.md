# TSG 与因果推断联合研究：下一轮实验设计

日期：2026-09-27。状态：`SPECIFIED_DEVELOPMENT`。本文件是下一轮有界开发实验的当前规划；任务身份、程序测量和执行配置尚待按本文要求形成执行输入。正式规范仍为 [protocol.md](protocol.md) 的 `SPECIFIED_DRAFT`。实验登记分别记录 specified、implemented、tested、executed、reported 状态。

## 1. 研究对象与贡献

TSG 与因果推断共同构成方法核心。TSG 表达源任务中的对象、操作、条件、量化范围、生命周期、非目标行为和来源依据；因果推断利用随机干预结果，评价候选政策并形成可检验的选择规则。干预编辑执行被选政策，程序测量提供安全与功能结果。

本轮评价以下三个研究问题：

1. **假设产生：**源任务驱动的 TSG 关系分析，能否产生语义正确、内容有区别、可实施且可测量的 Atomic 假设？
2. **因果选择：**利用开发任务的随机干预证据，能否在留出任务上获得超过源语义排序、总体效果排序及固定政策规则的收益？
3. **编辑实现：**根据任务关系生成的编辑能否保持要求的完整范围及非目标行为，其效果对表达方式具有怎样的敏感性？

验收同时覆盖候选质量、政策选择及代码结果。统计显著性与正向收益均作为待观察结果。运行记录须支持有效、无效、有害、支持不足及测量受限的分别判定。

## 2. 七个阶段与实际信息传递

| 阶段 | 输入 | 处理 | 输出 |
|---|---|---|---|
| representation | 原始完整任务、独立安全原则材料 | 构建 TSG，记录关系及依据；形成任务内与跨任务语义 | 任务 TSG、源状态及不确定性 |
| prioritization | 源语义、候选、开发干预结果 | 产生候选；在规定的开发角色中拟合并比较选择规则 | 候选集合、因果评分及选择器 |
| hypothesis freeze | 开发结果、固定选择规则、留出任务的源信息 | 固定具体政策、估计对象、编辑分布、候选槽位及统计规则 | 完整假设记录和执行输入 |
| intervention/randomization | 绑定后的单项政策、完整编辑及控制 | 预定分配处理、表达版本和生成种子 | 实际发送文本与全部分配记录 |
| measurement | 原始代码、源合同绑定、事前测量规则 | 使用对处理标签不可见的程序测量 | 安全、功能、联合成功、有效性及 unknown |
| outcome assembly | 全部分配和测量记录 | 保持任务、候选、表达版本、重复之间的对应关系 | 任务级结果与失败分类 |
| inference/reporting | 冻结的选择结果及任务级结果 | 估计固定研究总体内的效果与不确定性 | 比较结果、适用边界与可复算案例 |

生成代码只提供测量结果。TSG 关系解释为任务语义。因果分析变量来自生成前确定的任务与政策记录。

## 3. 从源任务产生假设

### 3.1 输入与生成范围

安全知识输入采用有来源依据的原则目录，登记每项原则的完整内容、适用边界和依据。目录提供安全性质，具体任务假设由源任务中的操作、对象及约束共同确定。目录内容、来源获取规则及候选生成指令均在本轮代码结果出现前固定。

每个基础任务具有两个候选输出槽位。候选生成程序允许输出空缺、冲突和 unresolved；每个槽位均保留原始状态。候选覆盖多个政策家族及不同任务关系，数量按语义身份统计。变量重命名和同义表达共用同一个语义身份。

每个候选必须给出：

- 一项完整性质及 ADD 或 REMOVE 操作；
- 直接约束的对象和操作、条件、量化范围及时间边界；
- 逐项来源依据与安全原则依据；
- 原文表达状态、兼容性、需要保留的行为；
- 哪些 TSG 关系支持这个绑定，以及哪些关系仍然 unresolved；
- 主要结果、预计可能发生的功能代价及程序测量范围。

ADD 以完整原文中未表达且兼容的要求为对象。REMOVE 以明确存在的源要求为对象，编辑保持其他源行为。每次生成只接受一个完整要求。各候选独立执行，不组合不同安全目标。

### 3.2 TSG 关系的实际使用

候选生成必须调用源关系查询，并保存查询依据：对象参与的操作、要求所属对象、条件约束范围、操作顺序、要求量化边界及对象生命周期。跨任务属性由这些关系及源事实计算，保留定义与任务实例之间的映射。

跨任务属性词汇在开发任务上定义并冻结；留出任务使用相同定义，未知状态单独保留。目标对象数量、调用模板数量、参数角色数量分别记录。算法输入中移除任务名称、文件名和实例 ID 等身份记忆字段。

关系使用的验证包括：同类词汇在不同对象关系中的绑定是否不同；条件约束是否只作用于源指认的操作；多个对象之间的公共与私密角色是否保持；删除后仍须保留的要求是否完整。关系检查覆盖存在的真实任务以及单独标识的受控机制材料。

## 4. Raw 与 TSG 的评价设计

采用基础任务级的表示流程随机分配。分配前仅使用来源元数据进行分层；同一任务全文只进入被分配的准备流程。Raw 准备直接使用完整原文与共同安全原则，TSG 准备使用完整原文、相同原则及显式关系查询。两种流程具有相同的候选槽位和准备预算，记录实际准备成本。每个任务产生自己的候选与编辑。

此设计估计作者辅助准备流程的平均效果。开发与留出任务按来源谱系和去重任务组隔离，表示流程在各角色内平衡分配。Codex 的作者身份和共用知识完整披露。自动抽取准确率需要独立参考评价，当前作者准备身份单独报告。

Raw 基线输出执行所必需的政策性质、目标、条件和非目标行为。其因果输入来自原文与候选描述的词语 unigram/bigram TF-IDF，采用 sklearn 的 TfidfVectorizer，最多保留 128 个特征，使用 sublinear_tf。TSG 因果输入来自源关系及相同政策元数据，以标准 OneHotEncoder 编码类别并保留 unknown。政策的原则身份、ADD/REMOVE 和表达身份作为两种流程的共同元数据。特征词汇与标准化参数仅从开发材料获得；表示流程效果包含各自特征形成过程。报告实际维度、支持量与准备成本。

等信息 Rich-Flat 用于表示转换的一致性检查。关系消融在共享源记录上执行，只删去被预定研究的关系，并保持实体、属性和来源记录；无法绑定的结果保留。关系消融产生的差异按信息使用诊断报告。候选生成使用完整任务全文时，关系可能从原文重新获得，此情形必须在解释中明确。

源语义质量检查覆盖全部留出候选。检查者的身份和可见信息写入记录；独立性不足的检查标记为作者自查。程序验证检查结构与引用，语义正确性单独评价。

## 5. 干预编辑与表达多样性

每个有效候选由绑定记录生成三份完整表达。表达可以采用自然段、对象与操作组织、时间与条件组织等适合源任务的形式；各文本由任务内容产生。三份表达共同保留相同的要求、目标、条件、范围、时间边界和非目标合同。评价记录逐项核查这些对应关系。

编辑位置依据源结构确定：ADD 可追加独立要求，或在对应任务段落中完整整合；REMOVE 删除或中性替换源要求。编辑位置、文本结构和具体文字均作为实际政策实现保存。局部整合须同时保存完整编辑前后文本与源要求对应关系。

每个表达具有四个完整处理：目标编辑 P、匹配控制 N、风格控制 S、方向兼容的一般安全提醒 G。控制根据该表达的编辑操作和源合同独立生成。每个处理的所有文本在相应代码生成前冻结。R 保存共同接口下的基础任务，用于评价政策选择相对于保持原提示的收益。

实现指引具有独立处理身份。本轮主要表达比较保持要求的实现自由；候选本身必须指定实现方式时，明确记录该限制并检验其来源与兼容性。

主要分配为每个任务、候选随机选择一个表达版本，并对其完整四个处理各生成两次。三种表达在源家族与研究角色内平衡。另有预定的十二个任务，各选择一个语义合格候选，在其余两个表达上执行相同四个处理及两次生成。任务与候选的选取只使用冻结身份及源资格，保持结果不可见。

报告分别给出语义正确率、目标完整覆盖、非目标改变、各表达的结果分布及任务内表达差异。三个表达共同定义本轮有限编辑分布；结果按预定权重汇总。

## 6. 因果估计与选择算法

### 6.1 估计对象

每项政策估计其完整冻结编辑分布下 P 相对 N 的任务级安全产出差；功能、联合成功、有效性和 unknown 单独计算。政策选择的合法动作包含 R，因此其决策评分另行估计 P 相对 R 的总产出差。两种差值使用各自的对照和解释。候选评分在开发任务上形成，留出任务的生成结果仅用于评价。

每个任务的候选以生成前的政策及 TSG 语义描述。跨任务预测输入可以包括要求类型、编辑方向、对象角色、操作、条件、生命周期和完整量化范围。任务结果和生成后合规情况禁止进入这些输入。

### 6.2 必须执行的共同数据比较

1. **源语义排序：**只使用来源支持、相关性、兼容性及可测量性，按预定规则选择候选。
2. **总体随机效应排序：**从开发数据估计政策家族与编辑方向的平均 P−R，采用相同候选和预算；P−N 独立用于目标要求的政策效果报告。
3. **条件效果选择：**使用开发任务内 P−R 配对差作为决策监督目标，拟合带正则化的任务／候选语义模型，预测留出候选收益；P−N 采用单独的估计输出。使用任务分组交叉验证；共享任务的候选和重复始终处于同一分组。
4. **源信息与结果关联排序：**在相同输入和训练预算下估计处理组的安全产出关联，检验随机干预差值是否提供额外选择价值。

条件效果模型采用标准库提供的 Ridge 实现；正则化参数候选为 0.1、1、10、100，通过开发任务分组交叉验证的政策收益选择。并列时选择正则化更强的配置。所有连续特征的标准化、文本特征的词汇与维度均只使用开发材料拟合。该模型的定位为可审查的条件随机效应基线，算法假设和外推限制随结果报告。

各方法为每个任务从两个候选及 R 动作中选择一个。因果排序采用 P−R 预测收益大于零时编辑，恰好为零选择 R；候选并列时依次使用源语义排名和稳定候选 ID。关联排序比较同一模型对候选处理与 R 的产出预测。源语义排序选择排名最高的可实施候选。需要学习的政策家族与编辑方向至少具有四个独立开发任务支持，缺少支持时选择 R。训练支持不足、候选不可实施及缺失预测分别记录。论文用途的最小有意义效果与任务级精度分析在新结果前登记，独立于这一选择规则。

### 6.3 FCI、GFCI 与 JCI 的位置

结构算法须指定实际查询、已知设计约束、输出中的被识别关系及其改变的动作。可以研究观察性候选优先化或跨环境证据合并，但每个查询必须与强直接基线使用相同合法信息。给定设计已经确定的关系作为背景约束记录。

本轮结构比较的执行前条件包括：总体分布层面的可识别性说明、正反机制、合法变量定义、PAG 到动作的完整映射，以及效果或实验成本上的评分。缺少完整定义的查询保留为未满足条件；本轮的随机因果估计与政策选择仍有完整评价。

模拟以独立数据生成重复为单位，真实代码以去重基础任务为单位。结构方法采用每任务预定一条观测进行需要独立样本的图搜索，并明确记录其与完整重复结果估计之间的数据利用差异。模拟真值与真实代码结果分别报告。

## 7. 来源、划分与数量

自然任务目标为九十六个独立、可解释、未受保护的外部来源任务，开发与留出各四十八个；每个角色内 Raw 与 TSG 各二十四个。身份、去重、来源谱系和既有暴露在读取新的任务结果前登记。所有既有结果暴露任务仅进入开发或测量控制。

来源准备采用一次有界、结果不可见的登记与获取，检查上限三百八十四个来源任务。来源范围、外部来源配额、哈希顺序及检查上限在读取所选任务全文前固定。获取规则使用预定来源及操作领域元数据。任何 FCI/RD 分数、候选排名、生成结果或 TSG 关系支持均不得参与获取。

自然覆盖目标包括至少三个语义不同的政策家族和至少四个独立操作家族。此目标评价研究覆盖情况，实际覆盖及缺失分别报告。人工任务独立保存为机制与测量材料。任务数量、政策家族数量和语义有效候选数量使用真实登记数，剩余空缺保持可见。

任务不足、测量范围不足和独立家族不足具有各自的未满足状态。执行资源冻结必须依据实际可用任务表。精度计算使用任务级独立单位与预定主要比较；达不到用途所需精度时，报告相应推断限制。

## 8. 程序测量与因果边界

每个候选具有从源合同、目标要求到程序观察的对应表。表内分别写明私密／公共对象、允许内容、初始状态、保留与销毁规则、操作时间范围，以及可观察的非目标行为。源原文未规定的事项保留 unspecified；共同实验约定明确标识为研究适配。

正例、负例和 unknown 控制覆盖实际输入所允许的代码形式。文件研究需覆盖短暂公共写入、合法暂存后删除、已有文件更新以及必要的分段写入；命令研究需区分目标调用、辅助调用、参数边界和原任务允许的解释语义。测量规则在候选结果可见前冻结。

程序测量对处理和选择方法标签不可见。执行失败、语法错误、unsupported 与被证实不安全分别保留；全部分配进入任务级结果组装。基础设施缺失会使对应估计不可计算，记录缺失原因。需要修订观察器时使用新研究配置，冻结证据维持其原输入及解释。

## 9. 主要比较与统计设计

代码结果的主要比较为：

1. 留出任务上，TSG 与 Raw 准备流程的固定选择器安全产出差；
2. 留出任务上，条件因果选择相对总体随机效应排序的安全产出差；
3. 留出任务上，条件因果选择相对源语义排序的安全产出差。

第一项使用基础任务级的分层流程随机分配，按实际分配概率估计。第二、三项使用同一留出任务的共享生成面板，按冻结策略选择相应记录并作任务内配对比较。每个角色与来源家族的权重在结果前固定。所有输出先平均任务内部重复，再按任务权重汇总。

报告有限留出面板上的条件于已训练选择器的结果。训练不确定性另行通过完整重训的分组重采样诊断，单独说明计算范围。语义与编辑正确性、P−N、表达敏感性、功能和联合成功为预定次要输出；其用途与多重性家族事前登记。

主要三项使用固定家族大小 3、家族水平 0.05 的 Bonferroni 探索区间，各项报告 98.3333% 区间。采用 5000 次留出任务分层重采样，种子 20260927，条件于已训练选择器；每个基础任务的全部候选、处理与表达随该任务共同抽取。第一项保留表示流程分配与来源层，第二、三项保持同任务内的策略配对。使用百分位区间并报告分层独立任务数、退化分布及其近似覆盖限制。单任务层不产生可报告总体区间。方法效应的方向与区间同时报告，宽区间保留为未确定。模拟比较具有独立统计家族。context 修饰推断保持未激活，直到精确任务与条件、比较公式及联合规则完整冻结。

候选空缺、无法编辑和 unresolved 计入固定候选槽位的产出报告。选择算法因源资格采用 R 的任务仍保留在方法结果分母。生成后合规、测量可用或功能通过均不作为分母过滤条件。

## 10. 资源与执行边界

按九十六个基础任务、每任务两个候选、一个被分配表达、四个处理、两次生成计算，主面板上限为 1536 次代码生成；R 每任务两次共 192 次；十二个任务的两个额外表达共 192 次。已暴露开发材料的吞吐与请求验证上限为 16 次。合计 1936 次，绝对请求上限为 2048 次。

语义不合格候选保留空缺记录；多余配额保持未分配。运行错误不触发候选替换或表达择优。服务资源以实际吞吐核算，单次研究墙钟上限为二十四小时，A800 服务上限为十八小时。执行配置记录开始时间、停止新增请求时间、测量预算及独立复算时间。实际吞吐不满足完整分配时，资源状态标记为不足。

Codex 准备源语义、TSG、候选、绑定、编辑和程序测量；vLLM 本地模型只生成代码。服务器文件限于 `/home/wsy/work/prompt-mechanism-study`。现有模块承担研究逻辑与调用，复用公共文件操作及独立验证入口。

| 研究输出 | 验收所需证据 |
|---|---|
| 候选确实由源任务产生 | 所有任务的原文、候选生成输入与输出、原则依据、关系依据、空缺和语义身份；报告政策家族与关系覆盖 |
| TSG 关系确实参与计算 | 每个候选的查询与绑定记录、被使用的关系、关系消融结果及无法绑定的位置 |
| 干预具有完整语义与表达覆盖 | 每个候选的三份表达、完整四处理文本、逐项语义检查及实际分配 |
| 因果选择使用独立证据 | 开发与留出隔离、训练与选择配置、结果出现前保存的逐任务选择、强基线的共同数据比较 |
| 测量支持宣称的性质 | 源合同到观察规则的对应关系、事前控制、全部原始事件、unknown 和错误分类 |
| 研究结论可以核查 | 主要比较、全部次要结果、候选与表达失败、自然覆盖、实际资源以及独立数值复算 |

每项分别判定完成、证据不足或执行失败。正向结果需要相应估计和不确定性支持；负向结果需要可排除的误差范围；宽区间保留为未确定。研究完成要求每项研究问题获得其规定的评价记录，未满足条件的项目明确列出。

## 12. 复用的实现位置

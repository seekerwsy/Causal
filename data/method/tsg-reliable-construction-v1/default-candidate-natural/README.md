## What actually ran

Eleven fresh Codex steps: two default proposals, two candidate reviews, two record
extractions, two ordinary record reviews, two scope assessments, and one paired
source-support review. No external API calls or charges; exact model snapshot and
seed are unavailable. No mechanical extraction repair or semantic patch was needed.
The second accepted factor (privilege elevation) remained a non-target invariant;
only the prospectively named lowering factor was edited.

The initial edit attempt failed. Its raw support response correctly labeled the
target requirement as policy-only, but the experimental adapter wrongly submitted
that already-owned requirement and its edge as supplemental operation/object
release declarations. It also supplied tuple-valued coordinates to the JSON-record
verifier. Those are adapter failures, not evidence of a wrong source judgment.

The original failure and implementation are retained in `analysis/replay-result.json`
and `execution-source.tar.gz`. A separate, zero-model-call replay then:

1. Removed only redundant `policy_only` declarations already handled by the target
   requirement edit, preserving every other judgment and the raw response; serialized
   scope coordinates as canonical JSON. Both paths then rejected different quotation
   lengths on unchanged non-target text.
2. Allowed different quotation lengths only when both full spans lie in one unchanged
   source-to-variant text block and their translated positions overlap. Both REMOVE
   and inverse ADD passed the editor and independently implemented verifier. Meanings,
   objects, graphs, source prompts, conditions and model judgments were not changed.

`edit-replay/original-implementation.json` and `repaired-implementation.json` retain
both outcomes. The follow-up plan and separate source archive distinguish the rule
change from fresh model evidence. The implementation still checks all non-target
semantic identities, relations, conditions and scope states. Text overlap alone
does not establish semantic entailment or unique reference in arbitrary repeated text.

# Bounded construction repeatability

Eight previously exposed natural source tasks, two fresh contexts per task. The
plan, source meanings, exact input requests and response schemas were written
before dispatch. They are fixed throughout this batch. The four transfer cases
are new to this construction revision, not protected or untouched evaluation.

Each constructor receives `protocol/constructor-instructions.txt` with its case
path and no conversation history. It sees only its inputs and frozen source
semantics, never the reference or another output. The inherited Codex model and
runtime are used; the exact provider snapshot and sampling seed are not exposed.
This cannot isolate an agent-workflow benefit from a model/runtime difference.

Run the frozen compiler once for each retained attempt:

```text
.venv/Scripts/python.exe data/method/tsg-reliable-construction-v1/agent-repeatability/validate.py CASE_DIRECTORY ATTEMPT_NUMBER
```

The validator extracts `execution-source.tar.gz`, checks its frozen identity, and
ignores changes to the current worktree. No attempt may be overwritten. At most
three attempts are allowed; construction stops at the first successful compile.
Compilation does not certify source meaning. An author source audit follows the
completed batch and separately checks actual conditions, targets, composition,
quantification, order, object roles, and unsupported additions.

The experiment uses Codex account usage and makes zero external-provider calls.
It does not perform candidate selection, interventions, code generation,
Discovery, Confirmation or paper updates. Even passing the bounded gate does not
prove general reliability; failed and unknown results remain in the report.

## Retained result

All 16 first retained drafts compiled without repair. The four post-output author
audits in `analysis` account for every frozen reference exactly once per run:
88/96 correct, four Pandoc predicate mismatches against the frozen reference, and
four unresolved privilege-target bindings. Twelve graphs pass the source audit.
The gate is not met. Pandoc's source relative clause is ambiguous; its four
mismatches are not independently certified source errors. Privilege order edges
are correct, but the recipients of the complete requirements remain unresolved.

`analysis/summary.json` is recounted by the parent `verify.py`, which also replays
all 16 exact drafts against the archived compiler. The [experiment report](../../../../docs/experiments/2026-09-17-tsg-reliable-construction.md)
explains the gate, correlated observations, runtime interruption, and unchanged
default method. Compiler replay and audit arithmetic passed; neither certifies
semantic correctness. No candidate or actual intervention ran in this batch.

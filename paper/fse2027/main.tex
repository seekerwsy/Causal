\title{Prioritizing and Evaluating Prompt-Side Security Interventions in LLM
Code Generation}

\author{Anonymous Author(s)}
\affiliation{%

  \country{}

\begin{abstract}
Natural-language programming prompts often specify functionality while leaving
context-specific security requirements implicit. We present \model, a
three-stage framework that maps each prompt into a typed Prompt TSG, discovers
and selects context-conditioned intervention hypotheses from observational
evidence, and evaluates frozen prompt interventions on cluster-disjoint
held-out tasks. The Prompt TSG separates immutable task-security context from
one editable safety factor and defines valid ADD or REMOVE operations.
TSG-derived constraints, FCI evidence, and support under semantic-cluster
resampling allocate a fixed evaluation budget without treating observational
relations as effect evidence. Matched target and control prompt policies then
undergo blocked randomization, and assigned-arm intent-to-treat analysis
estimates their effects on independently measured security and functionality.
For each hypothesis, \model assembles the represented context, frozen edit,
selection trace, effect estimate, uncertainty, and claim scope into an
intervention evidence record for expert evaluation.
\end{abstract}

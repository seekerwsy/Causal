\section{Introduction}

Developers using large language models for code generation face a concrete
prompt-level security decision: which requirements should be made explicit,
where within a multi-operation task do those requirements apply, and what causal
evidence justifies modifying the prompt? Insecure patterns are widespread in
generated code~\cite{pearce2022copilot,perry2023assistants}, and security
prompting or iterative prompt optimization can shift model
behavior~\cite{tony2025prompting,nazzal2024promsec}. Yet turning prompt
adjustments into trustworthy engineering guidance poses two foundational
methodological challenges.

The first challenge is \textbf{compositional scope ambiguity in multi-operation
prompts}. Natural programming tasks frequently combine several operations that
share data objects, nested attribute components, and logical execution
conditions~\cite{cicalese2026language}. A requirement to parameterize an SQL
value must specify which operation and input object it governs while leaving
sibling uses of the same object—such as file-path construction or return
formatting—unchanged. Flat requirement checklists or ungrounded concept tags
collapse these operation-level distinctions, and coupling semantic extraction
to brittle patch-syntax contracts causes syntax rejections to obscure true
requirement-binding effects. Structured task representation must therefore tie
normative propositions to exact operations, object-component ownership paths,
and logical guards while preserving local unresolved facts without discarding
valid bindings.

The second challenge is \textbf{confounded structural attributes under limited
target budgets}. Even when prompt semantics are precisely bound, observing
higher security in natural prompts that contain a requirement does not identify
the effect of explicitly editing that requirement~\cite{ji2025causality,velasco2026smells}.
Furthermore, target randomized budgets for any single atomic policy are small,
while prompt-derived structural attributes extracted from task graphs are
highly collinear and include latent-confounded proxy chains. Conditioning
directly on naive correlations or undirected adjacency risks overfitting noisy
source attributes or suffering negative transfer when downstream and upstream
mechanisms shift across populations. Causal structure discovery must
distinguish genuine context-anchored causal roles from latent proxies while
retaining strict finite-sample unbiasedness under target randomization.

We introduce \model, a two-stage framework for task-grounded requirement
representation and causal prompt guidance. In \textbf{Stage~I (Task-Grounded
Graph Representation)}, \prompttsg binds normative requirements, operations,
data-object ownership chains, and logical conditions to character-verified
evidence spans, decouples semantic representation from deterministic code
splicing, and extracts pre-assignment relational attributes $Z=q(G_P,r)$. In
\textbf{Stage~II (Context-Anchored Directional JCI and Cross-Fitted Effect
Learning)}, \model uses Joint Causal Inference~\cite{mooij2020jci} with
exogenous preparation contexts $C$ to discover a Partial Ancestral Graph (PAG)
over $(C,Z)$, decomposes attributes into canonical directional roles
$(V_{\rm root},V_{\rm up},V_{\rm term},V_{\rm other})$ to guide role-grouped
finite shrinkage with an unweighted fallback, and estimates target average
intervention effects via task-unit $K$-fold cross-fitted randomized residual
scoring paired with scoped evidence reporting.

Our methodological contributions are twofold:
\begin{enumerate}
  \item \textbf{Task-Grounded Graph Representation (\prompttsg).} We formalize
  scoped semantic graphs that resolve multi-operation object participation,
  preserve local \texttt{unresolved} boundaries, decouple prompt semantics from
  code-edit syntax, and project graph-topological attributes cleanly into
  pre-assignment statistical covariates.
  \item \textbf{Context-Anchored Directional JCI and Cross-Fitted Effect
  Learning.} We introduce a directional PAG role-grouped shrinkage estimator
  that separates context entry targets ($V_{\rm root}$), upstream precursors
  ($V_{\rm up}$), confluence terminals ($V_{\rm term}$), and latent-confounded
  leaves ($V_{\rm other}$), coupled with task-unit $K$-fold cross-fitting that
  preserves exact finite-sample unbiasedness while mitigating negative transfer
  across both downstream and upstream regimes.
\end{enumerate}

The evaluation design in Section~\ref{sec:evaluation} isolates each
contribution across three research questions: \textbf{RQ1} measures the
representation and binding gains of \prompttsg over \textsc{Raw} and
\textsc{Flat} baselines; \textbf{RQ2} evaluates effect-estimation variance
reduction of directional cross-fitted JCI against unstructured learners and
undirected-skeleton ablations; and \textbf{RQ3} assesses end-to-end positive
security-hardening yield while keeping adverse warnings, functionality, and
Oracle coverage distinct.

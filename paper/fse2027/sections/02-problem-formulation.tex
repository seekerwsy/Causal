\section{Motivating Example and Problem Formulation}

\subsection{Multi-Operation Scope Disambiguation}

Consider a software module where two operations access fields of the same
shared input mapping---for example, storing an uploaded \texttt{filepath} in an
SQL table while rendering a download response from the same path
(Figure~\ref{fig:method-example}), or parameterizing a database query over
\texttt{payload['role']} alongside a sibling formatter returning verbatim string
\texttt{'Filter<' + str(payload['role']) + '>'}. Adding a security rule to reject
SQL punctuation or interpolate via parameter bindings governs only the database
operation and its input component; propagating input rejection across the module
breaks valid formatting on inputs such as \texttt{O'Brien}. Similarly, swapping
module-level \texttt{random} calls for \texttt{secrets} fixes token generation
while destroying determinism in a sibling seeded permutation helper unless the
prompt boundary exempts that sibling contract and static security auditing
scopes to the target operation's call closure.

\prompttsg records these operation and ownership boundaries explicitly before
prompt realization or code measurement. An intervention policy $\mathcal{M}$
pairs each discovered causal security mechanism with governed target
operations, nested \texttt{part\_of} object paths, execution conditions, and
explicitly exempted sibling contracts. Evaluating \model against both an
unguarded correlation-selected scoped baseline and a causally selected unscoped
flat baseline cleanly isolates Stage~II deconfounding from Stage~I scope
protection.

\subsection{Split Isolation, Endpoints, and Paired Counterfactual ITT}
\label{sec:matter-definition}

All causal structure learning and policy selection execute strictly on a
disjoint Discovery split $D_{\mathrm{disc}} = D_{\mathrm{obs}} \cup
D_{\mathrm{probe}}$, while counterfactual comparison evaluates solely on
independent, deduplicated task units in a Held-Out Evaluation split
$D_{\mathrm{eval}}$ satisfying $D_{\mathrm{disc}} \cap D_{\mathrm{eval}} =
\emptyset$.

On every committed task unit $i \in D_{\mathrm{eval}}$ and every assigned arm
$a \in \{\texttt{baseline}, \texttt{corr\_tsg}, \texttt{jci\_flat},
\texttt{jci\_tsg}\}$, stateless code generation yields matched counterfactual
observations retaining full assigned-arm intention-to-treat (ITT) denominators
(provider timeouts, extraction/splicing errors, and runtime failures score as
real zero yields rather than being dropped post hoc):
\begin{itemize}
  \item $Y_{C,i}(a) \in \{0,1\}$ (\emph{code validity}): deterministic AST
  parsing and symbol splicing succeed on a single extracted Python block.
  \item $Y_{E,i}(a) \in \{0,1\}$ (\emph{Oracle evaluability}): the
  target-operation-scoped AST security profile renders a supported binary
  verdict (\texttt{secure} or \texttt{insecure}); \texttt{unknown} cases retain
  $Y_E = 0$ and are reported explicitly without coercion into insecurity.
  \item $Y_{\mathrm{sec},i}(a) = Y_{C,i}(a) Y_{E,i}(a)\,\mathbb{I}\{\text{Oracle label is secure}\}$
  (\emph{security yield}).
  \item $Y_{\mathrm{func},i}(a) \in \{0,1\}$ (\emph{deterministic functionality}):
  an isolated subprocess unit-test harness (\texttt{python -I}) passes all
  target functional and sibling contract assertions without timing out.
  \item $Y_{\mathrm{joint},i}(a) = Y_{C,i}(a) Y_{E,i}(a)\,
  \mathbb{I}\{\text{secure}\}\,\mathbb{I}\{\text{func pass}\}$ (\emph{confirmed
  joint success}, primary endpoint).
\end{itemize}
For any contrast $(a,b)$ on endpoint $Y$, within-task paired counterfactual
differences
\begin{equation}
  d_i^{(a,b)} = Y_i(a) - Y_i(b), \qquad i = 1,\dots,n_{\mathrm{eval}},
  \label{eq:paired-diff}
\end{equation}
cancel baseline task difficulty identically across matched prompts, enabling
sharp precision gains without model-assisted cross-fold shrinkage heuristics.

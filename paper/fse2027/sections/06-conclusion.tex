\section{Conclusion}

\model unifies task-grounded graph representation with context-anchored
directional causal learning to evaluate single-requirement prompt interventions
in LLM code generation. In Stage~I, \prompttsg resolves multi-operation
requirement scope, component ownership paths, and logical guards while
preserving local \texttt{unresolved} boundaries, decoupling semantic representation
from target-unit code splicing, and projecting graph-topological covariates
$Z = q(G_P, r)$. In Stage~II, JCI-12 Partial Ancestral Graph discovery over
exogenous contexts partitions attributes into directional entry, precursor,
confluence, and latent-confounded roles $(V_{\rm root},V_{\rm up},V_{\rm
term},V_{\rm other})$ to guide role-grouped shrinkage, while task-unit
$K$-fold cross-fitting with unweighted fallback ensures finite-sample
unbiasedness and mitigates negative transfer across shifted mechanisms.
Together with assigned-arm ITT accounting and scoped evidence reporting,
\model provides a principled, inspectable foundation for requirement-level
prompt security guidance.

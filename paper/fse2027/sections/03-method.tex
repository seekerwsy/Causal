\section{Method}
\label{sec:method}

Figure~\ref{fig:method-overview} summarizes the two-stage \model pipeline, and
Figure~\ref{fig:method-example} illustrates scoped binding on a multi-operation
shared-object task. Stage~I encodes source-grounded operation scope and renders
contract-preserving interventions, while Stage~II learns causal mechanisms with
temporal outcome sinks on $D_{\mathrm{disc}}$ and confirms policy effects via
matched within-task paired counterfactuals on disjoint $D_{\mathrm{eval}}$.

\subsection{Stage I: Tolerant Prompt TSG, Orthogonal Mechanisms, and Scoped Realization}
\label{sec:method-tsg}

\subsubsection{Source-Grounded Graph with Tolerant Span Degradation}
Given model-visible task text $P$ (instructions, API descriptions, and optional
legacy scaffold context), define the Task-Grounded Semantic Graph (\prompttsg)
\begin{equation}
  G_P = (V, E, \tau_V, \alpha, \epsilon),
  \qquad E \subseteq V \times \mathcal{R} \times V,
  \label{eq:source-graph}
\end{equation}
where typed nodes $\tau_V$ partition $V$ into task root (\texttt{task}),
callable operations (\texttt{task\_operation}), data objects and nested fields
(\texttt{data\_object}), execution guards (\texttt{condition}), and normative
requirement propositions ($V_{\mathrm{prop}}$)~\cite{banarescu2013amr}. Typed
semantic edges $\mathcal{R}$ link data objects to consumer operations
(\texttt{used\_by}), trace nested component ownership hierarchies
(\texttt{part\_of}, e.g., \texttt{payload\_role} $\xrightarrow{\texttt{part\_of}}$
\texttt{payload}), attach propositions to governed operations
(\texttt{about\_operation}), and bind guard conditions (\texttt{conditions}).
\prompttsg edges record static source scope and never denote causal edges.

To avoid brittle parser failures on natural prompts, compilation matches
evidence spans deterministically first by exact substring lookup and then, when
tolerant recovery is enabled, by whitespace-normalized and stripped-backtick
alignment, rewriting anchored spans to exact character coordinates of $P$.
Any fact or proposition whose evidence cannot be anchored degrades locally into
dedicated \texttt{unresolved\_semantics} and \texttt{unresolved\_relations} sets
rather than invalidating verified operation bindings elsewhere in $G_P$.

\subsubsection{Orthogonal Structural Mechanism Vector and Stability Gate}
For proposition $r \in V_{\mathrm{prop}}$ and governed operation $o$, querying
$G_P$ traverses \texttt{about\_operation} and \texttt{part\_of} chains to
extract an eight-predicate orthogonal binary vector
\begin{equation}
  Z = q(G_P, r) \in \{0,1\}^8,
  \label{eq:attribute-query}
\end{equation}
encoding non-redundant topological properties: (1)~untrusted input reaching a
sink, (2)~shared-object participation across multiple operations, (3)~nested
\texttt{part\_of} component ownership chains, (4)~missing containment or
allowlist guards, (5)~sibling format or deterministic return contracts,
(6)~unscoped global restrictions, (7)~ambiguous or locally unresolved scope, and
(8)~explicit exception or fallback branches. Prior to Stage~II, binary
extraction stability is audited outcome-blindly against calibration
perturbations using a strict gate ($\text{median flip rate} \le 0.05$).

\subsubsection{Scope-Bounded Interventions, AST Splicing, and Target-Scoped Oracles}
For any selected mechanism set $\mathcal{M}$, \texttt{render\_prompt\_intervention}
constructs matched prompt realizations sharing base prompt $P$:
\begin{itemize}
  \item \textbf{\texttt{baseline}:} unchanged source prompt $P$.
  \item \textbf{\texttt{flat} ($\operatorname{Do}_{\mathrm{flat}}$):} appends
  each mechanism rule globally (``\emph{Apply uniformly across the entire module}'')
  without resolving governed operations, ownership chains, or sibling exemptions.
  \item \textbf{\texttt{tsg\_scoped} ($\operatorname{Do}_{\mathrm{TSG}}$):}
  resolves each mechanism $m \in \mathcal{M}$ through $G_P$ to its target
  \texttt{task\_operation} and \texttt{part\_of} ownership path while explicitly
  enumerating all sibling operations and instructing the generator to implement
  their base task contracts without propagating the target-only security
  restriction.
\end{itemize}
Generated responses are extracted deterministically at single-fenced Python code
boundaries (rejecting diff arrays or multi-block ambiguity) and spliced by AST
symbol when a target symbol is declared. Crucially, to avoid false positives on
legitimate sibling behavior (such as seeded deterministic permutation helpers in
CWE-338 modules), AST static security evaluation restricts sink inspection to
the declared \texttt{target\_function} plus intra-module helper call and load
closures, while deterministic functional testing runs the full module inside an
isolated subprocess (\texttt{python -I}).

\subsection{Stage II: Temporal-Sink JCI Discovery and Paired Counterfactual Evaluation}
\label{sec:method-causal}

\subsubsection{Discovery Split PAG with Exogenous Contexts and Temporal Sinks}
On the disjoint Discovery split $D_{\mathrm{disc}} = D_{\mathrm{obs}} \cup
D_{\mathrm{probe}}$, observations record exogenous preparation environments and
randomized probe interventions
$C = (C_{\mathrm{env}}, I_1,\dots,I_K,I_{\mathrm{flat}})$ alongside structural
mechanisms $Z$ and independently measured post-generation outcome sinks
$S = (Y_{\mathrm{sec}}, Y_{\mathrm{func}})$~\cite{mooij2020jci,peng2025cweval,dai2026rethinking}.
Raw generated code ASTs never enter any causal graph; only outcome indicators
enter strictly on $D_{\mathrm{disc}}$ as post-generation temporal sinks.

Under JCI-12 assumptions paired with temporal sink orientation, anytime
majority-rule FCI~\cite{spirtes1995fci,zhang2008ancestral} with Zhang's
orientation rules enforces three structural constraints inside
\texttt{discover\_jci\_pag}: (i)~exogenous roots $c \in C$ emit outgoing tails
($c \to u$, zero arrowheads into $C$); (ii)~post-generation sinks $s \in S$
accept only incoming arrowheads ($u \ast\!\!-\!\!\!> s$, forbidding
sink-to-pre-generation tails $\widehat{H}[u,s]=3$); and (iii)~conditioning sets
separating any two pre-generation variables never include post-generation
collider sinks $s \in S$. A structural validity guard rejects any $\widehat{H}$
violating acyclicity of its definite directed subgraph or context/sink
orientation invariants.

\subsubsection{Mechanism Classification and Policy Derivation}
Evaluating both observational associations on $D_{\mathrm{obs}}$ and clean
single-probe shifts alongside PAG adjacency yields an explicit four-way
classification for each mechanism $Z_m$:
\begin{itemize}
  \item \textbf{Causal security driver:} definite directed path
  $Z_m \to^+ Y_{\mathrm{sec}}$ in $\widehat{H}$ (e.g., via $I_m \to Z_m \to
  Y_{\mathrm{sec}}$ when $I_m \perp Y_{\mathrm{sec}} \mid Z_m$) and positive
  interventional shift $\Delta_{\mathrm{sec}}(I_m) > 0$.
  \item \textbf{Latent-confounded proxy:} bidirected collider edge
  $Z_k \leftrightarrow Y_{\mathrm{sec}}$ arising from $I_k \to Z_k \leftarrow U
  \to Y_{\mathrm{sec}}$ with zero interventional probe effect ($I_k \perp Y_{\mathrm{sec}}$).
  \item \textbf{Environment-confounded proxy:} observational association on
  $D_{\mathrm{obs}}$ that vanishes given $C_{\mathrm{env}}$ with no directed path
  to $Y_{\mathrm{sec}}$.
  \item \textbf{Scope-bleed hazard:} directed negative path or significant
  functional drop from $I_{\mathrm{flat}}$ or shared-object bleed $Z_{\mathrm{bleed}}$
  onto $Y_{\mathrm{func}}$.
\end{itemize}
\model's causal policy $\mathcal{M}_{\mathrm{JCI}}$ retains only confirmed
causal security drivers---abstaining completely (empty mechanism set) when all
candidates are proxies or inactive---and recommends \texttt{tsg\_scoped}
rendering whenever multi-operation scope bleed is detected. By contrast, a
correlation baseline $\mathcal{M}_{\mathrm{corr}}$ selects top observational
associates on $D_{\mathrm{obs}}$ using an equal mechanism budget.

\subsubsection{Within-Task Paired Counterfactual ITT and Independent Verification}
On the strictly held-out split $D_{\mathrm{eval}}$ ($D_{\mathrm{disc}} \cap
D_{\mathrm{eval}} = \emptyset$), every task $i \in D_{\mathrm{eval}}$ is
evaluated across all four arms (\texttt{baseline}, \texttt{corr\_tsg},
\texttt{jci\_flat}, \texttt{jci\_tsg}) over full ITT denominators. Because all
arms share the same task $i$, the paired estimator $\hat{\Delta}^{(a,b)} =
\frac{1}{n}\sum_{i=1}^n d_i^{(a,b)}$ eliminates shared baseline variance:
\begin{equation}
  \operatorname{SE}_{\mathrm{paired}}^2(\hat{\Delta})
  = \frac{\operatorname{Var}(Y(a)) + \operatorname{Var}(Y(b))
    - 2\operatorname{Cov}(Y(a), Y(b))}{n}
  < \operatorname{SE}_{\mathrm{unpaired}}^2,
  \label{eq:paired-se}
\end{equation}
achieving positive pairing variance reduction whenever baseline task outcomes
correlate across counterfactual arms~\cite{egami2022texts}. We report both
unadjusted 95\% Student-$t$ intervals and Bonferroni-simultaneous intervals
across the three primary joint contrasts (\texttt{jci\_tsg} versus
\texttt{baseline}, \texttt{corr\_tsg}, and \texttt{jci\_flat}) against
practical margin $m_h = 0.05$, exact two-sided binomial sign-test $p$-values,
and endpoint-separated rates ($Y_C, Y_E, \texttt{unknown}, Y_{\mathrm{sec}},
Y_{\mathrm{func}}, Y_{\mathrm{joint}}$). Every saved bundle is audited by an
independent \texttt{study verify} module that replays PRNG streams, permutation CI
queries, PAG construction, mechanism classifications, \prompttsg compilations,
AST splices, AST security profiles, isolated unit tests, and paired statistics
without sharing production discovery or experiment code.

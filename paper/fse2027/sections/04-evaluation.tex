\subsection{Evaluation Overview}

Our evaluation isolates both contributions of \model---multi-operation scope
protection (\prompttsg) and causal mechanism deconfounding with paired ITT
inference (Stage~II)---across three research questions:
\begin{itemize}
  \item \textbf{RQ1 (Scope Protection vs.\ Unscoped Bleed):} How effectively does
  \prompttsg preserve sibling functionality while enforcing causal security
  requirements compared with unscoped module-wide (\texttt{flat}) interventions?
  \item \textbf{RQ2 (Causal Deconfounding, Null Abstention \& Precision):} How
  accurately does temporal-sink JCI discovery reject environment- and
  latent-confounded proxies, abstain on spurious negative controls, and reduce
  unpaired variance via within-task pairing?
  \item \textbf{RQ3 (Per-CWE Endpoint Separation \& Prospective Expansion):} How
  do verified security, code validity, Oracle evaluability, and functionality
  decompose across CWE families on live LLM code generation, and what remains
  pending prospective multi-model confirmation?
\end{itemize}

All runs enforce strict $D_{\mathrm{disc}} \cap D_{\mathrm{eval}} = \emptyset$
isolation, retain complete four-arm assigned ITT denominators, audit extraction
stability outcome-blindly prior to Stage~II, and pass independent replay via
\texttt{study verify}. Consistent with governance boundaries, formative
multi-regime benchmarks and live 32B multi-operation evaluations are reported with
explicit \texttt{formal\_claim\_allowed = false} provenance, while unexecuted
prospective multi-generator and external repository confirmation cells remain
marked \pendingresult.

\subsection{RQ1: Multi-Operation Scope Protection (\prompttsg vs.\ Flat Bleed)}
\label{sec:rq1}

\textbf{RQ1.} \emph{When enforcing verified causal security mechanisms in
multi-operation modules sharing input objects or stdlib primitives, does
\prompttsg prevent functional scope bleed while preserving full security yield?}

We evaluate 24 legacy-maintenance Python tasks spanning six CWE families (4 tasks
each for \texttt{CWE-22}, \texttt{CWE-78}, \texttt{CWE-89}, \texttt{CWE-328},
\texttt{CWE-338}, and \texttt{CWE-502}) on \texttt{Qwen2.5-Coder-32B-Instruct}
($\text{temperature}=0.0$, 96 live generations, 0 provider errors). Every task
supplies a runnable two-function legacy module sharing a structured request
mapping or random-number primitive between a security-sensitive target operation
and a formatting or deterministic-seed sibling contract.

counterfactual contrasts (verified via \texttt{study verify}).

On Stage~I stability, \prompttsg achieves $0.0$ median flip rate across all
eight orthogonal predicates. On held-out tasks, both causal arms reach
\textbf{100\%} security yield (24/24). However, flat application
(\texttt{jci\_flat}) induces severe scope bleed on 21/24 tasks (raising
\texttt{ValueError} on valid sibling strings, hashing sibling prefixes, or
replacing deterministic \texttt{random.Random(seed)} with non-seeded CSPRNG
calls), collapsing functionality to \textbf{12.5\%} (3/24). Binding rules
through \prompttsg (\texttt{jci\_tsg}) protects sibling contracts and recovers
\textbf{91.7\%} (22/24) joint success ($\hat{\Delta}=+0.792$ over
\texttt{jci\_flat}, $19\text{W}/0\text{L}/5\text{T}$, Bonferroni lower bound
$+0.573 > m_h=0.05$). Target-function scoping of the AST security Oracle
itself also proved essential: during Gate~1 formative inspection (12 initial
tasks), module-wide CWE-338 scanning penalized safe \texttt{secrets.choice}
targets for retaining \texttt{random.sample} in the protected sibling helper,
confirming that security measurement and prompt intervention must share matched
operation boundaries. Remaining zero-yield events stay in the full ITT
denominator: \texttt{baseline} and \texttt{corr\_tsg} each incurred one f-string
syntax failure ($Y_C=0$ on \texttt{eval\_cwe78\_arg\_counter\_12}), while
\texttt{jci\_tsg} saw two functional failures despite valid security (leading
\texttt{/} rejection triggered on temporary test archive paths in one CWE-22
task, and omitting the \texttt{random} import header required by a preserved
CWE-338 sibling).

\subsection{RQ2: Causal Deconfounding, Null Abstention, and Pairing Precision}
\label{sec:rq2}

sinks suppress environment and latent confounding, abstain under purely
spurious regimes, and tighten confidence intervals through within-task pairing?}

four structural regimes (4 seeds $\times$ 3 repetitions = 12 cells/regime;
$n_{\mathrm{disc}}=480$, $n_{\mathrm{eval}}=120$ per cell, 4,538 CI queries).
Table~\ref{tab:rq2-jci-regimes} contrasts \model against correlation selection
(\texttt{corr\_tsg}) and unscoped causal application (\texttt{jci\_flat}).

Across all three active regimes, observational correlation is trapped on
\textbf{12/12} cells by latent or environment proxies ($Z_{\mathrm{lat}},
Z_{\mathrm{env}}$), whereas JCI achieves 0/12 false discoveries in
\texttt{pure\_latent\_trap} and \texttt{multi\_op\_high\_interference} (1/12 in
\texttt{confounded\_and\_scoped}) and yields $+0.127$ to $+0.147$ net joint gain
over \texttt{corr\_tsg} plus $+0.095$ to $+0.283$ over \texttt{jci\_flat} with
zero adverse harm cells. Critically, in the \texttt{null\_spurious\_only} negative
control, JCI abstains on \textbf{100\%} (12/12) of cells (0/12 false positives
versus 12/12 for correlation). Paired evaluation cuts equivalent unpaired
standard-error variance by \textbf{56.5\%--82.9\%}. On the live 32B cohort, JCI
similarly isolated causal driver $Z_{\mathrm{cau}}$ while rejecting proxy
$Z_{\mathrm{lat}}$, avoiding \texttt{corr\_tsg}'s 0/24 security yield
($\hat{\Delta}_{\mathrm{joint}} = +0.917$, $p=4.77\times 10^{-7}$).

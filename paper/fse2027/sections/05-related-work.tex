\section{Related Work}

\paragraph{Structured Prompt Semantics and Causal Code Analysis.}
Feature-attribution and concept-based methods relate neural predictions to
tokens or high-level concepts~\cite{sundararajan2017integrated,kim2018tcav,lundberg2017shap,deyoung2020eraser},
while CodeQ~\cite{khati2026codeq}, VulFaith~\cite{wang2026vulfaith}, and
NLPerturbator~\cite{chen2026nlperturbator} examine token rationales, reasoning
trace faithfulness, and prompt-perturbation robustness. Orthogonal causal
frameworks---including Palacio et al.~\cite{palacio2024causation},
Galeras~\cite{rodriguezcardenas2023benchmarking}, Ji et
al.~\cite{ji2025causality}, Velasco et al.~\cite{velasco2026smells}, and
CAM~\cite{lyu2026cam}---infer observational or agent-level causal relations.
By contrast, \model binds security mechanisms directly to multi-operation
\prompttsg ownership paths (\texttt{part\_of}) to prevent sibling scope bleed, injects
exogenous intervention probes alongside post-generation temporal outcome sinks
inside JCI-12 PAG discovery~\cite{mooij2020jci,zhang2008ancestral} strictly on
$D_{\mathrm{disc}}$, and evaluates policies on held-out tasks via matched
paired counterfactuals.

\paragraph{Hardening LLMs and Measuring Secure Code Generation.}
Prompt-based hardening and automated prompt optimization
studies~\cite{tony2025prompting,cicalese2026language,bruni2025promptbenchmark,nazzal2024promsec}
complement training-time or decoding-time interventions such as SafeCoder,
SecCoder, SVEN, CodeGuard+, and
Thea~\cite{he2024safecoder,zhang2024seccoder,he2023sven,fu2024codeguard,elhusseini2026thea}.
Executable security benchmarks including SecurityEval, LLMSecEval, CWEval,
and BaxBench~\cite{siddiq2022securityeval,tony2023llmseceval,peng2025cweval,vero2025baxbench}
underscore why security and functionality must be evaluated jointly~\cite{dai2026rethinking}.
\model extends this line with target-operation-scoped static security
profiles matched to \prompttsg targets, isolated unit-test functionality checks,
and complete assigned-arm paired ITT denominators verified end-to-end by an
independent replay verifier~\cite{miller2019explanation}.

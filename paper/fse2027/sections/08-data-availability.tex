\section{Data Availability}

All active source modules, benchmark manifests, JCI configurations, and
independent replay verifiers (\texttt{study verify}) will be released in an
anonymous replication package containing the disjoint $D_{\mathrm{disc}}$ /
$D_{\mathrm{eval}}$ splits, \prompttsg compilations, AST security traces,
isolated Python unit tests, paired statistical summaries, and cryptographic
SHA-256 digests reproducing every reported quantitative result without relying
on personal paths or external R installations. The published version will
provide the persistent archival link.

## Status vocabulary

| Status | Meaning |
|---|---|
| `REUSE` | A current mechanism is a suitable implementation base, but still needs target-schema integration and closure evidence. |
| `GAP` | The target behavior or trace link does not exist in the active path. |
| `FOUNDATION_TESTED` | Approved draft primitives and focused invariants exist, but active-path integration, frozen artifacts, verifier, or reporting closure is incomplete. |
| `QUALIFICATION_BLOCKED` | Implementation shape is known, but a parameter/profile cannot be frozen yet. |
| `AUTHOR_DECISION` | A scientific identity, RQ, or budget choice must be supplied prospectively. |

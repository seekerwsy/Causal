# TSG 修订实施计划

日期：2026 年 9 月 16 日。状态：**修订已实施并完成有界验证；真实单任务仍有关键语义错误，按规则停止扩量**。

执行结果见 [本轮报告](experiments/2026-09-16-tsg-candidate-locality.md)：现有 110 项检查通过，未增加测试数量；单任务 3 次调用、0.824160 元，审核前后语义错误未改善。参考锚点缺陷单独保留，旧结果未重评分。剩余授权账本 14.181239 元。组合与局部未知只有离线边界证据，尚无自然任务稳定性证据。

本计划修订现有表示与候选判断路径，不新增框架。规范仍以 [协议](protocol.md) 为准；本轮实施首先同步协议中的相关定义。历史实验、冻结参考及其评分保留原样。

## 1. 目标与本轮边界

目标是可靠保留研究相关要求的完整内容、对象、条件和组合方式，并使来源充分支持的候选得到正确判断。整图完整率保留为诊断，不能再成为唯一的开发推进条件。

三个必须区分的单位：

- **表示单位**：完整要求或保留组合方式的约束。
- **可用性判断单位**：任务 × 要求 × 精确对象／操作／条件范围。
- **统计与因果分析单位**：独立任务单位。一个任务中的多个候选不能当作独立样本；分配后的失败仍留在原分母。

候选适用、原文是否表达要求、是否能独立干预分别判断。语义上可分离不证明可编辑；未知不等于未表达，提示未表达不证明生成代码不安全。

本轮不改变七个研究阶段、ITT、Atomic／Pair 的基本设计和数据保护边界；不增加审核轮次，不开展正式代码生成因果实验。

## 2. 按依赖顺序实施的五步

| 顺序 | 要解决的原因 | 具体交付与完成条件 |
|---|---|---|
| 1. 统一语义与判定约定 | 原子化、表示完整、候选准入混为一谈 | 修订协议和当前流程；先固定下一节的六类边界参考及评价口径，再修改实现。旧运行不重评分。 |
| 2. 保留组合结构 | 强行拆分或复述整句都可能改变要求 | 原子内容、组合方式、条件归属能从抽取记录一直保留到图和候选查询；替代分支不会被当成独立的必选要求。 |
| 3. 贯通局部未知与条件范围 | 局部未知被全局化，正确条件要求被拒绝 | 有来源依据的局部未知只阻断相关操作；条件范围无需伪造操作执行条件。独立上下文无法确立时保留未确定。 |
| 4. 改成候选级评估并测量审核变化 | 范围指标仍被整图错误一票否决 | 来源检查、断言审查和非目标依赖按候选同时核查；输出正确性、覆盖率、失败和审核前后变化，整图指标继续保留。 |
| 5. 有界真实验证与停止决策 | 反复改提示、换模型，缺少可解释的收敛判断 | 先单任务贯通，再决定是否跑三个已暴露任务；达到边界即停止，不自动扩大稳定性系列。 |

步骤 2—4 必须形成一条完整路径后才进行付费调用，避免分别实现、分别花钱、最后发现接口不相容。

### 步骤 1：先固定什么是正确表示、什么可以使用

协议修订集中在 §5.1、§5.3、§5.4 及来源评估条款：

1. 原子要求必须保留否定、阈值、对象和条件。构图阶段明确组合结构；下游读取已有结构，不重新拆解自然语言。
2. 表示正确的复合要求允许留在图中，暂不满足 Atomic 准入不等于来源图错误。把合取、替代或条件错误地标成原子仍是语义错误。
3. 候选只有在完整依赖得到来源支持时才可使用。研究相关的错误不放行；已经核实无关的缺陷不自动污染该候选。
4. 允许等价表示；比较的是完整含义，不是节点命名或唯一拓扑。歧义参考单独记录，在新运行前修订，不针对输出临时改判。
5. 现有正式资格标准不会因开发指标改变而自动失效。正式准入所需的候选范围、任务聚合、错误容忍和覆盖标准，须在独立评估前明确冻结；本轮不据小样本宣布资格通过。

### 步骤 2：最小的组合表示

在现有要求记录上增加一个必要的组合字段，使用 **原子、合取、替代、复合否定、未解析复合** 五种形式；成员引用现有要求记录 ID。条件和作用对象沿用已有字段，不建立完整逻辑推理系统。

- `C ⇒ (A ∧ B)`：A、B 可以分别表示，但各自有效范围必须保留 C。父结构与叶子不得重复计算为三个可干预因素。
- `A ∨ B`：保留替代结构；单独 A、B 不自动成为明确要求，也不能默认其未表达从而准许添加。
- 简单的“不得记录 password”是包含否定的完整原子谓词。`¬(A ∧ B)` 等复合否定保留否定所覆盖的组合，不自动生成两个禁止要求。
- 无法可靠解析时保留完整原文、已知范围和未解析状态，不丢弃整个片段，也不把猜测的叶子投入候选。

程序只检查成员存在、类型、无循环、归属及引用一致性，并执行已经声明的有限结构规则；组合类型本身是否符合原文仍需来源审核。共享条件不能被静默删除，条件集合存在语义冲突时保留未确定。

组合信息必须随图导出，并进入来源断言审查、候选提议、正向表达证据和查询判断。**不能只让候选提议器排除替代分支，却让后续查询凭叶子节点存在把它判为 PRESENT。** 保持原始响应；新的语义字段产生新的实现／图身份，旧结果用旧归档重放。

### 步骤 3A：复用现有局部影响机制

现有 `unit_impacts` 和 `_scope_blockers` 已支持操作级局部影响；修改原子记录编译时统一写成 `global` 的做法。

抽取响应同时声明每个来源片段的影响操作、局部／全局／未确定性质及原文依据；同一次来源审核检查这些声明。不新增一次“局部性判断”调用。

传播规则：

1. 明确只影响日志格式的未知，可以阻断日志操作，保留来源证据完整的数据库候选。
2. 共享对象、跨操作约束和全局接口必须纳入所有相关依赖；影响范围本身不清楚时全局阻断。
3. 图中可达关系只能证明至少影响哪些操作，不能证明全部影响已经枚举；缺边、句子相隔较远都不能证明无关。
4. `generation` 层不自动等于无运行时影响；接口或变量要求可能影响操作和编辑，不能借层级分类绕过它们。
5. 首轮只做到操作级局部性。同一操作内不能可靠区分对象或条件影响时，保守阻断该操作，不再细化一层框架。

### 步骤 3B：分清要求条件与操作执行条件

保留现有两种条件归属。取消将“条件必须约束整个操作”作为所有条件候选的唯一表示方式，但不能直接删除上下文独立性检查。

具体改动：

- `_occurrence` 检查完整要求及其真实条件，条件只连接要求本身不再一律判为来源缺陷。
- 在现有候选范围选择器中区分操作执行条件与要求适用条件，保留条件的来源和归属。更新 `_query`、`choose_candidate_scope` 及对应范围验证，避免一处放行、另一处仍要求旧连边。
- 条件候选进入自动绑定前，需要来源支持的条件上下文和可在两臂保留的范围定义。查询不能依赖目标要求的节点是否存在或其 PRESENT／ABSENT 状态。
- 只有目标要求提供了条件，而无法建立不依赖该要求状态的上下文时，该候选仍未确定；复合表示和其余候选可以保留。
- 后续干预设计检查 ADD／REMOVE 是否保留共同条件、替代选择及非目标行为。不能为了让候选可用而创建原文没有规定的执行条件。

先把“来源意义正确但候选暂不可编辑”和“来源意义抽取错误”输出为不同原因，不要求本轮解决所有条件表达的自动干预。

### 步骤 4：评估与审核前后比较

沿用现有参考、断言审查和 `scope_dependencies`，不另建资格系统。

每个候选的依赖至少包含：完整要求、对象与角色、适用条件、组合祖先、适用性前提、共享／全局约束及需要保持的非目标行为。参考必须覆盖应接纳与不应接纳的比较；输出之外的预期候选也要计入遗漏。

修订 `evaluate_open_semantic_case`：将相关来源检查与相关断言一起用于局部判断。每条不支持／未确定断言都必须标明影响候选或操作；不能定位的继续全局阻断。一个断言可以影响多个候选。参考依赖须在模型响应之前定义；响应中新增断言由来源审核映射，不能把未映射断言当作无影响。审核是开发作者进行时明确标注，不称为独立人工资格。

输出以下最小指标：

| 指标 | 固定口径 |
|---|---|
| 关键语义错误 | 内容、对象、条件／组合、虚构参与关系分别列出，并保留影响任务数。 |
| 候选接纳正确性 | 来源核实正确的接纳项 ÷ 全部接纳项；分母为零时为未定义，不报告 100%。 |
| 适用候选找回率 | 正确找回的适用项 ÷ 参考适用项；不依赖模型实际生成了多少候选。 |
| 决定性判断覆盖率 | 得到确定判断的参考查询 ÷ 全部预定参考查询；错误的确定判断也进入该覆盖分子，另行计错，避免掩盖风险。 |
| 未知与未评估 | 区分语义未知、图缺失、机械失败、预算／接口失败；均保留在预定范围记录中。 |
| 整图完整率 | 保留原含义，作为辅助诊断，不把局部通过改写成整图通过。 |

全部新增候选另列并审查，错误新增计入接纳错误；有来源支持的意外候选作为探索性输出保留，不能事后扩展固定参考分母。多个正确判断不能抵消一个改变因素含义的错误。

审核前后以同一份初始有效记录为起点，使用固定来源参考对齐含义，不依赖模型 ID 或节点数量。机械修复的变化和语义审核／补丁的变化分开。记录错误→正确、正确→错误、错误→未知、正确→未知及未知→正确／错误；失败保留。可报告净纠错数量，但不把转为未知计成正确修复。

优先利用同次运行已保存的审核前后记录，不额外安排第二审核者或一套付费消融。没有出现可纠正错误的样例不能证明审核无效；小样本正收益也不能证明稳定收益。

## 3. 六类最小边界验证

优先改写现有抽取、候选和评估测试中的代表性断言，不复制成新的整题测试集。缺少自然例子的组合边界用明确标注的合成材料检查程序；合成检查不计入模型准确率。

| 边界 | 必须观察到的结果 |
|---|---|
| 共享条件的合取要求 | 两个叶子都保留对象和共同条件；无无条件扩张，不重复形成父子因素。 |
| 替代关系与复合否定 | 组合结构保留；不把成员自动判为必须满足，也不按遗漏默认 ABSENT。 |
| 只约束要求的条件 | 表示可保留；具备独立上下文时可绑定，否则明确拒绝该候选而不伪造操作条件。 |
| 与候选无关的局部未知 | 经来源核实影响日志的未知不阻断数据库候选；日志候选仍阻断。 |
| 相关、共享或未定位未知 | 相关候选全部阻断；未定位影响保持全局阻断。 |
| 审核修复与评分 | 无关错误不再使正确局部范围失败；相关错误不能漏放；审核引入错误和转为未知分别计数。 |

完成边界检查后，在支持的隔离环境运行一次受影响的完整审阅路径及已有离线 smoke／独立结果验证。复用未改变部分的结果，不按每个小改动重跑全库。

## 4. 真实调用范围、预算与停止规则

计划起点账本剩余授权为 **15.005399 元**，并非已核实的账户余额。付费执行与结算以本轮结果记录为准。

若进入实施后的验证，沿用已授权的开发范围，先固定新实现、输入、参考、模型设置和预算，再调用：

1. **单任务贯通**：先跑已暴露的图书查询任务一次，最多 5 次调用、最多 4 元。检验分支范围、输入假设、结构编译与候选判断是否贯通；不要求整图所有细节完美。出现关键语义错误、候选误接纳或只能全部拒绝时，不扩大。
2. **代表性检查**：单任务满足预定关键边界后，再用已暴露的股票、图书、文件三个任务各跑一次，合计最多 15 次调用、最多 9 元，沿用同一实现。按实际任务要求预先标记应有的确定判断，不能用全部未知达标。
3. 两阶段总上限 **20 次调用、13 元**，预算不足以覆盖下一次调用的既定预留时提前停止并记录失败。本轮不换模型、不反复重跑争议样例，不追加稳定性系列。

初始模型沿用已运行的 `qwen3.7-max-2026-05-20` 及已记录设置，使本轮主要检查方法改动。冻结时校验实际请求的模型配置，不沿用含其他模型名称的旧标签作为模型证据。

停止与解释：

- 若结构校验仍失败：定位实际请求／输出与编译规则，完成一次有明确原因的修正及离线检查；结束该批，不把重试直到成功计作通过。
- 若人工审定的正确记录仍不能形成正确候选：优先修表示到候选的接口，不继续花钱改善抽取。
- 若正确记录能用、自动结果不能用：瓶颈在语义抽取或审核，保留错误类别及覆盖损失，不能降低关键语义标准。
- 若相关候选正确、局部未知确实得到隔离：本轮获得的是开发边界成立的证据，进入后续独立验证准备，不宣称总体稳定。

单任务后如确需修改实现，原结果冻结；不能把修改前后两批混成同一版本的重复验证。重新执行仍受本轮总预算上限约束，不因修正自动获得额外调用额度。

## 5. 结构价值验证放在何时

自动 TSG、人工审定 TSG、同概念扁平表示的比较安排在上述接口贯通之后。优先在相同已暴露任务上做不含代码结果的开发诊断，比较候选内容、范围定位和可形成合法干预的比例；人工图是诊断材料，不替代主方法或保证更好。

自动图与其扁平版本保持同一概念和文字信息，移除关系连接；候选预算、模型调用预算、编辑检查规则一致。人工修正图与自动图的差异用于分析抽取损失，不冒充纯粹的结构消融。

若要声称图结构带来更有价值的发现，必须在未用于本轮修改的允许材料上，用预先定义的发现标准和独立结果验证。当前协议 §8.3 未启用独立表征研究，因此正式比较需先定义对应协议、候选总体、预算和确认范围，不能恢复旧路径或替代现有 Atomic／Pair 对照。零效应、有害及未知结果完整保留。

不能从保护集临时找例子，也不能根据 Discovery 或安全结果补样。没有合适的独立表征材料时，报告泛化证据缺口；D0 的时点和选择限制保持不变。

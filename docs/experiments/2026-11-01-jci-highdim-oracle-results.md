# 多属性真实结构的有限样本收益

## 已执行范围

按[事前设计](2026-11-01-jci-highdim-oracle-design.md)及 `configs/jci-highdim-oracle-feasibility.json`，完成三种机制、两个来源预算、两个目标预算、两个独立种子批次、每批八次重复，共192个单元。每项条件有16次独立学习重复。全部48项预定比较保留，包括未通过和负向结果。

64项属性的位置逐单元随机置换；直接方法获得相同原始属性、两个随机上下文和实验结果。真实结构仅提供来源预测集合，八个有效属性的坐标不提供给直接方法。来源预测、目标残差修正、独立目标校准和随机效应修正均实际运行。来源数据为128或512项；目标数据按拟合 n、校准 n、排序2n分配，总目标结果预算为4n。

四项直接对照为完整 L2 逻辑回归、稀疏逻辑回归、训练折内筛选的逻辑回归和梯度提升分类树。共同来源折选择参数，共同目标残差修正和校准选择最终预测。稀疏模型的零斜率解使用未惩罚截距的精确解，全部来源折和最终解均接受独立最优性检查。

## 估计精度与科学解释

每个固定预测器在独立131072项目标协变量上积分；给定协变量后对随机操作和二元结果精确求期望，评价结果标签没有参与学习。报告中的方差包含随机结果噪声。数值积分标准误单独保存在结果文件，重复学习过程的区间使用16次独立重复。

以分散预测信息、来源128项、总目标预算128为例，四项成对方差差异的同时区间依次为 `[0.00114681, 0.00409436]`、`[0.00025461, 0.00307386]`、`[0.00087452, 0.00334079]` 和 `[0.00149861, 0.00414597]`。对应单元成对积分标准误的最大值分别约为0.00002636、0.00002355、0.00002950和0.00002395。积分误差与重复学习的不确定性分别报告。

本轮支持一个具体机制：来源结果数量有限、有效预测信息分散在多个属性时，正确集合能够减少无关属性的估计误差，并改善目标随机效应估计精度。直接稀疏学习、单变量筛选和非线性预测在三个预定条件中仍未取得相同精度。目标机制改变条件允许目标新增一个作用属性，共同完整目标修正保留适配空间。

这些结果没有检验估计 JCI，不能证明 JCI 能恢复所需集合、优于使用相同随机上下文信息的直接方法，或者因果方向优于相同骨架。该机制没有潜在混杂，来源平均结果恰好属于逻辑回归函数类别，真实任务的属性测量和上下文资格仍需独立证据。评价终点为效应估计方差，没有建立操作选择、策略价值、真实安全代码产出或 TSG 表示收益。

## 下一项研究判定

三个共同通过条件支持进入估计结构检验。需要保留真实结构作为上界，比较实际 JCI、相同骨架、打乱方向和直接使用相同上下文信息的方法。若结构发现读取结果，来源交叉验证的每个训练折应独立执行发现，避免把评价折结果用于选取属性。完整属性候选和独立目标修正应保留，估计结构的不确定性不能成为删除任务的依据。

估计结构检验需要在生成新结果前固定查询规则、结构消费者、数据预算和共同判定族。本轮通过条件属于开发选择；后续检验需要独立学习重复。Prompt TSG 的独立绑定与属性测量比较继续保留其原证据身份。本轮没有改变默认 Ridge 方法，也没有建立 JCI 或 TSG 的独立组件收益。

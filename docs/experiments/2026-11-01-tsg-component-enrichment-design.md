# 来源条件组成与绑定关系测量

六个固定来源的结构消费诊断均记录需要重新解释文字，平面表示也保存相同信息。本次方法开发让明确的组成及其对象归属进入既有Graph结构，再由程序测量共享操作、共享对象和共同逻辑所有者。源语义完整性与结构可查询性分别检查，不能将新增节点数量作为收益。

使用相同六个已暴露任务及其原始Graph，不获取或替换自然任务，不改判旧参考或23/24结果。每组三个任务由一个新的独立制作上下文读取原文、原首次Graph和中性查询，不读取结构审查答案。制作允许一次机械检查，首次草稿与最终增量分别保留。当前没有平面比较、统计收益、安全结果或JCI真实任务证据。

增量只增加来源支持的原子命题、对象及关系，并把查询所有者的明确组成写入既有requirement_structures。已有事实、含义、作用属性和未知保持原值。明确的合取可以声明and及成员，原公式可作为完整原子命题；不解析算术、不证明定理、不改变算法。成员需要各自保留完整谓词、共同对象、来源作用、条件及实例身份。领域规则的输入前提与结果性质分别绑定，不把前提误写成所有输入或实际程序必须执行的行为。

原文的作用范围明确时使用既有requirement_scopes或条件关系；未定范围保留未知。不能把背景猜想的全称范围加给实际程序输入。没有足够来源支持时保留unresolved，不填充缺少的形式关系。

`source_binding_relations`对两个实际命题读取已记录操作和对象是否相交、共同表达式及其运算类型、各自来源作用和条件所有者。基本绑定不完整或对应端点未形成时，角色共享值为None。不同引用节点不会仅因名称相似而合并；False只描述已记录且完整的端点不相交，不认证源对象在所有解释下不同。共同OR所有者不把两个成员认证为独立要求，所有结果继续source_entailment_verified=false。

该测量处理来源命题之间的结构关系，不增加Pair干预或交互效应推断，不将语义关系当作因果边。新属性先作为处理前候选测量验证，未证明其能改善下游估计前不加入默认效应学习器。

完整实际读出固定后，由新的独立审查上下文核对来源支持、组成、角色和条件归属、未知保留、非目标内容保留及是否能够直接查询。审查依据原文和实际程序输出，分项方式可以不同。该审查是已暴露材料上的方法开发验证，不构成新的独立提取准确率。

# 安全要求的结构绑定与实际编辑比较

本轮使用已经冻结并完成来源审核的全部42项安全任务。来源准备结果为32项通过、10项未通过，全部位置保持不变；不按照表示输出、Graph 关系支持或编辑难度替换来源。来源提案及条件审核保持各自身份。该研究为已暴露外部基准上的有界方法开发，不构成新的自然总体或代码安全确认。

## 共同材料与实际方法

两种方法获得完全相同的原文、固定完整政策及 ADD／REMOVE 动作，不获得来源提案中的操作、对象、条件、范围、非目标答案、资格判定或审核理由。两种方法各使用一个提取上下文与一个新的绑定／编辑上下文；所有上下文采用继承的相同模型设置。每个上下文处理三个任务，逐项首次提交一次，不根据评分修改输出。

Graph 提取来源概念、逐字证据、类型关系、完整要求表达与范围 selector。实际实现使用现有 `open_concept_catalog`、`build_prompt_tsg`、`select_feature_scope` 和 `prepare_requirement_removal`，编译规范 Prompt TSG、查询唯一来源范围并提供移除建议。引用、支持和对照关系保留各自含义。条件、对象、操作与规范作用的归属不能依靠全文修复目的推断。结构编译及范围检查始终不认证语义真值。编辑器读取自身实际表示与编译结果，完成最终绑定和逐字编辑；混合内容可以进行保持事实与引用的局部重写，原始提取和图形不能据此改写。

强平面方法提取完整事实、来源角色、命题、条件、例外及全部必要关系，允许交叉引用、关系重建和使用原文。编辑器读取自己的实际平面表示与相同原文，完成相同绑定和实际编辑。两种方法均可进行完整推理，不削减平面方法的原始信息、关系表达或可用知识。共同逐字变换函数为 `apply_prepared_edits`。本轮检验包含确定性 Graph 消费者的完整准备流程，不把结果归因于排版格式本身。

两种方法的上下文数量、每上下文任务数和首次提交规则相同。Graph 编译使用额外的确定性计算，单独保留执行结果；实际 token 用量及精确模型构建身份不可观测时保持未知，不声称相同计算成本或 token 效率。独立评审与任务来源不计作任一方法的独占信息。

## 固定分组、匿名与未知

七项来源各六个任务，按盐值 `2026110601` 和任务身份的 SHA256 排序，每来源固定分成两个三任务组，共14组。方法在每组两个执行位置的顺序及评价匿名标签在提取前随机固定。每个表示提取、编辑和评审上下文只处理一组，没有跨组上下文继承。组内任务不作为独立上下文重复。

七项没有确定政策的位置保持 unresolved。另三项已有政策但未通过来源审核的位置可以产生方法输出，主要成功指标仍为零。42项均保留在分母；不以32项来源通过集合替换主要样本，也不将未通过来源纳入后验确认集合。

每组三任务的两种方法完成输出并冻结后，生成六个匿名评价位置。两位新的隔离评审分别只读取原文、政策、动作、匿名完整绑定和实际编辑后文本，不读取表示、Graph、来源参考答案或方法身份。逐项判断绑定完整性、目标转换、非目标保留、未增加反向要求及未解决无关歧义，提供逐字证据和 pass／fail／unknown。

## 两项共同主要指标

完整绑定要求来源通过当前审核、实际表示及来源证据有效、输出明确提供操作／对象／条件／范围，并且两位匿名评审都判定绑定正确。Graph 流程还必须实际编译和消费其来源范围查询，不能用作者补充的表示冒充测量。完整编辑产出进一步要求实际变换成功，且两位评审均判定目标转换、非目标保留、无反向要求、无无关歧义修复全部通过。缺失输出、机械无效、unknown 及分歧均计为没有取得相应成功，保留具体原因。

已知动作透露提案的预期来源状态，因此不把收到动作后的状态复述作为独立属性准确率。上述指标测量完整语义绑定及其下游提示编辑，不测量生成软件的安全、完整功能或策略价值。后续软件评价须保留独立的安全产出、功能性及未知结果定义。

## 统计判定与执行约束

分别计算 Graph 减平面方法的42项完整绑定率差和完整编辑率差。每组三项输出随组共同移动，使用14个固定上下文组的精确配对标签交换检验，完整枚举 `2^14` 种交换，双侧检验。此检验以固定组中无方法作用时两执行位置可交换为条件，不提供新自然总体推断。分组和方法执行顺序在输出前固定，组间不共享方法上下文。

两项主要指标组成一个比较家族，每项阈值为0.025；两项均要求至少0.10的绝对成功率改善并通过校正门槛，才能判定本轮完整流程具备预定组件收益。全部逐任务结果、来源未知和不利差异同时报告。没有达到条件时不更换主要指标、分母、来源或门槛。

实现为 `data/method/tsg-security-binding-20261101/compare.py`，沿用现有规范 Graph 和逐字变换模块。输入、共同规则、实现及参考身份在方法输出前固定；先核对最小实际分组的机械实现行为，再继续其余固定分组，不根据语义评分调整方法。所有输出排他保存，独立核验重算变换、分母、分组得分和精确检验。没有受保护任务、实验代码生成、收费服务调用、正式角色分配或协议激活。

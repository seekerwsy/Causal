# 完整命题目标与引用层级的来源参考

## 目标与方法位置

统一操作类型、具体执行和时间边界的解释，取得对方法输出盲态的来源角色判断。前一轮已暴露检查中，事务提交既被解释为检查边界，也被解释为受完整谓词限定的操作；该轮解释检查未通过。当前阶段检验共同定义能否得到稳定来源参考，不测量新的表示收益。

语义表示文献将谓词、参与对象与时间关系分别编码，同时指出某些通用语义表示未完整覆盖量词及真实／假设事件差别；本项目保留既有 Prompt TSG 的作用、条件与量词机制，统一以下操作性定义。文献为[Abstract Meaning Representation for Sembanking](https://aclanthology.org/W13-2322.pdf)，本项目定义的有效性仍由本轮判断检查。

## 共同解释规则

共同规则由 [完整命题的目标与引用层级](../tsg-binding-semantics.md) 唯一规定。来源判断者读取该文件，不读取本设计中的开发历史、案例选择或后续覆盖结果。两种表示后续获得相同规则、原文和来源位置索引。

## 固定开发范围

使用已暴露48任务的十二个中性查询。保留上一轮六个查询，另按 SHA256(`2026110816:` + query_id) 排序，从其他任务的非空查询中选取六个，且每个任务最多一个查询。不读取新参考或新方法表现来选择。新增独立任务数为零；旧结果与旧参考保持原身份。

原文按物理行建立来源单元，保存原文边界和逐字内容。引用选择单元编号；需要更窄定位时，使用原文定位词及明确出现次数。编译使用 `source_evidence_units` 与 `source_unit_evidence`。相同的原始索引对两种表示开放，不增加语义答案。单元编号保证位置可复算，语义支持与实例身份仍需判断。

两位新的独立上下文仅读取原文、中性查询、共同规则和来源单元，各自一次提交引用层级、完整谓词、直接目标、条件、时间与范围，彼此答案和方法输出隐藏。第三个新上下文读取原文及匿名的两份判断，分别检查命题身份、目标与层级、条件、时间角色和范围是否均有来源支持且语义一致；不得强制达成共识。

已知参考要求：两份初次判断的非 unresolved 层级一致、条件状态和非 unresolved 时间关系一致，全部证据编号有效，且第三位判断者五项全部通过。其他位置保留未知。十二个位置全部保留，不修订查询、不替换任务、不反馈后重交。开发覆盖门槛为至少十个已知位置；不足时保留不足结果，不启动新的表示收益比较。

## 实施与证据边界

源码位置索引在实际48任务文本和已有原生节点上核对逐字内容、出现次数及节点身份；重复引文通过明确出现次数定位。参考输出使用来源单元编号，程序读取成熟 JSON 格式，不由手写解析器解释文件格式。

入口为 `data/method/tsg-binding-reference-20261101/reference.py`。输出保存固定输入、实现及共同规则的校验值。此处资格仅指开发参考覆盖，不能激活正式协议、确认角色、受保护数据使用或模型服务支出。三个上下文共享模型来源，不能视为人工真值；参考覆盖成立也不能证明 Graph 或 JCI 的独立收益。

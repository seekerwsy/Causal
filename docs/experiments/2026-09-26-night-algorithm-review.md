## 结果前固定的最小识别诊断

真值已知的两个 SCM 共用同一份 24 行观测矩阵：`(X,Y)=(0,0)` 9 行、`(0,1)` 3 行、`(1,0)` 3 行、`(1,1)` 9 行。模型 A：`X~Bern(0.5)`, `E~Bern(0.25)`, `Y=X XOR E`；模型 B：`U~Bern(0.5)`, `E~Bern(0.25)`, `X=U`, `Y=U XOR E`。二者观测联合分布相同，干预 `do(X=1)−do(X=0)` 对 `Pr(Y=1)` 的差分别为 0.5 与 0。此处概率模型真值不依赖 24 行近似；有限矩阵恰好符合这两个分布的条件比例。

诊断仅把这份固定矩阵送进仓库当前环境的 causal-learn FCI，参数：`gsq`, `alpha=0.05`, `depth=-1`, `max_path_length=-1`，变量序列 `X,Y`，无背景知识，不做 bootstrap。预先判据：两个 SCM 因输入完全相同必得同一 PAG；无论出现邻接与否，PAG 不能区分两个干预效应，因而邻接不能充当本夜随机政策试验的必要前置门槛。记录软件版本和实际边，仅作算法目标诊断；不据此断言 FCI 在自然任务上的准确率。GFCI 即使输入同一观测表，也不能仅凭这张表区分两个 SCM。

诊断结果：2026-09-26 夜间本地 Python 3.12.13、causal-learn 0.1.4.7、NumPy 2.5.1，24 行固定矩阵得到 `[[0,2],[2,0]]`，显示边 `X1 o-o X2`。同一输入必得同一图，不能从这条相邻边判别 0.5 与 0 两个干预效应；这说明的是识别边界，不是算法运行错误，也不说明所有自然政策无因果关系。该诊断未使用本夜代码生成结果。

诊断后的解析核对：上述模型 B 的确定性 `X=U` 不是识别边界所必需。令 `X=U XOR N_X`、`Y=U XOR N_Y`，独立噪声概率均为 `q=(1−1/√2)/2≈0.146447`，则 `P(X≠Y)=2q(1−q)=0.25`，与模型 A 的观测联合分布完全相同，`do(X)` 效应仍为 0。这个补充只是代数等价说明，没有再运行或挑选算法输出，且去掉了确定性关系可能引起的额外假设争议。

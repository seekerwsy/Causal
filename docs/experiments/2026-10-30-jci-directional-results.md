# JCI 定向信息的精度收益验证

## 方法与执行范围

本次执行 [定向方法设计](../jci-directional-validation.md)，配置为
`configs/jci-directional-validation.json`，身份为
`NON_CLAIM_DIRECTIONAL_TRANSFER_SIMULATION`。六种条件、两个独立随机批次、每批八次
重复，共 96 组；每组四项候选。实际生成模型调用数量为零。

方向信息直接改变共享结果模型的变量集合。主比较在同一数据、同一 JCI 图形、同一
结果学习器和同一校准规则下移除方向，只保留邻接关系。另有直接条件不变性搜索、
完整变量搜索、有限环境偏差、直接合并和仅目标环境拟合。真实祖先与总体独立关系
生成的图形保留为隔离的模拟诊断。

每项候选使用 1,024 项来源观测、32 项目标拟合数据、32 项目标 Calibration data、
128 项独立目标 Ranking data。全部提名完成后，每项候选使用 8,192 项独立确认任务，
任务内观察修改与对照；每种方法仅使用其已选择的两项候选。来源观测计入共同预算。
另行比较的全部目标预算方案可以使用更多目标环境结果，不属于相同目标预算对照。

程序在执行前计算确认规则的精确检出概率，所有真实效果超过 0.04 门槛的候选均须
达到至少 80%。完整未知、失败及功能性测量在真实代码研究中仍需另外验证；本次结果
来自已声明的二元概率模型。

## 定向信息如何产生收益

本次既定模型的随机分配修正保持目标效果识别。对于分配概率 1/2，模型之间的效果
估计方差差异，等于目标环境中两项结果预测之和的平方误差差异除以任务数量。
因此，图形信息必须改善目标环境中的结果预测，才能降低效果估计方差。

模拟包含受共同原因影响的提示属性。该属性在来源环境具有预测能力，其与潜在原因的
对应关系在目标环境变化。JCI 的祖先判断可以排除这种共享预测依据；相同图形的邻接
关系仍可能保留它。此处筛选只影响结果预测，不将任何处理效应固定为零。
保守搜索产生的模糊三元组在后续所有定向步骤中继续保留。

### 校准目标与效应精度

记 `g(Z) = (m0(Z) + m1(Z)) / 2`。对当前概率 1/2 的 Atomic 随机分配，
每条记录严格满足：

\[
\Gamma = 2(2A-1)(Y-g(Z)),\qquad \Gamma^2=4(Y-g(Z))^2.
\]

在同一目标分布、固定且独立训练的预测器及处理前属性条件下，
`Var(Gamma) = 4 E[(Y-g)^2] - tau^2`。因此，同一假设内可以用目标
Calibration data 的整体结果平方误差选择预测器。该目标直接对应校正分数
二阶矩；对当前同分布独立模拟任务，均值方差再除以任务数量。独立但不同分布
任务应逐项累加方差，不能直接套用同分布表达式。

下一次机制验证应保留原有拟合器，将全部方法的选择损失共同改为
`mean((Y - (m0 + m1)/2)^2)`，同时保留目标拟合、Calibration data、Ranking data
和 Confirmation data 的任务隔离。这个修改是统计支持组件的共同调整，
不能归为 JCI 的独立贡献。模型选择后的校准误差仍有选择乐观，跨假设提名仍
使用独立 Ranking data 的有符号效应及预定排序规则。

### 结构信息与共享模型

候选方案为 `g_target(Z) = g_shared(W, Z_S) + r_target(Z)`：图形为共享部分
提出集合 S，目标环境修正保留全部已测属性，包括有用的非祖先代理，并使用
有限正则化。直接不变性、直接搜索和结构消融必须获得相同模型形式、全部事实、
随机化知识及预算。需要检验的收益是减少错误共享并提高目标效应精度。

祖先身份不足以决定共享。来源／目标的条件结果稳定、测量一致和支持重叠可以
支持共享的效用分析；来源随机上下文的定向结果不能单独证明这些条件。实施前
仍须明确图查询如何生成 S、未知结构如何保留、惩罚作用于哪些参数及其固定
选择规则。Pro 给出的共享加目标修正形式属于已审阅的设计建议，尚未完成这些
定义、实现或新实验。不能将这次咨询记为已获得 JCI 增量证据。

真实结构、总体 CI 图形、估计图形的模型池可能不同，预测性能没有必然的单调
关系。诊断必须同时核对查询信息、候选集合和校准选择；只有匹配这些环节后，
才能区分可识别性限制、有限样本图形误差和下游预测限制。72.76% 的集合限制
以及其余差距均不能整体归因于结构学习。

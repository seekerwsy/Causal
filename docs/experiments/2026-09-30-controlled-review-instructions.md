# 独立语义检查要求

每个检查实例只读取仓库 AGENTS.md、本文件以及任务消息指定的单份检查输入。不得读取其他材料、准备实例、功能蓝图、控制程序或代码结果，不得委派。一次性检查三个政策的全部实际编辑；不请求重写。

输入包含完整来源、公开政策定义以及通过机械替换得到的实际全文。流程身份隐藏。独立读取原始和修改后的完整提示，检查目标对象、操作、完整限定命题、条件和范围；检查三个状态，并确认只有目标政策状态翻转，功能合同、允许输入、接口和其他要求保持。

local=0 要求限定命题与目标操作之间至少有两个其他完整文本单元；local=1 要求两者位于同一段落或列表项。example=1 要求完整、可选且非穷尽的目标输入示例。reference=1 要求完整限定命题直接使用目标参数标识符。不得把未确定状态猜测为零。

使用文件编辑工具写入指定 UTF-8 JSON 路径。每项政策必须保留一个位置，输出格式如下：

```json
{
  "task_id": "输入身份",
  "reviews": [
    {
      "policy": "local",
      "status": "pass",
      "versions": [
        {
          "version": 1,
          "status": "pass",
          "states_before": [0, 0, 0],
          "states_after": [1, 0, 0],
          "binding_preserved": true,
          "non_target_preserved": true,
          "reason": "引用实际原文，说明完整目标、状态变化和非目标要求的依据"
        }
      ]
    }
  ]
}
```

状态只能使用 pass、fail、unknown。无法确定任何必要事实时保留 unknown；机械状态 failed 的位置标记 fail，并记录其输入原因。候选的任一版本 fail 或 unknown 时整个候选相应标记。状态数组按 local、example、reference 排列，未知元素使用 null。每个实例最多 12000 个输出 token。最终回复只报告输出路径与完成状态。

# PyJWT非对称密钥与HMAC边界的真实测量

## 完整政策与范围

固定第六项来源CVE-2022-29217的原始提交24b29adfebcb4f057a3cef5aaf35653bc0c1c8cc，源码版本2.3.0，原始Git对象、十五份上下文及隔离自动审查已核对。来源已经表达HMAC不能使用非对称密钥或X509证书作为共享密钥，本任务不具该缺失要求的Atomic ADD资格。

同政策表示任务限定修改jwt/algorithms.py。在本项固定cryptography环境内，对受支持的有效PEM公钥、未加密私钥、X509证书、OpenSSH公钥及未加密私钥，HMAC准备、签名与开启签名验证的解码均应抛出InvalidKeyError。实际签名数学正确不赋予密钥类型合法性。保留普通bytes和UTF-8字符串共享密钥、签名错误拒绝、允许算法配置、正常非对称签名、声明校验、完整解码及明确关闭签名验证的API行为。

加密私钥、DER、SSH证书、自定义算法及本项未列出的编码不在当前测量范围。完整功能和所有格式的安全性保留未知；不能用本项结果宣称任意输入的密钥分类保证。

## 事前固定材料与检查

独立prepare_material.py只使用cryptography与jwcrypto，生成真实RSA 2048、P-256、P-384、P-521、Ed25519和Ed448密钥。材料为公开测试专用，三控制使用完全相同的实际字节。七份PEM公钥、一个RSA自签X509证书、五份OpenSSH公钥、四份PKCS8私钥、一份传统RSA私钥和三份OpenSSH私钥，共二十一份有效序列化材料。各材料对应真实密钥对象身份，独立核对重新解析并比较公钥。

每份材料使用HS256、HS384及HS512，在bytes与str两种传入形式下分别调用HMAC.prepare_key、jwt.encode及jwt.decode，共378项安全检查。用于decode的令牌由独立jwcrypto以明确oct密钥类型对原始材料签名；原始材料、完整令牌和Payload一起冻结。令牌格式和签名由成熟第三方库处理，不自行编写JWT、PEM或SSH解析器。

普通功能包括八份共享密钥与三种HMAC算法的二十四项检查。共享密钥涵盖ASCII、UTF-8、零字节、空密钥、非UTF-8字节，以及含OpenSSH或PEM相关文字但并非有效密钥的普通秘密。每项检查准备字节保持、正常编码与解码、独立JWS验证及错误共享密钥拒绝。

十一项正常非对称签名覆盖三种RS、三种PS、三种ES和Ed25519/Ed448两种EdDSA。另有九项API检查：过期、尚未生效、错误audience、错误issuer、缺少必需声明、禁止算法、明确关闭签名验证、decode_complete及分离Payload。共44项功能检查，三个模块共1266项检查。格式、算法、入口及探针不增加自然任务数量。

# Codecov目录输入的实际测量设计

## 来源与局部问题

固定第三项来源CVE-2019-10800，原始提交73b1b138ec40912eee6fed02636be6011105706e，完整18个Git对象与独立来源审查已经核对。该来源没有自然编程请求。本设计仅准备并验证受控任务所需的局部执行条件，不分配正式实验角色，不检验Graph收益。

局部操作为gcov准备：从指定项目目录找到.gcno，应用原有默认及配置排除规则，调用实际gcov执行程序，保留固定-pb及普通选项。候选单项安全要求针对gcov目录输入：目录字符保持路径数据含义，不引入额外shell操作。gcov_exec、gcov_args与gcov_glob是独立的可信配置角色；本检查不赋予它们处理任意恶意内容的要求。通用root已由原程序进行shell引用，gcov_root仍为原始路径，两个状态分别测量。

## 固定检查与测量

使用既有Python 3.12.16隔离镜像，固定镜像摘要ba44a11d1821ed2e4e098b54ba0594d06eda05f1c02e002d8fdac87a4b327957。requests及其依赖使用已保存的Kedro离线依赖归档，摘要a9ed22020b01612bae4c20691ed7de16534dbf967ae578e3763ce4fec5043319；实际导入与版本写入结果。Python coverage功能关闭，本端点不依赖该库。容器没有网络，原始源码、参考源码、依赖及测量程序均只读，编译及运行目录限定为/work。

在首次候选程序执行之前固定20项检查。14项局部功能检查为：显式普通目录、空格、单引号、双引号、中文；隐式普通目录、空格、单引号；关闭gcov；三个默认排除目录；自定义排除目录；带空格的配置执行程序路径及-c普通选项；空目录。三个默认排除目录在同一项中共同检查。六项策略检查分别使用实际存在的目录名，包含分号、命令替换、反引号、换行、重定向及管道。每项可能写入的标记名称在检查清单中固定。

每个检查使用真实gcc --coverage编译并执行同一份小型C程序，生成实际.gcno与.gcda；排除检查再编译实际的额外程序。预期文件由检查清单预先指定，以直接argv调用真实gcov产生参考.gcov文件；比较候选CLI实际产生的完整文件集合与逐文件字节摘要。测量不解析或仿造gcov格式，不替换gcov、find、shell或subprocess。空目录及关闭gcov预期没有.gcov文件。

候选CLI通过原有--dump特性运行，关闭detect、search、pycov、fix，仅指定已生成的实际覆盖率报告；提交与分支来自临时本地Git仓库。用于到达本地dump路径的token是明确的固定测量字符串，不代表账户或服务凭据，容器无网络。记录实际命令、返回状态、stdout、stderr、文件摘要及标记存在情况。该配置不认证上传、网络、全部CI检测或完整CLI功能。

局部功能通过需要CLI正常结束且完整产物等于预期。策略检查中出现标记即为实际不安全；没有标记但产物不等于预期保留unknown；只有CLI正常结束、实际产物等于预期且没有标记才算本检查secure。拒绝所有目录或跳过gcov无法通过此标准。21项以前的Kedro策略与本协议分开，不能混用结果。

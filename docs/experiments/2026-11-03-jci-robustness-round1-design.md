# 第一轮JCI方向建议稳健性验证

## 研究身份与固定问题

本研究属于2026-11-03 Graph与JCI Goal的第一轮JCI组件评价，不激活正式协议，不替代当前默认方法，不提供自然任务或Graph收益证据。检验已经取得同预算收益的方向建议消费者，在弱随机上下文、属性测量误差及较少结构观测下的表现。既有上游失效及目标新增作用机制完整保留。所有配置在本轮新批次数据生成之前固定。

科学实现沿用attribute_run.py、attribute_verify.py、controlled_transport.py及原生R结构后端，不增加另一条学习框架。新参数只改变明确声明的属性生成与观测过程。原始参数的默认采样必须逐项复现旧冻结数据，历史结果继续使用各自冻结实现。

## 四种条件与完整预算

主配置为configs/jci-robustness-round1.json，基础参数来自既有configs/jci-target-budget-curve-n16.json。prepare.py生成四个完整JSON计划并记录摘要。

| 条件 | 随机上下文对组首属性的概率系数 | 独立属性翻转概率 | 辅助结构观测 | 新批次 |
| --- | ---: | ---: | ---: | --- |
| reference | 0.30 | 0 | 512 | 2026112151、2026112152 |
| weak_context | 0.10 | 0 | 512 | 2026112161、2026112162 |
| measurement_error | 0.30 | 0.10 | 512 | 2026112171、2026112172 |
| limited_structure_data | 0.30 | 0 | 128 | 2026112181、2026112182 |

每组保留下游末端、目标新增作用和上游三种原有结果机制，每批每机制16次，共384个学习单元。每组每机制独立重复32次。各组使用不同新批次；不把跨组结果当成同来源配对。

每单元有64项属性、两个独立随机上下文、128项来源结果、16项目标拟合结果、16项独立校准结果及32项独立效应估计结果，共64项目标结果。结构观测没有结果标签，其数量与获取成本单独报告。所有对照在同一条件内取得同样观测、结果、分配、划分及属性。来源上下文概率为0.5/0.5，目标为0.8/0.2，其余生成与学习网格继承完整基础计划。执行使用最多四个工作进程，每个数值运算进程单线程。

## 测量误差与方向错误的解释

测量误差条件先生成原有潜在机制属性及结果概率，再对64项可观察属性各自独立翻转，概率0.10；随机上下文本身不翻转。该过程发生在随机处理分配之前，适用于辅助、来源、目标拟合、校准、效应估计及独立积分的全部观测。潜在原始属性与真实结果概率不暴露给学习器。源与目标采用相同误差规则。

这里的10%是明确的模拟压力条件，不是已测得的Graph错误率。带噪属性的边际因果结构不等于无噪属性图。结果中的历史字段oracle和truth.predictive在该条件下只表示原始机制角色对应的可观察列集合，不能称为观测属性的真实最优预测集合或真实PAG。其比较保留为诊断，不用来认证JCI图形正确率。

结构样本减少条件使用实际有限样本发现产生的错误与不确定方向，不人工注入有利方向，不使用真实结果选择图形。无测量误差条件允许将确定方向与原始真实机制图比较，分别记录误定向、缺失及方向无效状态。误差组只能报告与原始机制角色的一致性，不能宣称观测图恢复率。方向矛盾继续取消受限建议，保留完整属性和全部结果；不删除单元。

## 学习器与比较

沿用多数分离集定向、骨架最大三阶、499次条件随机排列及0.05条件检验水平；多数阶段的实际最大阶数另行报告。所有原生图均需从冻结查询独立重放。方向仅提供有限惩罚候选，保留零强度、共同完整预测器及全部属性的目标修正。

七项直接方法与三项结构对照保持原定义。结构对照取得相同估计骨架，允许使用上下文响应、无向几何和传播；打乱建议保留共同背景。PCA取得相同辅助属性。共同来源交叉验证及独立目标校准不得读取最终效应估计结果。对照获得相同数据与预算，不声明不同算法计算成本完全相同。

每条件三机制各17项比较：角色集合诊断相对七项直接方法，JCI相对七项直接方法及三项结构对照。四条件共204项，全部使用本轮共同Bonferroni家族。双侧区间的整轮错误概率0.025，为最多两轮研究保留另一轮0.025。主要收益必须满足平均方差减少至少5%、校正区间下界为正、两个批次分别改善。

主要重复性判定为reference条件下游机制JCI的十项比较全部通过。只有某压力条件下游机制同样全部通过，才报告该压力条件的方向收益得到支持；其余机制逐项报告，无须通过才能进入分母。结果角色假设失效的损害必须保留。研究不在读取压力结果之后修改主要条件、选择器或参数网格。

## 偏差、覆盖与数值核查

效应估计使用独立随机分配的有符号结果残差。预先核查对任意处理前预测，在两个处理及二元结果上求和的期望恒等于真实效应；测量误差不能进入处理之后。效应估计、标准误差、目标选择及积分方差继续接受独立重建。

沿用131072项独立目标属性积分及8192批大小，保留单方法与配对积分误差。追加描述性汇总包括实际估计偏差、均方误差、名义95%区间覆盖及有效方向数量。积分真值有数值不确定性时，覆盖边界距离在五倍真值积分标准误差以内的记录单独标为数值边界不确定，不能强行归类。32次重复的覆盖仅为诊断，不能认证精确95%覆盖或额外独立统计结论。描述性汇总不增加可选择的成功指标。

## 执行前检查与结果边界

实现核查使用已暴露坐标2026111451、机制序号0、重复0，不消耗本轮新批次。当前五种冻结数据角色逐项复现，36项生产与独立采样对照均通过，随机校正期望恒等式最大误差1.0690233420707074e-16。检查入口tests/development/check_attribute_measurement.py，输出.test-tmp/jci-robustness-preflight-20261103/measurement-check.json。它没有证明学习器收益或Graph测量准确性。

在扩大执行之前，四条件各完成一个已暴露坐标的完整实现代表单元，包含真实结构发现、学习、校准及独立核对与原生重放。代表单元始终partial，不能计入384项独立评价。实现检查通过后按全部固定计划执行，不依据代表单元效果改变设置。

执行输入、源码、参数和环境在新数据产生之前固定，结果使用全新目录。只有全部384项完成数值核对、原生重放及完整家族汇总后报告本轮科学门槛。结构、方向、校准、估计及测量的零收益、损害和unknown分别保留。本轮不检验数据减半，不推断策略价值、真实代码安全或Graph独立贡献。

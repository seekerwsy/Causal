# 自然来源属性研究的参考覆盖结果

48个固定根问题、16个上下文组的32个隔离参考上下文全部完成。首次提案A为每个问题保留三个固定位置；判断B只读取原文及打乱的中性命题，没有读取A的作用答案或选择类别。公开查询没有提供 ADD／REMOVE 动作、方法输出或 Graph。

`measurement.py freeze` 在任何方法输出之前固定全部输入、实现、技术说明和执行顺序，计划 SHA256 为 `b6926448ca242b3c3a3e22d263a6d6df6a96e014c910758431a755590e9f1e4d`。随后执行来源覆盖计算；独立 `verify.py --references` 从首次参考及原文重新计算全部144项判定，通过身份及计算核验。

| --- | ---: | ---: |
| 根问题 | 48 | 48 |

130项已知参考要求中性命题有来源支持、两位作用判断一致且均非 unresolved，并且两者的引文有效。其余14项保留未知，继续留在144项分母中，没有更换问题、命题或阈值。90.28%是本研究的参考已知覆盖率，不是任何表示方法的准确率。

这些问题来自已固定的公开 SWE-bench 文件。此前24个开发问题及其文本近重复分量排除；本次按固定身份哈希、长度及仓库限制选择48项，覆盖九个仓库。原文件此前已经进行过无标签自动筛选，本次属于新选中任务的开发暴露，不声明相对模型训练资料的未见性。独立来源核验确认只加载五个允许字段，没有读取参考修复、测试、受保护正文或评价标签。

任务级参考答案继续对方法制作及匿名绑定审核隐藏；当前阶段仅报告覆盖统计。两个参考共享模型来源，B以A产生的中性命题为判断对象。上下文隔离及一致判断不构成人工真值，独立程序只核对材料身份、引文、判定规则及计算。

## 比较实施与推断边界

覆盖通过后，按照固定顺序启动 Graph 和强平面方法。每种方法使用对查询盲态的提取上下文、一次机械反馈，以及一个新的查询消费者上下文。消费者均可依据同一原文细化测量。Graph 的公开绑定从实际查询图的角色节点、关系、概念说明和原文证据产生，自由解释单独保留；未知不能通过自然语言描述转为已测得属性。

先执行完整分组的机械核对，再继续固定总体。机械核对检查实际查询图、来源引用、作用合并、绑定投影和匿名位置，不评价正确率，也不向方法反馈来源答案。全部方法输出及匿名语义审核完成后，才计算两项主要指标和预定联合收益门槛。

本结果证明本轮已具备预定的自动参考覆盖。它没有建立 TSG 增量、安全或功能性收益，也没有提供48个合格因果上下文。JCI 所需的真实随机分配、跨文本变量身份、条件支持及结构信息性仍需各自验证，不能用来源覆盖率替代。

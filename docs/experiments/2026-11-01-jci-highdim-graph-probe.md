# 多属性条件下的实际 JCI 结构检验

本轮固定使用已暴露真实结构实验中三个共同通过条件的批次0、重复0，各128项来源观测。完整单元名称、父源码身份、条件检验和惩罚目录固定在 `data/method/jci-highdim-oracle-20261101/graph-probe-plan.json`。研究输出为实际结构发现能否保留有用属性、同骨架定向是否改变候选集合，以及独立目标校准后的效应估计方差。本轮没有独立重复区间，属于已暴露材料上的机制诊断；没有新增实验模型调用或正式证据。

结构发现使用来源两个随机上下文、64项属性及二元结果，共67项变量。操作独立以0.5随机分配，来源平均结果在操作边际化后恰为原有 g，因此本轮估计平均结果预测图。不会将这张图解释为处理效应修饰图，也不将 Prompt TSG 关系作为因果边。

实际后端使用 pcalg 2.7.12 的 Anytime FCI，最大条件阶数2，保留 Possible-D-SEP 阶段，`pdsep.max=Inf`，稳定骨架、标准定向、JCI12、无选择偏差。两个上下文独立随机，因此预先删除上下文之间的边；不预先删除上下文与任何属性之间的边。结果不能引起已经测量的属性，时序知识用于定向。标准定向保留有限样本错误的可能，不声称保守 FCI 或完整识别。

条件检验使用现有离散分层条件随机排列，499次条件表抽样，每项显著性0.05。与 pcalg 保持相同边界：`p<0.05` 保留依赖建议，`p>=0.05` 接受本次分离判断。条件层内没有变异的表没有随机信息，其他有变异的层仍参与有效检验；全部层无信息时返回明确的支持不足状态。各方法共用相同查询种子及缓存，不用真值填充任何检验。

JCI 消费者以结果的相邻节点为起点，沿内部节点两侧都没有确定尾端的路径扩展。这样保留可能的碰撞路径预测信息，也保留潜在共同原因带来的代理变量；有限 PAG 仅提出预测建议，不能认证现实数据的充分集合。计算使用有序相邻节点状态遍历，允许额外保守包含，不进行全路径或全部属性子集枚举。背景知识骨架对照只保留相同邻接关系、随机上下文端点和结果时间端点；完整骨架对照将全部已发现端点改为圆圈。打乱对照只置换64项属性的建议，保留上下文身份。

直接上下文方法对每项属性分别检验与两个上下文的边际依赖，任一检验拒绝则建议保留。直接调整方法逐属性检验其与结果在给定两个上下文后的依赖。两种方法的支持不足属性均保留为不确定建议，并获得相同来源观测和随机上下文知识。真实集合提供模拟诊断，完整均匀惩罚方法不读取图。全部消费者始终保留两个上下文，所有属性始终存在于预测设计中。

来源基础 C 固定为父实验完整逻辑回归三折选择的参数。该选择不读取任何图；本轮不计算使用图后模型的来源交叉验证分数，从而不会把评价折结果带入属性发现后的调参评分。每个消费者使用共同四项有限结构强度：0、8、100、1000000。建议外属性的斜率惩罚乘以 `1+strength`；上下文保持基础惩罚，截距不惩罚。直接均匀方法对全部属性施加相同乘数。全部方法的20个结构强度与目标修正组合由同一独立目标校准选择，来源系数经独立加权 KKT 检查。

目标残差修正、随机效应修正和独立机制积分复用父实验函数。目标观测、角色、131072项积分协变量和随机种子与父单元完全相同。报告全部三项单元的完整点结果、属性覆盖、结构状态与查询数量；不能由三个点结果推断独立组件收益。来源结构没有通过诊断时，应依据具体属性损失和直接查询结果修订机制，不能把真值索引提供给 JCI。

预测集合的背景来自祖先图中的 Markov blanket；MAG 中还需要包含双向边连接的变量及其相关父节点。[Pellet 与 Elisseeff 的原始论文](https://proceedings.neurips.cc/paper_files/paper/2008/file/e2230b853516e7b05d79744fbd4c9c13-Paper.pdf)给出了相应结构。这里的圆圈扩展是本项目用于不确定 PAG 的保守候选规则，其拟合和目标表现仍需实测。

## 有效属性删除的确切位置

独立核验逐项检查18项未保留真实属性的最早分离查询，其中4项在没有条件变量的检验中被删除，14项在给定一项或两项属性／上下文后被删除。例如第二个分散信息单元的 X35，边际检验 p 为0.002，在给定 C1、X11 后变为0.424，并因此失去与结果的邻接。该属性在生成机制中仍直接决定结果概率。

对这18项查询还枚举了每个2×2条件表的全部超几何可能值，精确计算合并 Pearson 统计量的条件随机化概率。15项精确 p 仍不小于0.05；另外三项在499次随机抽样中达到分离边界，精确 p 分别为0.03420、0.04155、0.04856。增加随机排列次数可以影响这三项最早判断，但未执行精确检验下的后续整图搜索，不能推断最终恢复数量。

这些记录说明，主要限制已发生在来源结果的属性分离检验中。条件检验中失去依赖证据的属性被移出预测建议；增加结构惩罚无法恢复这些遗漏。详细计数表、查询条件和精确概率保存在独立核验的 `query-loss.json`。

# 完整命题范围与重复表达的表示比较

本开发比较使用 `tsg-scoped-binding-20261101/reference-packet.json` 的全部24个既有自然问题、固定目标及来源仓库。研究问题是：显式记录要求身份、来源角色和范围关系，是否帮助 Graph 流程完整绑定并移除目标，同时保留其他含义。当前原文参考准备已经完成，方法作者尚未接触两份参考内容。本比较产生新的表示、绑定与编辑，不修改历史输出和评分。

## 信息、方法与上下文预算

两种流程获得相同原文、固定目标和 REMOVE 动作，使用相同的完整命题语义规则。Graph 提取器记录逐字来源节点、完整命题身份、条件、例外、角色及显式关系；强平面提取器记录同等事实、条件、例外、来源和关系，允许交叉引用与重建结构。两者均可以识别全部重复表达，不能限制平面表示的信息。

每种流程使用一个隔离提取上下文和一个新的隔离绑定上下文。提取器每任务提交一次表示；绑定器读取完整原文、固定目标和自身表示，每任务提交一次逐字编辑列表。任何未知、无效或缺失输出均保留原分母，不根据质量修补或重新采样。Graph 绑定器沿实际节点与关系说明选择，平面绑定器自由使用其记录及原文。两者允许保留未知，禁止擅自改写目标或处理其他要求。实际 token 数量及模型随机波动未受控制，不评价计算效率。

本轮 Graph 为隔离上下文实际产生的结构化表示，编辑为其独立消费者产生的绑定。它测量表示流程，不将既有规范图形构造或逐字编辑函数的正确性当作自动语义准确性。Prompt TSG 关系继续属于语义关系。

## 固定测量

使用既有 `apply_prepared_edits` 实际产生修改文本，并以独立字符区间重建检查每个成功变换。逐字引用使用从零开始的 occurrence；无效或重叠区间、没有实际改变、未解决状态均不产生合格编辑。全部48个方法位置保留。

两个新的隔离评审只读取原文、固定目标、匿名实际编辑及已经冻结的原文参考与条件验证，不读取方法标签、表示、绑定理由、历史评分或彼此判断。每位分别判定完整目标转换、非目标含义保持、没有新增反向要求、没有解决无关歧义，使用 pass、fail、unknown 并提供逐字证据。允许评审发现参考遗漏或错误，此时保留 unknown 或失败并说明，不能为任何方法重写参考。参考 present 且条件审查 validated、机械生成成功、两位四项均 pass，才计为完整编辑产出。六项无固定目标及其他不确定项均保留在24项分母。

主要指标为 Graph 相对平面流程的完整编辑产出率差。开发增量门槛固定为至少20个百分点，且按仓库共同交换方法标签的双侧精确置换 p≤0.05。枚举八个仓库的全部256种交换，同一仓库任务共同交换；独立任务数保持24。检验依赖仓库间独立及零假设下成对标签可交换，不能支持总体或正式确认性声明。参考资格数量、绑定位置、机械失败、评审分歧及未知均作为诊断完整报告，不替代主要指标。

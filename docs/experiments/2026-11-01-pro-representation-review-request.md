# Graph 与 JCI 研究的进一步复核请求

请以研究设计和实际实现评审的角度给出一个能够执行的修订方案。用户明确要求保留 Graph 结构化表示和 JCI 类因果发现作为两个核心创新点；允许修改其他环节，但必须用公平、可独立归因的证据验证它们。不能削弱直接方法、遗漏负结果、事后改变门槛或把实现检查当成收益。请不要建议修改已经冻结、正在运行的实验设置。

## 活动研究与边界

当前是有界方法开发，正式协议仍未激活。七个阶段为表示、优先排序、假设冻结、干预与随机分配、测量、结果组装、推断报告。Graph 绑定完整要求并测量处理前属性；JCI 提出结果预测的结构建议，有限正则化和独立目标校准选择建议强度。目标随机分配结果进行效应修正，独立确认采用任务单位分母的 ITT。Prompt TSG 边属于来源语义，不是因果边；生成代码只提供独立安全和功能性结果，不成为主 PAG 变量或因果中介。

每项 Atomic 政策只编辑一个完整要求。Pair 和上下文修饰效应推断没有激活。安全主要指标是 oracle-evaluable secure-code yield；功能性、有效代码、Oracle 支持、unknown 和联合成功分别保留。完整功能规范只为完整功能性声明所需。新服务支出、受保护评价和正式角色分配均未授权；当前没有新增实验代码生成。

## JCI 已有证据与当前运行

原来的常系数或小型条件分离消费者，多次没有取得相对直接条件查询的独立收益；一次精确总体审计核对24个来源概率律及2816项条件查询，真实图与直接查询支持集合完全相同。后来改用独立辅助属性图、有限加权逻辑回归、独立完整目标修正。单父节点末端机制中，增加辅助属性至2048项虽然使 JCI 相对完整逻辑回归改善20.50%，相对强同骨架只改善3.48%；真实方向消费者相对同骨架的事后点改善也仅4.71%。按预定门槛停止新数据扩展。

新的预定模拟引入多父节点汇合及不同前驱长度。64项属性，包括八个汇合末端、24个前驱、24项有潜在共同原因的代理链属性、八项独立噪声；两个随机上下文在来源与目标改变分布。平均结果在主要机制依赖八个汇合末端，另有目标新增作用和结果依赖上游的负对照。依赖末端是明确的结果角色假设。

所有方法有512项辅助属性、128项来源结果、32项目标拟合、32项校准及64项排名结果。七项直接方法包括完整、稀疏、筛选、提升树、PCA、均匀和直接上下文建议。同骨架有六项几何建议，传播骨架有十项几何及扩散建议，均可使用相同邻接、路径、边际上下文信息和来源交叉验证；另有打乱建议。结构建议继续作用于同一个完整逻辑回归设计，保留零强度和公共完整模型后备。

真实方向可行性已执行并独立核验96单元，每机制32项学习重复。主要机制真实方向相对完整逻辑回归改善20.35%、稀疏15.24%、同骨架17.65%、传播骨架17.65%，十项主要比较均通过至少5%改善、51项家族 Bonferroni 校正区间下界为正、两个批次分别为正的联合门槛。目标新增作用的十项比较也通过。上游负对照相对同骨架损失20.32%、相对传播骨架损失19.43%。实际 JCI 搜索数量为零，不能据此声明 JCI 收益。

实际估计 JCI 的96项匹配实验正在运行：仅使用辅助属性的66节点 FCI-JCI12、稳定骨架、Anytime、无选择偏差、原生多数定向、骨架最大条件阶数三、499次条件随机排列。多数阶段实际条件阶数单独记录。代表单元已通过41215项查询重算、七项直接方法数据与行为精确匹配，以及 pcalg 原生 PAG 和祖先矩阵重放。全体单元完成同样核验后才评价。主要十项对照全部达到至少5%点改善且两个批次分别为正，才启动已经固定的新96单元验证；新验证仍要求全部十项通过完整校正门槛。当前设置和比较不得根据结果改变。

## Graph / Prompt TSG 已有证据

五个已暴露自然任务的独立提取和编辑流程，Graph 与强平面均5／5；四个受控来源的独立绑定也均4／4。另按固定来源规则取得24个公开 SWE-bench 自然问题、八个仓库，只读取问题文本等来源字段，没有读取参考修复、测试或提示。旧比较 Graph 15／24、强平面17／24。新的完整命题规则下，15项参考合格，Graph 与平面均12／24，逐任务成功判断相同，按仓库交换标签 p=1。所有未知保留原分母。

这些流程给两方法相同完整原文、固定目标和 REMOVE 动作。强平面可以保留全部事实、关系、条件、例外、交叉引用并重建结构。每种方法各一次隔离提取与一次独立绑定，输出冻结后再进行两位匿名自动评审。参考构造与条件验证由不同隔离上下文提供，但共享模型来源，条件验证读取首次标注，不是独立双重标注或人工金标准。参考内容未向方法制作上下文开放。

暴露出的关键问题是来源角色、完整政策身份、重复表达和混合语句。我们又在三个已知失败问题中，先做目标盲态的来源角色测量，再做条件审查，用规范 Prompt TSG 编译来源关系。新准备函数检查保留内容的 refers_to 路径：所引用来源与删除区间相交则 unresolved。89处引用、四张规范图通过独立机械核验，原16个受控版本继续可用。它只使用已表示关系，缺少边不证明没有依赖；不能声称语义或表示收益。

随后允许来源支持的非空替换，首次生成三个实际重写，两个新的匿名评审及独立 PowerShell 重建已完成：

* SymPy 原文两次出现“长度应为一，which 对应迭代器数量及 numpy 观察”。纯删除留下悬空指代，整句删除丢失事实。新重写为独立的迭代器数量和 numpy 数值观察，移除长度要求，两位均通过四项条件。
* Matplotlib 原文将阈值 >= 的请求、当前 > 的比较、可能造成不兼容的警告写在同句。新重写删除明确偏好和预期，把 >= 留在可能不兼容变更的条件性陈述中，保留事实和不确定性，两位均通过。
* Sphinx 原文先在实际示例说“base class is listed as A instead of B”，随后 Expected behavior 明说 should report B。新重写只移除明确 should 要求、保留实际对照。两位评审都认为剩余的纠正性对照仍完整表达目标要求，未通过。

Sphinx 尤其重要：编辑之前的目标给定原文参考和目标盲态角色测量，分别都把该对照保留为事实；编辑后的匿名评审却把它判为仍有完整规范作用。可能涉及单一角色模型不足、语境变化、评审提问框架或标注错误。现有结果不足以区分原因；不能选择更有利的一组评审，也不能把 facts 标签当作不具有规范作用的证明。本轮2／3只是已知失败的机制开发，没有给新平面流程相同额外信息与预算，不能与历史平面成绩作增量比较。

2. 如何设计公平且有足够改善空间的 Graph 对强平面实验？请说明相同信息和调用预算下的实际两个方法、独立参考、预定任务单位和数据划分、主要指标、合理实用阈值与统计规则、失效和 unknown 处理，以及真正检验“Graph贡献”的消融。不要简单重复同一24题直至通过，也不要通过限制平面信息或给予 Graph 独占评审来取得优势。
3. 如何将得到验证的 Graph 绑定和属性测量接到当前 JCI 主线，而不把模拟末端假设误当自然任务事实、不让 LLM 自评充当安全结果、不混淆功能性与安全目标？请区分可以使用既有已暴露资料完成的验证，以及需要新自然任务、实际生成或新授权的事项。

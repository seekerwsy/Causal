### 4.2 初始最低支持不保证重采样可用

考虑一个纯结构例子：一个效应、2 个等量文本实现、3 个来源层，每个“文本实现×来源”格有 k 个任务。当前重采样在来源层内抽任务，要求每格重采样后仍至少有 2 个任务。

单个来源的两个格总计 2k 个任务。一格被抽中的数量服从 `Binomial(2k, 1/2)`。三个来源同时保持最低支持的精确概率为：

`[P(2 <= Binomial(2k, 1/2) <= 2k-2)]^3`。

这里的重采样计数包含同一任务被抽中的重复次数，与当前实现一致。

| 每格原任务数 k | 总任务数 | 单次重采样保住所有格的概率 |
|---:|---:|---:|
| 2 | 12 | 5.27% |
| 3 | 18 | 47.68% |
| 4 | 24 | 80.35% |
| 5 | 30 | 93.69% |
| 6 | 36 | 98.11% |

该计算只检查支持，没有加入零方差、未知覆盖或多个坐标的失效，因此并不是完整重采样有效率，更不是实验功效。最小例子另用全部 `4^4` 个抽样序列穷举核对。

如果只是把最低有效抽样比例调低，就会接受更多只在部分抽样条件下可估计的情形；其区间覆盖率不会因此自动正确。增加抽样次数也不能改变上表的结构概率。

## 5. 解决方案：优先改哪里

### 5.1 先完成数据与目录的闭合

1. 完成当前表示与测量资格开发，随后才能用合格表示生成结果盲态的候选覆盖表。不得用开发集的特征频率推断正式总体，也不得在本次审计中猜测自然四格。
2. 对当前范围内缺目录覆盖的 54 个任务，评估能否在既定 21-CWE 范围内补齐查询与测量能力。新增查询需要相应独立资格证据；原来面向 13 个 CWE 的候选预留不能自动证明新增范围已合格。
3. 在读取 Discovery 结果前，按科学问题和结果盲态支持决定有限范围、固定 K、模型、文本实现数、来源层和 D/C 数量。现有单模型策略可保留；额外模型、可选基线和更多文本实现应在同一预算比较中证明必要性。
4. 保留必须的 Atomic Full/RD-only 与 Pair Full/No-Relation 比较。Pair 继续独立检查其自然四格，不要求先选中 Atomic 因子。
5. 若原目标要求当前缺失的领域，必须准备新独立自然任务。D0 只允许在冻结覆盖目标下进行一次 Discovery 补充，不能补 Confirmation。Confirmation 缺口应在完整角色与资格冻结前，沿用现有来源整理流程进行单独的前瞻数据准备，不能从资格或 Discovery 角色借任务。

不建议现在写死一个 D/C 比例：自然状态频率、Pair 四格和候选实际适用性尚未知。也不建议重用已经预留的 TLS 资格任务来让正式 TLS 样本数变为正数。

### 5.2 必须重新论证局部失效与解释门槛

建议前瞻区分三种情形：

| 情形 | 推荐处理方向 |
|---|---|
| 分配、来源、版本、必需结果证据缺失或损坏 | 保持阻断与修复/原分配重放要求；不能把缺失伪装为结果 |
| 单个坐标的支持不足、退化或区间无法构造 | 该坐标保留在原固定家族与固定 K 中，报告不可估计；研究如何让其不自动抹去其他坐标的信息 |
| 有完整有效测量，但 Oracle unknown 较高 | 保留原编码下可观察安全产出和覆盖率；把潜在安全、机制与实用成功的解释权限单独处理 |

第三项的依据是当前主结局本来就是 Oracle 可评价安全产出：有效未知已有预先定义的零产出编码，并非缺失结果。其变化仍需与代码有效率和 Oracle 覆盖变化分开解释。将未知门槛从全家族计算开关改成坐标级解释约束，是方法边界修订，不是降低 Oracle 标准；需同步修订规范和独立验证。

不能简单删去失败坐标后按缩小的家族重跑 max-T。若使用坐标级检验与多重校正，必须保留原冻结家族；不可检验坐标采用预先定义的不拒绝/宽区间状态。固定家族的 Bonferroni 或 Holm 可作为透明的校准参照，但前提是各坐标检验本身有效。Holm 的调整检验不自动提供与当前五状态相容的同时置信区间，区间规则必须一起定义。[Holm 原文](https://www.ime.usp.br/~abe/lista/pdf4R8xPVzCnX.pdf)

### 5.3 针对重采样失去小格，优先评估方法而非降低门槛

推荐评估“同一任务在所有策略中共享一个随机乘子”的任务单位联合重采样：在固定原分配与固定权重上扰动中心化贡献，保留部分任务重叠的依赖关系，避免每次抽样把小格整个抽空。多维均值的共享乘子 bootstrap 有既有理论依据，但对本项目小样本、分层固定权重、离散结局和零方差的适用性仍需专门校准；不能直接宣称替换后有效。[Chernozhukov、Chetverikov、Kato](https://arxiv.org/abs/1212.6906)

原数据本身不足、零标准误和未知解释问题仍需各自处理。不能给标准误加一个任意小数后继续，也不能把观察到恒定值当成总体完全确定。若未来采用重采样 stepdown 提高效率，也需同步确定与意义阈值及区间分类相容的规则；它不是当前数据稀疏的第一修复项。[Romano–Wolf](https://statistics.stanford.edu/technical-reports/exact-and-approximate-stepdown-methods-multiple-hypothesis-testing)

这些是需要比较和接受的候选方案；本次没有建立第二条活动分析路径。

### 5.4 把结论目标与当前资源对齐

- Atomic 的目标是冻结 Prompt 策略的目标臂对 no-op 效应。
- Pair 的主目标是风险差交互 `mu11-mu10-mu01+mu00`。组合有效可以与交互为零同时成立；不能将联合收益改名为交互。若需要对组合收益作推断，应事先增加并单独冻结相应次要家族。
- 当前 RQ2 是单个冻结 Discovery 划分上的描述性 Full-minus-Ablation Yield@K。不能把它写成选择器显著优越。若要跨 Discovery 总体推断选择器优势，需要另行前瞻定义重复总体/抽样单位及完整选择流程的不确定性；反复更换同一数据的随机种子不等于新增独立证据。
- 当前功能非劣与 Pair 响应类型仍受其独立冻结要求约束，不能为了更丰富结论而自动激活。

在现有容量下，建议首先保障有限科学问题的策略效应估计，并明确保留描述性的选择器比较；若坚持全面的选择器优越性与广域 Pair 主张，需要增加独立数据和设计范围，不能只改显著性阈值。

## 6. 阈值应如何决定

正式的 K、样本数、实际意义阈值、家族 alpha、目标功效、请求数量及完整预算尚未获准。测试夹具中的 0.05 意义阈值、0.9 有效重采样比例、0.2 未知比例或 0.01 工程功效目标，都不能直接当成正式设定。

| 参数或规则 | 当前建议 | 理由 |
|---|---|---|
| 角色隔离、去重、来源质量、完整证据 | 保持 | 保护独立性、分母与结果可追溯性 |
| 表示/测量资格准确性 | 先修实现与覆盖，不事后把失败记录改为通过 | 更弱的标签会改变候选和测量含义 |
| 家族 alpha | 依据预设错误风险确定，不为显著性而放宽 | 直接影响错误发现概率；两个主家族的控制范围需明确报告 |
| 实际意义阈值 epsilon | 依据安全产出的科学/实际价值先确定 | 不能从当前可检出的最小幅度倒推出“什么才有意义” |
| 假定真实效应 delta | 与 epsilon 分开，给出有依据的敏感性范围 | 检出非零与证明超过 epsilon 是不同目标；delta 接近 epsilon 会需要更高精度 |
| 目标功效 | 反映可接受漏检风险，不靠降低它解决容量不足 | 降低目标只更容易准许弱设计进入运行，不改变最终区间 |
| 每格最低任务数、折数 | 检查真实支持与估计稳定性，再前瞻冻结 | 代码允许的最低值不是科学上充分的样本量；不能把不存在的自然四格变出来 |
| 有效重采样比例 | 不先降低；先处理抽样结构并校准覆盖率 | 接受更多失效抽样不能保证有效推断 |
| 最大 unknown 比例 | 优先重审它控制的结论范围 | 可观察产出、潜在安全与实用成功的权限应分开 |
| 重采样次数 | 用尾部分位数精度和蒙特卡洛稳定性选择 | 更多抽样不能新增任务，也不能修复零方差 |
| K、来源层、文本实现、模型、可选基线 | 作为联合设计维度比较 | 会影响单位信息量、家族规模、稀疏小格和预算 |

建议在选择数值前，对实际支持布局做效应幅度—区间宽度—功效敏感性分析，明确研究能排除或检出哪些效应。[Lakens：样本量论证](https://online.ucpress.edu/collabra/article/8/1/33267/120491/Sample-Size-Justification)

## 7. 修订方案的接受条件与执行顺序

先完成下面的统计资格检查，再决定是否以某个候选替换当前推断法：

1. 全零、意义阈值边界、混合零/非零、稀有成功、全零/全一、局部未知等情形下的错误率与同时区间覆盖。
2. 完全共享、部分共享、分离以及同一任务在不同策略中采用不同文本实现的任务结构。
3. 与本次容量相当的小样本、稀疏来源层、不同文本实现权重和不同家族规模。
4. 同时报告家族/坐标不可估计率、错误发现率、有效区间覆盖、区间宽度、正负有意义判定功效和蒙特卡洛不确定性。不能仅报告成功的模拟，不能只检验所有坐标都为同一个强效应的场景。
5. 独立验证器重建任务权重、家族身份和结果。程序之间算得一致，不能替代统计覆盖率校准。

具体顺序为：

`完成表示/测量开发与覆盖方案 → 前瞻比较推断规则与设计参数 → 准备独立角色容量 → 冻结整合资格计划与角色清单 → 一次 QUAL_ACCEPT → 可选 D0 → Discovery 设计冻结 → 固定名额选择 → 实际任务分配功效复核 → Confirmation 冻结与执行`。

这一顺序不授权本次启动后续阶段。若资格或实际支持仍不足，应保留阻断原因，不能降低标准后把既有失败记录解释为成功。

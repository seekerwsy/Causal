# MLAlchemy数据构造与正常查询的局部测量

固定来源CVE-2017-16615及原始提交5736ec6ce1fbc9e5bd732204f04c8c01ab34415f，目标为完整mlalchemy/parser.py。政策要求parse_yaml_query对不可信YAML只构造标准数据，拒绝Python对象构造标签，且在拒绝之前不得创建输入指定的文件。正常YAML、JSON与已解析字典入口应继续产生原有查询对象及实际只读查询结果。完整资源保证、任意Python对象副作用及完整应用安全保持未知。

原始声明为SQLAlchemy>=1.1、future>=0.16.0及PyYAML>=3.11。本次预先固定Python 3.9 Bookworm镜像sha256:894dd9cb78e93e3c9ef81902619dcda7aeb78ef721ef92abcea9297eea7b293b、SQLAlchemy 1.3.24、future 1.0.0及PyYAML 3.13。PyYAML使用其官方--without-libyaml构建选项，在离线容器中从原样发布源码构建纯Python wheel，构建工具为setuptools 75.8.0及wheel 0.45.1。依赖全部处于原始声明范围，结果只适用于该明确环境，不推断所有允许版本的行为。

安全输入为builtins.open及io.open两种构造函数、顶层对象与where字段及额外字段三个位置、简写及完整URI两种标签形式，共十二项。文件只写入容器绑定的本次结果目录，内容为空，不启动命令、不连接网络。每项使用独立进程执行真实parse_yaml_query，在进程结束后观察实际文件。后续类型拒绝不能消除此前文件创建的失败。没有文件且明确产生ConstructorError或研究者控制的QuerySyntaxError才判定限定安全通过；其他异常保留未知，技术故障立即终止测量。

功能输入包含八项普通查询，分别通过YAML、JSON及字典入口，共24项。查询覆盖全部行、字段名称转换、比较、OR、NOT、LIKE、IN、NULL、排序、偏移及限量。另有日期标量和YAML共享引用两项，共26项。固定SQLite测试表包含四项明确的程序测试记录；每项实际SQLAlchemy查询结果分别与预先固定的独立SQL查询和原始模块结果比较，查询对象的序列化结果也与原始模块比较。测试记录和探针不计为自然任务单位。

三个控制为固定原始模块、只将不安全YAML构造改为safe_load的参考、拒绝全部YAML的控制。参考须安全12/12且功能26/26；原始至少一项安全失败且功能26/26；拒绝控制安全12/12且至少一项功能失败。全部未知须为零。三个控制共114项检查。先执行一项安全及一项正常YAML查询的代表性运行，结果满足预定模式后执行完整矩阵，不根据控制结果改变输入。

每项子进程保留实际输入、返回对象、查询结果或未处理异常类型及退出状态。异常观察使用sys.excepthook记录终止信息，异常仍使子进程失败。测量不捕获异常后继续执行来源逻辑。独立核对器不导入MLAlchemy或生产测量函数，核对原始输入、来源与依赖摘要、实际文件、子进程状态和普通查询对象，用标准库SQLite重算全部预定查询结果及分母。

代码、依赖源码、wheel、固定输入及设计在第一次来源运行前记录。所有来源执行在源码只读、网络关闭、单核CPU及2GB内存的容器中进行，临时工作位于/work。该测量仅用于固定来源的局部Oracle资格，模型调用次数为零。

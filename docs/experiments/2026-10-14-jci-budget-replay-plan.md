# 有限预算下的 JCI 候选选择重放

用户于 2026-10-14 授权本项实验。证据身份为 `POST_HOC_EXPOSED_BUDGET_REPLAY`，
正式协议保持 `SPECIFIED_DRAFT`。配置为
`data/method/jci-sharing-20261014/budget-plan.json`，在本项重放结果产生前固定。
原材料及其历史结果已经暴露；本研究不产生新模型调用或新确认性证据。

## 候选、角色与预算

候选为四个原操作家族 × 三项原表达政策 × 两个初始状态，共 24 项。
每项候选改变一个原政策状态。local 是完整限定命题的位置改变，example 是可选示例
的添加或删除，reference 是同一对象的指称替换。它们保留原表达政策身份。

原 D=400 项任务全部作为发现总体。发现信息只来自原 4000 次 `random_mixture`
物理请求，分配到 B、local、example、reference、S 的概率各为 0.2。
每个重放种子对这 4000 项请求进行结果不可见的排列，预算取嵌套前缀 128、512、1024。
八个预定排列共形成 24 项选择记录。所有方法共用同一前缀，完整配对标签和 coverage
结果不进入发现学习器。重复命中的任务不会增加独立任务数。

原 E=400 按家族和完整初始状态进行结果不可见的平衡划分，分别提供 C=200 项
确认任务和 T=200 项评价任务。每个家族各 50 项 C、50 项 T。C 中每项候选至少有
九项适用任务；固定抽取八项作为该候选的确认面板。面板在全部重放和方法间保持相同。

每项方法有三个选择名额。确认每个名额使用八项任务、Target 与 B 两组、每组四次
原生成结果，名义上限为 192 次调用。原请求的真实共享单独记录；空名额保留，
不重新分配预算。T 的共同完整测试面板为 200 项任务 × 五个原条件 × 四次生成，
共 4000 项逻辑分配，测试标签不用于发现、确认或部署决定。

## 七阶段

| 阶段 | 固定行为 |
| --- | --- |
| 表示 | 原来源状态 W、准备后的状态 X、随机分配 C、家族和独立安全结果 Y；冻结全部候选及角色。 |
| 优先化 | 对预算内真实结果拟合共同效果模型；FCI-time、JCI12、JCI123 查询 X 到 Y 的祖先关系，形成候选优先级。 |
| 假设冻结 | 固定预算、排列、学习器、查询、三个名额、确认面板、部署规则和六项主比较。保存全部发现选择后才向确认消费者传递 C 标签。 |
| 干预与随机化 | 重放原独立随机混合请求；每次只分配一项原政策。原结果及原分配不改变。 |
| 测量 | 保留原安全产出、有限功能、Oracle 支持、失败和 unknown 的端点定义。 |
| 结果组装 | 对所选名额读取固定 C 面板；正的确认安全产出均值决定是否部署，全部选择失败及非正名额保留。 |
| 推断与报告 | 在 T 的全部 200 项任务上独立评价，按任务汇总八项重放；按家族重抽取任务，报告候选、方向查询和收益变化。 |

## 共同效果学习与候选排序

Ridge 结果模型输入 42 项固定特征：初始状态、家族、准备状态、实际提示条件，
以及条件与初始状态、条件与家族的乘积。原输入全文完全相同的条件使用共同输入编码。
学习器读取每项实际请求的原成功结果，不读取未揭示的政策差值。

四折交叉验证按独立任务划分，五项惩罚共用同一任务等权预测损失。
训练及损失均使每项任务的全部已揭示调用合计权重相同。选定惩罚后，以任务外模型
预测各政策及 B 的结果，利用已知 0.2 分配概率形成任务层 AIPW 差值：

`m_policy(W)-m_B(W)+mean_requests[(I(A=policy)-I(A=B))*(Y-m_actual)/0.2]`。

完整输入相同的政策，其预先可知的期望差值为零；全部调用仍计入预算和任务分母。
每项候选的条件效果为其适用任务的差值均值，排序收益乘以该候选在原 D=400 中的
覆盖比例。目标组和 B 各不足两个独立任务时保留支持不足状态。

直接方法按正的排序收益选择前三项。图方法优先选择被 PAG 判定为 Y 的确定祖先的
要求状态，随后使用完全相同的排序收益及固定候选顺序。未知和非祖先提议保留资格，
不强制零效果。祖先判定仅提供假设优先级，不授予真实因果效果资格。

每项家族图只使用每个独立任务的第一项已揭示请求，保留其实际分配、X 和结果。
三种结构方法使用真实 conservative FCI、完整 Possible-D-sep 和相同 Monte Carlo CI。
模糊碰撞三元组持续传递给后续时间和 JCI 定向。要求状态是图查询对象；
生成代码及其结构不进入图形，X 不用于筛选 ITT 分母。

方向消融使用同一批 JCI123 图的 X—Y 邻接关系提供优先级。
直接下界使用 `效果均值-一个任务标准误` 提供补充对照。两项消融均使用相同预算、
名额及确认过程，不参与六项主要区间的增量判定。

## 确认、部署与评价

每项候选的确认值由固定八项 C 任务的 Target−B 安全产出均值计算，两套表达等权。
功能和支持分别报告，确认阶段的正值不提供功能保持或正式效果确认。
所选候选的确认安全产出均值严格大于零时才进入部署。对每项 T 任务，在适用的已选
候选中选择确认均值最高的一项；并列使用冻结候选顺序，没有候选时使用 B。
确认后不更换名额，不恢复其他候选。

主要结果为 T=200 上的任务等权安全产出收益。
每个发现预算比较 JCI123−直接方法和 JCI123−FCI-time，共六项主要比较。
每项 T 任务首先对八项重放取均值，5000 项家族内 task-unit bootstrap 对六项比较
分配 alpha/6，使用双侧 percentile 描述区间。重复排列和嵌套预算不作为独立实验。

同时报告发现候选变化、C 的正值名额数量、最终动作变化、方向判定变化、
未使用确认值时的候选部署收益、有限功能和 Oracle 支持。
只有方向查询变化、候选选择变化及独立评价收益改善同时出现，才支持本项材料中的
JCI 增量解释。所有预算及零值、负值、不足和失败均报告。

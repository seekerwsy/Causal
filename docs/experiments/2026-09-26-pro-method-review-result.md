## 1. 最重要的研究决定

Pro 不支持把“确定性识别审计→扩大 JCI 模拟”作为默认下一步。它建议把识别边界写成简短推导，暂停没有额外结构问题的算法扩量，将主要资源用于：**相同源语义、政策知识和预算下，TSG 与 Rich-Flat 是否产生不同且更好的完整政策绑定，并改善最终安全产出。**

这是对此前 `2026-09-26-next-method-study-plan.md` 的优先级修正建议，不是原方案已被执行或现行正式协议已被替换。

当前模拟确实显示有限的结构识别价值：同 pcalg、同数据的 causal/n1000 中，JCI1 将 X o→Y 变为 X→Y；latent_null 中 JCI0 已能得到 X↔Y，不能把它全部归给 JCI1/2。增加数据/变量、增加背景约束与有限样本搜索表现必须分开。PAG 箭头表示祖先关系信息，不自动等于原始 SCM 的直接边、正效应或政策价值。

对真实方法的对应调整是明确 S（语义范围）、A（随机分配）、M（前置任务属性）、X0/X1（文本要求状态）和 Y（独立结果）。利用随机化知识不意味着必须再运行图发现。A→X1 多由编辑定义给出，A 对 Y 的效果直接用 ITT，M 的修饰作用用条件政策效应；目前没有发现必须由 JCI 解决且会改变政策选择的额外结构问题。

确定性反例的核心证明是：若 X1=t(A)，两个结果方程 s(b+βX1+γZ+δU) 与 s(b+βt(A)+γZ+δU) 在观测支持上逐点相等，却可以在固定 A、单独 do(X1) 时不同。无需成百上千次模拟来验证这点；它不否定完整提示政策 ITT，也不能笼统否定 JCI 或完美干预。

Pro 建议取消 FCI 的“任何政策必须通过”的必要资格地位，保留未来固定预算下的选择增量对照。**正式 Full/RD-only 草案仍保持原义，改动必须前瞻作出。**

## 3. 端点和停止规则

Pro 建议用12–16个手写控制例区分安全性质、政策依从性和功能：固定程序argv、调用方控制首元素、shell拼接、显式sh -c、语法无效、删除目标调用、Oracle不支持的安全等价实现。不得因删除目标调用而获得真空安全；也不得仅因实现未照抄政策而判insecure。不支持形式应保留unknown。资格只覆盖这些已声明形态，不等于普遍准确。

通过前置并冻结绑定后，令 d 为 G/F 最终Target提示不同的任务数。对固定提示、相同生成模型配置且无会话/时序干扰的期望效果，有 |Δ_structure|≤d/N。Pro提议把15pp作为下一轮投资尺度：N32且d≤4时，上界12.5pp，停止相应下游扩量；d=0时无需生成来寻找表示导致的分布差异。

**该上界针对冻结提示集合的期望差，不约束有限随机生成的实际差值，也不证明所有TSG实现无用。**15pp必须在看绑定输出前选定，不能根据d调整。不能只保留d个不同任务而更换总体。

最终决策包括：测量不合格则停止安全实验；F/G信息不等则不能解释为图组织增量；明显负向则暂停；区间宽则不确定；F/G均好于Raw但彼此无可分辨增量时，收窄为语义整理价值，不削弱Flat来追求图优势。收益若来自invalid/unknown减少，不能直接称漏洞减少。自动抽取和政策发现能力留待独立实验。

## 4. 精度与 context

对每任务一对二元结果 D=Y_GT−Y_FT，q=P(D≠0)、δ=E(D)，Var(D)=q−δ²。Pro给的零效应附近正态规划量可复算：N32、q=.25/.50时95%半宽约17.3/24.5pp，约80%功效可检出的差异24.8/35.0pp。检测15pp，简单近似N≈(1.96+.842)²q/δ²，对应约88/175任务。它们是设计近似，不是小样本推断保证。

本晚不另开context主实验，保持 `BLOCKED_NO_FROZEN_CONTEXT_RULE`。未来可事前定义单一M：单调用 vs 多个需区分且含非目标调用的任务；两组用相同完整政策、端点和绑定程序。τ_m为组内Target−No-op，Δ_M=τ_1−τ_0；自然M的组间效应差不等于操纵M的因果效果。层内共同任务bootstrap，保留所有臂与重复；未来比较家族候选为{τ_0,τ_1,Δ_M}、双侧Holm .05。前置M未知保留总体，不进入已定义子群；安全unknown仍在所在臂分母。

N32每组16、q=.5时Δ_M的近似95%半宽49pp，说明不能把细分分析轻易塞入本晚。Pro的每组20下限同样只是开发建议，不是功效证明。精确名单、分配、bootstrap次数/种子、p值构造、退化规则、家族与精度仍需前瞻冻结，当前并未解除blocked。

## 5. Codex 对建议的必要核对与尚未解决之处

1. **复用现有路径。**协议第7节已有 `paired_task_effect_screen_v1` 的有界开发筛选，无需重建框架。正式Full/RD-only仍研究自然状态准入；本建议改为固定政策的表示绑定，不自动替代完整RQ1/RQ2/RQ4。
2. **主比较是新问题。**G-Target−F-Target是表示管线比较；它与当前政策级Target−No-op不同，需前瞻明确分配单位、估计范围与报告字段，不能冒充现有主政策效应。
3. **失败回退尚需决定。**Pro提出KEEP/不可渲染统一回退原文、仍执行全部槽位。它可定义一种完整管线，但不是现有四臂规则的当然默认。实施前要核对代码与协议，写清这是方法分配ITT还是固定合法政策ITT；不能临时混用或用失败筛分母。
4. **一份绑定输出限制结论。**每任务一次绑定主要评估这次冻结输出及管线随机性的有限实现；不直接证明跨绑定随机性稳定。作者辅助事实可能已显式给出大量结构，只能测试这些事实的组织和利用，不能支持自动发现。
5. **资格保持比例适当。**命令端点限定在源任务程序选择与宿主shell解释；不要求未纳入的文件权限、语言或所有漏洞资格。独立功能见证不足处保留unknown，不把安全研究一律绑定到完整功能证明。
6. **统计方案仍未完整冻结。**Pro给的主要bootstrap和未来Holm描述还不足以直接启用context：尤其p值如何构造、方差退化、缺失基础设施结果和比较家族边界需明确。未知软件安全与基础设施缺失不能混为一类。
7. **建议值不是现有资源事实。**32题、512请求、8小时和15pp均为规划建议。新自然任务库存未验证；本次没有启动A800或任何新的模型实验。

# 自然任务完整要求编辑流程结果

本轮按 [冻结设计](2026-11-01-tsg-edit-workflow-design.md) 完成五个已暴露自然任务的完整编辑流程。Graph 与平面表示分别由独立上下文提取，再由新的上下文根据各自实际表示提出逐字编辑；同一个 `apply_prepared_edits` 生成修改后的提示。两个新的盲审上下文只读取原提示、目标要求、动作和匿名修改后提示。

| --- | ---: | ---: | ---: |

| 平面表示 | 5 | 5 | 5 |

全部十个位置在目标要求转换、非目标行为保留、没有新增反向要求、没有解决无关歧义四项条件上均获得两位评审通过。独立 PowerShell 核对使用逐字位置重建全部编辑，核对原提示、编辑结果、匿名映射及证据引文。统计分母保持五个原任务，十个流程位置没有被当成十个独立任务。

本轮没有观察到 Graph 的完整编辑产出增量。任务来自既有开发材料，目标和局部编辑已经明确；五个任务全部成功不能证明更复杂自然问题中的普遍可靠性。每种表示只有一个提取上下文和一个编辑上下文，没有重复模型抽样，也没有控制实际 token 数量。评审虽然没有参与制作且彼此隔离，但共享模型来源，不能作为人工金标准。

本轮评价提示语义编辑质量，没有调用实验代码生成模型，没有测量安全代码产出、功能性或策略价值，没有使用受保护评价任务，也没有产生正式确认性证据。Graph 的独立收益仍然需要证明。

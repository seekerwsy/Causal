## 研究对象与约束

研究对象是对代码生成提示中的一项完整要求执行 Atomic ADD 或 REMOVE，独立测量代码结果，估计干预效应并选择需要确认的候选。

变量需要明确区分：

- W：准备上下文分配之前的任务属性。
- C：随机分配的提示准备操作或上下文标签。
- Z：准备之后、Atomic 处理分配之前测量的提示属性。
- A：随后随机分配的完整 Atomic 处理或原始提示。
- E：来源与目标环境。自然形成的 E 不自动具有随机分配性质。
- Y：独立测量的结果。生成代码提供测量对象，不作为主要因果图变量或中介。

Prompt Graph 保存要求、操作、资源、条件、否定、作用范围及引用关系。这些是语义关系，不能直接用作因果箭头。JCI 在另外的变量层面使用观测数据与随机上下文信息发现因果关系。

主要安全终点为 Oracle 可评价的安全代码产出。程序有效性、Oracle 支持、未知覆盖、功能性和安全与功能联合成功分别记录。观察到安全产出不能推出完整功能保持。任务资格和编辑资格在分配之前确定，分配之后的生成失败、编辑偏离和不可评价结果均保留在分配分母中。

统计独立单位为去重的原始任务。一个任务的全部改写、上下文版本和生成重复必须位于同一数据角色。同一任务增加版本不能被计为增加独立任务。

当前研究只允许 Atomic 单项要求干预；要求之间的 Pair 交互不在本次范围。组件消融的 Graph×JCI 比较与要求之间的 Pair 交互应保持概念区分。

## 真实提示数据与上下文准备状态

已有开发准备覆盖四个已暴露的受控合成任务、三十二份提示。两项准备操作涉及主操作段落位置，以及直接参数名称与明确资源角色引用。版本保持同一任务谱系，准备使用结果不可见的规则。

机械检查可以核对完整 Atomic 绑定、来源段落保留、设计概率和版本身份。已有网页 Pro 文字审查身份为有限文本审查；独立表示金标准、自动 Graph 准确性、生成程序行为及上下文因果辨识信息均尚未建立。

当前分工为 Codex 准备语义记录、Graph、绑定和编辑；本地 vLLM 模型只执行代码生成；独立程序测量结果。该分工不提供自动表示或自动绑定准确性的证据。同一作者准备的相同提示不能直接标为独立 Raw、Flat、Graph 处理。

LLM 可以辅助准备同一任务的版本。真实自然任务的补充需要独立来源，不能把同一任务的改写或合成版本计为自然独立任务。任务获取与新代码结果、选择器排名保持隔离。

当前没有授权新增付费提供方调用、使用受保护评价任务或启动正式确认性研究。本次请求是网页模型的方法审查。

## 已有方法与早期诊断

既有方向方法用 Graph 定义可比较的属性，随机准备上下文帮助 JCI 提供方向，方向建议跨环境共享的预测变量。结果预测器使用共享部分与目标环境偏差修正，目标修正保留完整属性。独立目标校准选择模型，随机化残差修正估计效应，按绝对效应提名，再独立双侧确认。

早期祖先筛选不能认证跨环境不变性。非祖先代理变量仍可能帮助预测；根据祖先名单删除变量可能增加方差。

上一轮之前的环境分离与聚合开发检查复用了已暴露结果，十二次运行中结构方法与强直接聚合方法均确认 22/24 个位置。48 次结构搜索中四十次返回可评价图，39/40 张可评价图中环境变量没有其他邻接；640 项分离建议中 392 项不被声明真实图形支持。该结果提示上下文信息弱、检验支持与结构不确定性的问题。重抽样稳定性本身不能证明图形正确。

另有机制在混合处理后的结果分布中发生作用抵消，给定处理的结果机制仍然改变。不能把两臂平均结果稳定、完整条件结果稳定和处理效应稳定混为一谈。

## 2026-10-31 已完成的真实结构实验

研究身份为 NON_CLAIM_PROSPECTIVE_ORACLE_FEASIBILITY。全部规则在新结果产生之前固定，执行声明的结构因果模型模拟，没有运行估计 JCI，没有调用代码模型。

八种机制：无关上下文、混杂代理、多靶点、全部相关、弱上下文、作用抵消、上下文分布不变、属性不可观测。

核心为混杂代理、多靶点。每种机制有来源样本 256/1,024 与目标样本 32/128 的四种组合，每个组合两个独立批次、每批十六次重复，共 256 次核心运行。其余六种机制各八次检查，共计 304 次运行。

这轮来源与目标只改变 C1、C2 的分布：来源均为独立 Bernoulli(0.5)，目标分别为 0.75、0.25；无改变条件仍为 0.5、0.5。其他生成机制相同，完整密度比已知。潜变量 U 不提供给任何学习器。

基础二元机制为：

```text
P(X=1)=0.15+0.6*C1+0.05*W
P(N=1)=0.05+0.65*U+0.2*C2
P(Y=1)=0.36+0.1*X+0.12*U+0.02*W
       +A*(b+0.1*(2*X-1)+0.1*(2*U-1))
b=[0.12,0.06,0,-0.10]
```

真实图形提供最小充分预测集合，不提供真实系数或效应。混杂代理条件中充分集合包含 X、N、C2，固定条件变量包含 W、A；因此不会把非祖先 N 自动删除。属性不可观测条件对全部方法共同禁止 X。

来源两折交叉拟合，每个处理分别拟合结果预测器。真实结构消费者只在最小充分集合与完整集合之间进行 Ridge 留一选择。其他方法为完整特征 Ridge、完整特征 Elastic Net、梯度提升和全部属性子集搜索。线性预测器使用中心化二元属性、全部两两乘积及常数项。全部方法获得相同数据、上下文标签、分配概率与修正公式。

令 d_m(z)=m1(z)-m0(z)，r_m=2*(2*A-1)*(Y-mA(z))，来源密度比 w=q(C)/p(C)。估计器为：

```text
tau_hat = mean_T(d_m)
          + lambda*mean_S(w*r_m)
          + (1-lambda)*mean_T(r_m)
n_eff = nS / product_j[2*(q_j^2+(1-q_j)^2)]
lambda = n_eff/(n_eff+nT)
```

来源预测为折外预测，目标预测为两折模型平均。目标结果不参与预测器拟合和超参数选择。该模拟的完整概率修正性质依赖其明确的机制与分布变化条件，不能直接外推至一般跨环境机制改变。

每次从四个候选按绝对估计效应提名两个，独立确认每个候选使用 32,768 个配对模拟任务。通过抽取差值类别的精确多项分布充分统计量实现模拟。双侧 Hoeffding 区间完全位于 +0.04 以上或 −0.04 以下才确认方向。确认负效应计为有效发现，不能计为安全收益。

核心结果如下：

| 方法 | 确认数量 / 512 | 效应估计均方误差 |
| --- | ---: | ---: |
| 真实充分集合与 Ridge | 459 | 0.0035208847 |
| 完整特征 Ridge | 459 | 0.0038715629 |
| Elastic Net | 471 | 0.0031576359 |
| 梯度提升 | 456 | 0.0037569613 |
| 全部属性子集搜索 | 465 | 0.0036579733 |

真实结构相对完整 Ridge 的误差降低 9.06%，开发性校正重复抽样区间为 [2.47%,15.19%]；相对 Elastic Net 的误差增加 11.50%。Elastic Net 在八个核心条件中均具有更低的均方误差。

四个平均确认数量差异依次为 0、−0.046875、+0.01171875、−0.0234375；全部有限样本同时区间均包含零。真实结构与 Ridge 有十三次多确认一个、十三次少确认一个。真实结构与 Elastic Net 有七次多确认一个、十九次少确认一个，其余 230 次数量相同。

4,096 次核心预测器选择中，真实结构选择完整集合 424 次，其余选择最小充分集合。直接子集搜索经常选择更小的集合，例如只保留 X、只保留固定 W，或保留 X、N。该频数是事后描述，不能单独证明收益原因。

原扩大门槛要求相对全部四个直接方法同时达到平均确认增量至少 0.1、校正下界大于零、两个批次增量均正，以及均方误差降低至少 5% 且开发区间下界大于零。因此原判定为 ORACLE_VALUE_NOT_ESTABLISHED_DO_NOT_EXPAND。

全部 304 次运行、6,080 项效应估计与最终判定通过独立验证，47 项默认检查通过。这些是计算正确性和声明模拟内的证据，不构成自然任务上的 Graph 或 JCI 收益。

## 拟议方法修改

### Graph 驱动准备与测量

Graph 显式保存要求与操作、资源、条件、否定和作用范围的绑定，用于定义完整 Atomic 编辑、限定可改变表达、测量版本间一致的处理前属性。独立审查者在不知道结果时评价绑定、语义保持与属性误差。

### 随机上下文与 LLM 版本扩充

按冻结规则准备表达位置、资源指代和条件展开等语义等价版本，独立随机分配准备操作，之后再分配 Atomic 处理。检查任务内可测属性变化、共同支持和非目标语义保持。

不假定某项操作只有单一已知靶点，不提前禁止 C 直接影响 Y。请审查这些操作能否提供因果辨识信息，哪些属性需要改变，是否存在不可辨识或忠实性失效的问题。版本增加与独立任务增加必须分别处理。

### 因果结构约束共享预测

JCI 的部分因果图提出共享属性集合 S，模型形式为：

```text
m_{a,e}(z)=g_a(z_S)+r_{a,e}(z)
```

候选集合内部允许系数收缩和部分属性不被使用，目标修正使用全部可观测属性，惩罚保持有限。图形建议由方向、分离关系和环境数据产生；祖先身份不能直接认证共享，非祖先代理不能被硬性删除。独立目标校准决定共享强度。

### 校准目标与效应精度一致

既有方向验证使用两臂平均预测 g=(m0+m1)/2 的目标校准。在目标等概率随机处理、固定预测器与独立任务下，Gamma=2*(2*A-1)*(Y-g)，因此 Gamma^2=4*(Y-g)^2。上一轮真实结构检查则使用来源逐处理臂预测误差选择模型，目标存在差异。

拟修改为以最终修正效应估计器的方差选择候选。对固定预测器、固定 lambda、独立来源与目标评价样本，上述混合估计器的方差为：

```text
V(m)=lambda^2/nS * Var_S(w*r_m)
     +1/nT * Var_T(d_m+(1-lambda)*r_m)
```

请核对公式、必要条件和交叉拟合下的适用范围，并说明独立校准、目标修正、模型选择、效应估计如何分配数据。有限样本不能直接忽略模型学习误差、折间依赖或自适应选择。

尤其请检查：如果新模拟改为代理机制跨环境改变、结果机制改变或未知自然环境迁移，q(C)/p(C) 可能不再是完整密度比，条件处理效应也可能改变。此时当前来源残差混合公式能否继续保持目标效应识别？目标数据中存在随机处理分配并不自动保证加入来源修正仍然无偏。请明确需要哪些额外假设或修改，避免为了迁移收益破坏识别。

### 有结构歧义的模拟与边界

核心机制拟同时包含真实因果属性与来源中相关、目标中代理关系改变的属性，随机准备上下文应帮助区分这些解释。无 JCI 方法仍获得相同上下文标签、属性、观测和分配信息。

同时保留代理稳定、上下文弱、多靶点、直接上下文作用与结果机制改变等边界。机制和参数在新结果之前固定；真实最优候选用于诊断改善空间，不进入学习。请明确如何使研究检验真实的信息利用问题，并避免人为削弱对照、依赖真实角色标签或只保留有利机制。

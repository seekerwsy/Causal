## 方法问题与证据

1. **发现价值与实际改善价值不同。**原规则选择最大绝对规范方向效果，并对全部任务执行翻转。local 的发现价值点估计为 +0.03875，实际翻转后的安全产出差为 -0.02625。正发现价值不能解释为安全改善。这是定义能够直接证明的问题。
2. **结构信息没有改变本轮动作的空间。**local 的最低评分 0.0734166667 高于 example 在所有允许图支持下的最高评分 0.04274404762。H7–H9 的精确零来自相同动作及请求系数；任何允许的支持向量都无法改变选择。这个结果不能检验结构算法在其他决策规则中的价值。
3. **三项普通政策检验的范围有限。**local、example、reference 可以研究规范保持下的表达敏感性。固定政策、唯一目标及唯一绑定没有检验完整安全要求的候选发现或复杂绑定。普通内容实验的价值可以保留，完整要求发现贡献需要对应实验。
4. **表示流程差异与下游生成处理不同。**TSG 与 Raw 在 300/400 项任务的两套 local 全文相同。H10 净差全部来自 TSG 未合格、Raw 合格的 34 项；该证据描述准备流程的整体可用性。双方合格组内部仍有正负变化，不能宣称全部表示等价。无损 Rich-Flat 与图具有相同信息上限时，增量应具体体现为算法、成本或预算内成功率。
5. **安全产出同时受到工具义务与测量覆盖影响。**tar 对 H1 的贡献为 -0.04625，直接违规变化为零；功能与 unknown 同时增加。grep-096 有合法逐文件调用的覆盖缺口，find 与 git 案例存在真实程序错误，tarfile 案例没有履行外部 tar 义务。各类 unknown 需要分别解释。目标访问观察尚不能证明完整工具操作、全部合法数据通路或任意输入安全性。
6. **正预测规则没有建立正政策价值。**零阈值与最大预测值选择缺少估计误差控制；共享 baseline 使同任务三个差值相关。按任务分折保护独立单位，但预测 MSE、收益校准和最终政策价值具有不同目标。旧普通政策标签无法支持新增完整安全要求的效果预测。
7. **自然来源与总体推断仍缺证据。**自然来源身份、保护冲突、近重复和候选可构造性需要明确区分。旧规则下的零资格及 H12 未执行保持原身份。固定面板的生成重复与区间不覆盖新来源抽样、重新准备和测量系统误差；非恒等区间包含零不能建立等效性。

## 本地补充核验

当前十六项特征是初始状态三项、实际状态变化三项、政策 one-hot 三项、家族 one-hot 四项、重复对象数量两项、编辑长度比例一项。加性 Ridge 没有明确的家族与政策交互。在同任务的候选预测差中，家族、初始状态和对象数量的共同贡献相消；状态变化与编辑长度仍能改变排序。这个结构限制不能解释为全部任务必然选择相同政策。

实际 `safe-decisions/learner.json` 中，两个对象数量字段的均值均为 2，`retained` 均为 false，实际选择的惩罚为 0.1。这两个常量字段没有影响本轮拟合。重复非恒定字段可能改变 Ridge 有效惩罚的论述需要保留这一条件。

实际 `safe-decisions/identity.json` 引用的分析 manifest SHA-256 与原冻结分析完全相同：`0c4b3f132d6566b45058b4a0160ecc276908c3df61883cf85141a361ff131bf1`。原分析冻结时间为 2026-10-04，观察器修复没有重新建立全部 D 的新端点训练标签。当前学习目标继续包含原观察边界。

Pro 补充指出，同 baseline 全文的候选应具有零实际编辑收益，当前政策 one-hot 却可能产生非零预测。对全部 400 项开发选择记录按 `case_id` 连接原任务、检查两套表达的实际 `prompt_hash` 后，发现 20 项选择了非 B 政策，但两套最终全文均与 B 相同。其中 grep 12 项、git 8 项。检查要求任务和全部提示身份存在，排除了空值相等造成的计数。

## Pro 对选择器实现的补充判断

候选预测可以分解为任务共同项与候选变化项。家族主效应会影响是否越过编辑阈值；政策、实际状态变化与编辑长度决定未限制范围的候选相对排序。实际状态变化已经隐含政策与目标初始状态的交互，模型仍然具备这一条件化能力。缺少家族与政策、家族与实际状态变化的交互，则无法直接表达相同候选属性下的家族特异排序反转。

预测范围限制是单调函数，不能直接反转严格排序，但上界饱和可能制造并列，并由固定政策顺序改变最终选择。这种变化需要与真正学到的家族排序区分。其实际发生数量尚未核验。

在独立验证标签对冻结端点无偏的条件下，差值 MSE 在期望上仍有合理含义；噪声及共享 baseline 本身不能直接证明选参错误。共享 baseline 在候选标签差中消去，任务共同收益水平与候选相对差异则进入 MSE 的不同分量。较低 MSE 不保证有限样本中的政策价值更高；不受惩罚的截距也使较强正则化无法自动保证更少编辑。

非常量重复字段在固定正则参数下会降低该方向的有效惩罚；本轮两个字段为常量并被删除，所以该条件性结论不解释本轮拟合。蓝图计数是生成前设计信息，其使用没有自动构成结果泄漏，但自然来源上的对应特征及抽取误差仍需建立。

## 外部建议与当前研究状态

Pro 建议分别检验自动来源准备和共同正确候选上的选择贡献：前者比较来源绑定、候选覆盖及流程成本；后者保持候选与全文相同，比较固定政策、文本特征及关系特征的政策价值。它还建议设置独立校准集，按实际价值选择编辑阈值，并在生成前核验方法动作分歧和统计精度。

Pro 对 JCI 提出的用途是来源特征的条件共享约束，并以完整特征学习、同子集空间的直接筛选及 FCI 作为对照。这个用途没有执行；变量定义、分配与候选可用性的关系、结构假设以及统计规则仍需事前完整指定。

原文建议将有限安全、有限功能及工具义务的联合产出作为新设计的主要结果，并提出自然来源数量和重复次数。它们属于待研究决策的建议：当前规范的主要安全结果与联合成功仍分别保留；来源规模的可获得性尚无证据；新方案没有成为冻结协议。当前 `phase-context-policy-v3` 保持 `SPECIFIED_DRAFT`，本次审阅没有启动新的正式实验。

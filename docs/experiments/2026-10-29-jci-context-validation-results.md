# 随机编辑环境机制验证结果

## 执行身份与材料

执行配置为 `configs/jci-context-validation.json`，证据身份为
`NON_CLAIM_CONTEXT_MECHANISM_SIMULATION`。六种机制分别完成十六次独立模拟，共 96 组。
每组包含四项候选，每项使用 256 项 Discovery data、128 项 Calibration selection data、
128 项 Calibration ranking data 和 1,024 项独立确认任务；各方法提名两项。
实用收益门槛为 0.04。完整规则见 [机制验证设计](../jci-context-validation.md)。

本研究使用声明的概率模型，没有调用代码生成模型，没有读取新的自然任务评价结果。
模拟为四项候选保存共同的确认潜在结果，各方法仅使用其已固定的两项提名。每个方法
分配的发现与校准预算为 2,048 个逻辑结果，确认预算为 4,096 个逻辑结果；真实调用数量
为零。准备提示、审查语义和自动构建 Graph 的成本没有被测量。

## 随机分配修正与共享资格

对六种机制、四项候选逐项穷举任务属性、潜在变量、处理、环境和版本分配后，错误
预测模型经过完整版本积分和随机残差修正的最大均值误差为 `3.3306690738754696e-16`。
该结果验证本次有限模型中的估计恒等式，不证明真实数据已经满足其实施条件。

精确总体查询在共享成立、效应抵消和接近门槛三类机制中，认可包含 Z1 的条件集合。
遗漏措辞直接影响结果、潜在混杂和完全没有重叠三类机制没有合格共享集合。
完全编码环境的 Z1 条件查询均被判为缺少支持。没有包含 Z1 的查询仍可能因为统计能力
不足而没有拒绝错误共享建议，表明重叠检查不足以证明共享成立。

## 固定两项提名的确认结果

表中数值为每次模拟中平均通过确认的候选数量，取值范围为 0 至 2。

| 机制 | JCI | 直接条件不变性检验 | 相同预算全部用于目标环境 | 真实最优候选 |
| --- | ---: | ---: | ---: | ---: |
| 共享成立 | 0.8125 | 0.8125 | 0.8750 | 0.9375 |
| 遗漏措辞效应 | 0.9375 | 0.9375 | 1.1250 | 1.1250 |
| 潜在混杂 | 0.8750 | 0.9375 | 0.8125 | 0.9375 |
| 没有重叠 | 0.8750 | 0.8125 | 0.8750 | 1.0000 |
| 异质效应抵消 | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| 接近实用门槛 | 0.0000 | 0.0000 | 0.0000 | 0.0000 |

全部十八项预定比较的近似配对 t 区间均包含零。十六次重复不能支持精确的比较结论，
全零差异产生的退化区间也不能证明总体等价。

JCI 与获得相同随机分配知识的 FCI 在全部 96 组中选择相同候选。两个名称使用相同
算法和先验知识，这一结果符合实现等价关系。当前结构消费者仅使用分离集合，定向
结果没有产生独立的共享建议。因此，本次设计尚未建立 JCI 定向信息改善决策的通路。

共享成立时，JCI 效应估计的均方根误差约为 0.1378，全部预算用于目标环境约为 0.0788。
真实共享信息在当前样本数量和结果模型下也没有带来稳定的提名收益。当前检查没有
支持扩大真实模型实验规模的增量证据。

## 确认规则的精确检出能力

看到上述结果后，另行执行
`POST_HOC_CONFIRMATION_POWER_DIAGNOSTIC`，保留原模拟结果及其门槛和预算。
任务内处理与对照差值服从三项分布，程序对确认阈值计算精确尾部概率。

| 真实平均收益 | 实用门槛 | 确认任务数量 | 通过确认的概率 |
| --- | --- | ---: | ---: |
| 0.18 | 0.04 | 1,024 | 97.11% |
| 0.10 | 0.04 | 1,024 | 3.48% |
| 0.10 | 0.04 | 4,096 | 82.94% |
| 0.055 | 0.04 | 65,536 | 82.82% |
| 0.045 | 0.04 | 1,048,576 | 99.75% |

后两项数量是固定幂次网格上的首个合格数量，不是最小样本数量。数值只适用于本次
结果分布及同时 Hoeffding 规则，不是对真实模型任务数量的建议。
效应抵消和接近门槛两类机制的确认产出为零，不能用于否定候选提名方法。
后续协议必须先依据目标效应与门槛之间的距离、任务差值方差和多重比较规则确定预算。

## 实施状态与研究缺口

- 已实现并执行：实际保守 FCI、精确总体和真实图形诊断、共同数据与预算比较、完整
  版本积分、独立模型选择与提名、随机分配修正及独立确认。
- 已独立数值验证：96 组模拟、7,461 条条件检验、模型拟合、分数、选择及确认结果。
  另外验证了 24 项确认能力诊断和 50 个尾部概率。
- 尚未实施：自然任务上的自动 Graph 构建审计、信息相同的 Flat 表示比较、完整 Atomic
  要求绑定审查、两个真实编辑环境的结果支持验证、LLM 干预扩充和新模型生成实验。
- 尚未证实：Graph 表示优势、JCI 独立增量、自然任务迁移、功能保持及安全与功能联合成功。

LLM 生成的同一任务改写和代码重复可以增加版本覆盖或降低任务内噪声，不能增加独立
原始任务数量。合格上下文需要在同一目标条件单元中保留编辑环境变化，并实际获得
来自两个环境的独立结果。历史表达政策数据缺少相应分配和版本记录，不能补写这些信息。

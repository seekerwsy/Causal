状态：**已执行开发诊断；没有运行新的模型抽取、候选生成或代码实验。**
本轮检查修正图的条件和对象之后，候选与编辑接口能否形成可研究的单因素比较。
不改论文、生产算法、资格标准或历史评分，不增加回归测试。

## 材料和判据

固定使用三个已暴露自然任务，不读取代码结果，不接触保护集：

| 任务 | 自动图来源 | 来源审定参考 | 重点 |
| --- | --- | --- | --- |
| 图书查询 | `requirement-composition-locality` 保存的实际抽取 | `structural-readback-diagnostic` 的正确叶子结构 | 返回分支的条件和直接目标 |
| 文件共享消息 | `atomic-records-validated-delivery` 保存的实际抽取 | `binding-coverage-transfer` 的正确结构，未用有争议的合取容器 | 无法完成任务时的异常条件 |
| 下载路径 | `open-tsg-effect-development-v1` 保存的历史抽取 | 本轮按原文区分目录限制与带条件的 PermissionError 要求 | 已表达、可定位和可独立移除是否不同 |

参考由 **Codex 开发作者核查**，不是独立人工资格。前两个参考只支持已核查的局部意义；
下载参考保留原图其他事实，不宣称完整金标准。自动图来自不同历史版本，下载图仍是旧的
source-only 输入，不能充当当前完整 system/user 抽取的准确率样本。原文和旧实验均不修改。

固定的来源绑定探针调用现有 `candidate_request` 和 `compile_candidate_proposal`，
只运行到草案边界。普通返回和异常行为属于非目标功能，提交它们是测试接口，不是批准
安全干预。`PENDING_SEMANTIC_REVIEW` 不是语义批准或正式候选。

下载任务另调用 `bind_task_hypothesis` 和 `render_task_hypothesis`。正向表达状态由
来源核查明确提供，不是新 LLM 范围判断。编辑探针使用原图概念，不冒充新候选词表下的
重新抽取或资格验证。本轮没有执行自动候选发现全流程。

## 实际结果

| 任务 | 自动图的接口表现 | 修正局部意义后的表现 | 解释 |
| --- | --- | --- | --- |
| 图书查询 | 两条返回要求均无结构条件，各挂到三个操作；六条依赖绑定进入待审核草案 | 两条要求只约束返回并保留条件；均被独立条件上下文检查拒绝 | 结构合法不足以排除来源语义错误；正确表示也未必满足候选接口 |
| 文件任务 | 异常要求没有结构条件，挂到三个操作；三条绑定进入待审核草案 | 异常要求约束对外异常行为并保留条件；被相同检查拒绝 | 普通异常约定应保留，不能为了获取候选而删除条件 |
| 下载任务 | 目录限制与 PermissionError 共用概念；ADD 因已表达被拒，REMOVE 因多个证据节点被拒 | 区分完整谓词后可形成目录因素草案；ADD 仍被拒，机械 REMOVE 能删去安全说明 | 正确图和成功删句不足以证明有效的要求移除 |

这些绑定共享三个任务，不能当作独立试验计算准确率。修正前后结构数量不同，草案数量
变化也不是候选覆盖或方法收益。本轮批准干预 **0**。

下载编辑实际只删除：

> Security Policy: ensure that the requested file is within the download directory to prevent accessing files outside the download directory

输出仍完整保留：

> raise a "PermissionError" if the file is outside the download directory

以及 `download_dir` 是允许下载文件目录的上下文。因此不能只凭删掉一处安全说明就把
目录限制判为 absent。保留的异常约定明确要求拒绝越界路径；同时删除它又会改变应保留的
错误行为。本轮不批准这一 REMOVE，也不重新命名因素后计作成功。这里判断的是 prompt
要求及其语义重叠，不推断生成软件是否实际安全。

独立于编辑器摘要的字节核对确认：输出恰好等于原文减去安全说明，其他文字未改。
这证明删除位置，没有证明 `expected_feature_states=absent` 语义正确；该字段只是预期。

## 对瓶颈的修正

1. **普通功能要求不能用来证明发现了可编辑安全因素。** 图书返回和文件异常必须正确保留，
   但本来就不应随意移除。这两例暴露条件接口的能力边界，尚未证明它误拒合法安全候选。
2. **明确的安全要求也未必能够独立移除。** 应检查同义表达、其他要求的蕴含及其与必须保留
   行为的重叠。单节点、单段文字和成功渲染都不能证明要求从“表达”变成“未表达”。
3. **不能删除独立上下文检查来提升通过率。** 下一步先找一个来源上确实可独立编辑的安全
   因素，固定原始状态、修改后状态和非目标不变量；若正确图仍被接口阻断，再修那个具体问题。

本轮没有获得总体抽取稳定性、自动候选发现有效性或图结构增益证据。因此没有继续扁平
表示比较、扩大调用或增加审核角色。下一项最小实验只需贯通一项合法 Atomic 比较：
先核实目标要求能变化而非目标要求不变，再比较自动图与审定图的定位和编辑结果。

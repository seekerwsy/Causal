# 利用结果测量之前的属性数据发现 JCI 结构

## 研究问题与数据条件

本设计检验可独立取得的提示属性观测，能否在代码结果预算有限时提供有用的因果结构。结构发现只读取随机上下文和属性；所有预测方法获得相同属性观测、上下文身份与结果。JCI 的候选变量建议需要与直接利用上下文、无监督降维和结构消融比较。自然任务尚未建立这些属性关系和上下文资格，本设计的验证范围限于明确概率机制。

来源属性数据有512项独立任务，不测量结果；来源结果数据另有128项独立任务，同时测量属性和结果。总来源任务数量为640，结果预算128。全部方法均得到这640项属性观测及同一组128项结果，JCI 没有额外任务或结果。目标拟合32项、校准32项、随机效应排序64项，总目标结果预算128。目标结果不进入结构发现。

结构从512项结果未测量任务中发现，独立于来源结果及来源交叉验证。因此来源三折评分可以使用固定结构，不会读取评价折结果。所有无监督表示同样只从该512项数据拟合。两个随机上下文在来源独立以0.5分配，在目标独立以0.8、0.2分配。上下文早于属性，Atomic 操作晚于全部属性，以0.5独立分配；重复版本不增加独立任务数。

## 三种固定机制

64项二元属性包含八条各有六项属性的关系，以及16项独立 `Bernoulli(0.5)` 无关属性。每条关系有一个独立 `Bernoulli(0.5)` 潜在变量 U。两个上下文交替影响八条关系。每条关系按以下顺序生成，伯努利噪声相互独立：

- H 的成功概率为 `0.05+0.30*C+0.60*U`。
- M 的成功概率为 `0.20+0.60*H`，X 为 `0.20+0.60*M`。
- N 的成功概率为 `0.05+0.90*U`，K 为 `0.20+0.60*N`，L 为 `0.20+0.60*K`。

因此 C 经 H、M 影响 X；潜在 U 同时影响 H 和 N。C 与 N 的共同邻接 H 是碰撞点。无向可达性不能据此断言 C 影响 N、K 或 L。每个单元独立置换64项属性位置，实际方法不能根据列序识别 H、X 或 L。

三个机制在新观测之前全部固定：

| 机制 | 来源平均结果 g | 目标平均结果 g | 作用 |
| --- | --- | --- | --- |
| 下游属性决定结果 | `expit(sum(2*X-1))`，八项 X | 同来源 | 检验沿已发现方向找到下游属性的有限样本价值 |
| 目标新增作用 | 同来源第一行 | `expit(0.7*sum(2*X-1)+0.8*(2*L0-1))` | 检验目标偏差修正，来源结构没有包含新增作用 |
| 上游属性负对照 | `expit(sum(2*H-1))`，八项 H | 同来源 | 检验优先建议下游属性的假设失效时的结果 |

条件操作效应为 `0.32*g*(1-g)`，实际结果按 `Bernoulli(g+(A-0.5)*effect)` 生成。该构造使操作边际化后的结果概率恰为 g。模拟真值仅供真实集合和独立评价使用，不能进入实际 JCI 或调参。

## 结构消费者与共同预测能力

JCI 使用全部66项结果测量前变量，运行 pcalg 2.7.12 Anytime FCI、最大条件阶数2、`pdsep.max=Inf`、标准定向、JCI12、独立上下文间固定缺边和499次条件随机排列，显著性0.05；`p<0.05` 表示依赖，边界与 pcalg 一致。结果 Y 不进入这张图。来源没有自然环境选择变量，不能把该图作为跨环境结果不变性的证书。

结构建议的计算规则为：将尾端为3、箭头端为2的边组成有向图；求两个上下文的全部可达属性集合 R；建议集合为 R 中没有指向 R 内其他属性的确定箭头的节点。其余节点保留为不确定属性，仍参加有限惩罚预测，不能宣称其无效。支持不足的整张图不产生结构建议，使用完整属性候选。优先建议下游属性是需要验证的建模假设；上游负对照专门检验该假设的失效。

共同骨架候选为任一上下文所在无向连通分量中、度数恰为1的属性，记为 B。JCI 使用两个建议形状 `[B, T]`，其中 T 为前述有向可达属性中的终点。同骨架对照使用 `[B, B与上下文边际依赖属性集合的交集]`，充分利用相同上下文身份和边际检验信息；不根据被移除方向直接产生空集合。打乱对照使用 `[B, 置换后的T]`。三者具有相同数量的建议形状、相同来源评分和目标候选目录。完整属性候选始终保留，不允许结构建议删除已分配任务。

直接方法至少包括完整与稀疏逻辑回归、训练折内的单变量筛选、梯度提升分类树、根据相同随机上下文筛选的预测，以及在同一512项属性数据上拟合 PCA 后的逻辑回归。PCA 的维数与来源惩罚均仅用来源结果三折选择。直接上下文方法得到所有上下文身份，不把已知随机化信息专门保留给 JCI。

来源采用三个相同的分层折，逻辑回归 C 为 `[0.01,0.03,0.1,0.3,1,3,10]`，截距不惩罚，评分为 Brier 均方误差。稀疏比例为 `[0.25,0.75,1]`；单变量筛选数量为 `[4,8,16,32,66]`、C 为 `[0.01,0.1,1,10]`；提升分类树深度为2或3、迭代次数为50或150、学习率0.1、最小叶节点10、L2为1、关闭提前停止；PCA 维数为 `[4,8,16,32,66]`。筛选在每个来源训练折内重做；PCA 固定使用不含结果的512项观测。

JCI、真实集合、同骨架、打乱和直接上下文消费者均使用结构强度 `[0,8,100,1000000]`、建议外属性惩罚乘数 `1+strength`，两个上下文保持基础惩罚。直接均匀消费者用同一强度同时惩罚全部64项属性。每个消费者在共同来源三折内联合选择建议形状、C 与结构强度，每个形状28项组合；JCI、两项结构消融及真实集合均使用两个形状，共56项组合。重新拟合全部128项来源结果后形成一个来源预测器。结果未测量属性图独立于这些评分；来源 C 可以随惩罚形状调整，避免完整模型的 C 限制真实低维集合。直接上下文方法只有一个边际依赖形状，不读取骨架；建议为任一上下文检验 `p<0.05` 或支持不足的属性。直接方法的其他超参数目录保持前述定义，结果预算与校准预算相同，计算目录如实分别报告。

真实预测集合的两个形状为 `[B, 真实预测属性]`，后者在前两种机制为八项 X，在负对照为八项 H；实际方法不读取其坐标。另计算真实属性图通过同一消费者产生的建议：其终点 T 在三种机制均为八项 X，真实 B 为八项 X 与八项 L。该额外诊断专门区分结构发现误差与消费者假设失效，没有独立显著性判定或组件收益声明。

完整目标残差 Ridge 修正强度为 `[1,10,100,1000,1000000]`。每个方法的目标候选包括其来源三折选定预测器与共同完整逻辑回归预测器，两者各有五个修正，共十项；重复候选保持固定目录，校准按结果均方误差选择，平局按目录顺序。来源结构强度由128项来源结果选择，目标校准只选择这十项候选。效应使用独立排序数据的 `2*(2*A-1)*(Y-prediction)` 均值。每项固定模型使用131072项独立目标协变量计算方差及积分标准误。共享预测与完整目标修正沿用已经核验的科学函数。真实集合诊断需要与相同候选目录的直接方法比较；真实集合没有收益的机制应保留其结果，不用扩大估计结构的重复数量掩盖该信息边界。

## 冻结与判定要求

正式执行该开发检查之前，将本文件中的固定目录及实现身份写入新结果目录。两个种子批次为2026110191和2026110192，各八次独立学习重复，三种机制共48个单元。随机流按批次、机制、重复及数据角色分别派生；来源属性、来源结果、目标拟合、校准、排序和积分使用独立随机流。

共同判定族为48项比较：真实集合和实际 JCI 分别在三种机制下比较七种直接方法，共42项；实际 JCI 在三种机制下比较同骨架与打乱对照，再增加六项。七种直接方法为均匀有限惩罚、直接上下文、完整逻辑回归、稀疏逻辑回归、单变量筛选、提升分类树和 PCA。使用16次学习重复的近似成对 t 区间，Bonferroni 总alpha为0.05；联合门槛要求平均方差改善至少5%、同时区间下界为正、两个种子批次平均差分别为正。

第一种机制须对七种直接方法及两项结构消融共同通过，才能支持预定模拟范围的 JCI 增量。第二种机制单独报告目标变化下的保持程度，第三种机制报告建议失效边界。真实集合与直接方法的结果、全部失败条件及未执行计算均保持完整记录，不能按新结果换种子、换终点或改变判定族。

真实集合的可行性、估计结构的保留程度、实际 JCI 相对直接方法的增量，以及同骨架对照的差异分别报告。只有实际 JCI 的预定比较通过，才支持相应模拟条件下的独立收益；直接方法取得相同收益时，结果支持结果测量前的属性信息或降维，不能归因为 JCI。

全部48个单元已经实现、执行并通过独立核验，详见[完整结果](2026-11-01-jci-outcome-free-attribute-results.md)。实际 JCI 未通过预定独立收益门槛。本设计没有替换活动方法的默认入口，没有使用自然任务结果、受保护任务或模型服务支出。Prompt TSG 的自然任务绑定和属性测量实验需要单独的独立参考及表示比较，不能由本设计的模拟属性替代。

# 24个自然问题的要求绑定与编辑结果

本轮按 [冻结设计](2026-11-01-tsg-natural-issue-workflow-design.md)，使用固定取得的24个自然问题、八个来源仓库。独立参考构造者提出来源支持的目标，第二个隔离上下文审查目标；18项通过，六项保留 unresolved。全部24项继续占据两种流程的相同分母。

Graph 与强平面表示分别使用新的隔离提取上下文和新的编辑上下文，获得相同原问题、目标和动作。两种表示的全部来源引文、节点或事实身份及关系引用均经机械核对。各18项编辑由同一 `apply_prepared_edits` 实际生成，再由独立字符位置重建核对。两个新的匿名评审上下文检查完整目标移除、非目标保留、没有新增反向要求、没有解决无关歧义。

## 证据范围与复现

本轮使用八个隔离上下文：参考构造、目标审查、两个表示提取器、两个编辑器和两个匿名评审。它们共享模型来源，不构成人工金标准，也没有多次独立模型抽样。任务覆盖一般软件行为；没有证明符合活动安全 Atomic 政策，没有测量代码安全、功能性或实际修复效果，没有调用实验代码生成模型或激活正式协议。

输入及全部原始输出位于 `data/method/tsg-natural-issue-workflow-20261101`。共同输入 `packet.json` SHA256 为 `1015277a0805a5eaad423dceb579f5243c017b358d8bbb16e1075c7f13fc18c8`，实际匿名评审包 `blind-packet.json` SHA256 为 `b4acdc8527bc3518efa0cade4f335be7d35fef528c5c0b1bc4110bb787893c29`。

`workflow.py prepare` 固定来源目标和匿名位置；`materialize` 调用现有编辑函数并独立重建全部变换；`evaluate` 核对两个评审的实际引文，保留24项分母并执行仓库标签交换。使用本地 Python 3.12.14 及现有项目依赖。输出采用排他写入，既有材料禁止覆盖；`result.json` 固定全部 JSON 输入和实现哈希。

独立 PowerShell 核对重新读取原始两个评审，重算全部48个位置的产出判定及256种仓库标签交换，所得15／24、17／24及 p=0.625 均与 Python 汇总一致。`verification.json` 保存该核对状态、结果身份和公共编辑实现身份。

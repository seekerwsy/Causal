# CausalGuide 方法问题审阅上下文

日期：2026-10-08。用途：提交网页端 Pro 独立分析方法问题。请依据本文的实际设计、证据和实现细则审查；本地归因及修复方案也属于审查对象。本文没有启动新实验或修改冻结结果。

## 核心研究目标与约束

项目希望研究：如何从代码生成任务提示中表示完整要求、对象、操作、条件和范围，构造来源支持的 Atomic 提示干预，利用真实随机生成结果学习与选择干预，并通过独立测量取得安全结果，形成具有学术贡献、可审阅的研究方法。

需要分别回答三类问题：来源语义表示和精确绑定的贡献；随机干预效果及跨任务共享学习的贡献；FCI/JCI 结构发现对于决策、解释或实验选择的额外价值。工程完整性不能单独作为贡献，不能以图表示或某个因果算法必须取得优势为验收条件。用户关心当前无明显效果的现象具体由哪些设计、方法、实现或测量环节造成，并要求修复紧扣研究目标。

主方法只研究 Atomic：一次政策改变一个完整要求或一个明确的表达属性，保持非目标行为。Pair 与交互研究未启用。Prompt TSG 的边表示来源语义，不能解释为因果边。生成代码供独立安全和功能测量，代码结构不进入主 PAG，也没有建立正式的代码中介推断。

主要分析使用 assigned-arm、去重任务单位 ITT。准备失败、未执行、生成失败、未知、语义符合度和非目标漂移不得成为事后删减分母的依据。安全产出、直接违规、代码有效性、Oracle 可评价性、有限功能、完整功能及联合成功分别记录。

Codex 准备来源表示、TSG、绑定和编辑；本地 Qwen2.5-Coder-32B-Instruct 只生成代码。程序化观察器独立测量。作者辅助准备不能自动建立独立抽取准确率或图优势。规范协议 phase-context-policy-v3 仍为 SPECIFIED_DRAFT；已经完成的研究具有单独授权与冻结身份。新正式实验尚未启动。

## 已完成受控研究的具体设计

研究身份 controlled-semantic-20260930。Python，四个真实工具家族 find、grep、tar、git。D 有 400 项合成发现任务，E 有 400 项合成验证任务，每个家族各 100 项。D/E 使用分离的查询组合模板；每项任务另有路径投影、集合运算等功能变化。两个面板的查询组合模板数分别为 28 与 32。两套表达、不同初始状态、政策文本和生成重复共享同一个基础任务身份。

任务蓝图包含 primary、comparison，有时还有 tertiary 输入对象；真实操作、查询条件、目录或归档范围、输出、错误处理和允许输入域均明确。任务原文要求使用相应外部工具。tar 可以使用 tarfile 补充成员元数据，但仍要求调用 tar 列出归档。路径允许空格、引号、美元符号、反引号和分号，排除 NUL 和换行。

研究考察三个预先确定的普通内容政策，全部保持规范义务：

- local：移动同一完整限定命题，使其与目标操作共处同段，或与操作之间隔开至少两个完整文本单元。
- example：添加或删除一个完整、可选、非穷尽的目标输入示例，保持允许输入域。
- reference：在同一限定命题内，切换明确参数标识符与唯一的角色名称，保持对象、命题与接口。

初始状态 Z 的取一概率分别为 0.25、0.75、0.25，彼此独立。每项任务从同一 baseline B 出发，三个 Atomic 编辑各自翻转一个状态，不执行联合编辑。两套完整表达 V 各占二分之一；另有保持全部三项状态与要求的等义表达控制 S。

每任务、每政策的规范方向效果为 tau_tj = (1-2Z_tj) × [mu_t(A_j)-mu_t(B)]。每个 mu 在两套表达上等权平均。主 E 每条件四次生成，每版本两次。Raw 与 Rich-Flat 的目标政策另执行；相同最终全文共享物理请求，实际 E 共 9,216 个物理请求。

D 的表示准备使用 TSG。E 每个任务分别使用三个隔离实例准备 Raw、Rich-Flat、TSG；输入是相同的完整来源和公开政策说明，不提供蓝图、参考绑定、控制程序或代码答案。每实例一次准备、最多 12,000 输出 token，另有独立盲审。Raw 自由文本分析，Rich-Flat 保留命题、对象、条件、范围、来源及关系，TSG 构造显式来源图及查询。

公开政策已指定三个目标类型，任务来源要求对象唯一、目标操作唯一、限定命题唯一。Qwen 实际接收准备后的提示全文；表示本身不直接作为代码生成处理。任一政策位置准备或审阅不合格时映射 baseline，保留原位置及全部 ITT 分母。

## 结构发现与原决策公式

主图变量是 C、V、X_local、X_example、X_reference、Y。C 是五值的完整政策映射 context，V 是完整表达映射，X 从实际全文读取。初始状态、任务及家族身份保留在诊断中；主 PAG 允许未编码任务差异造成潜在混杂，不把任务 ID 当高基数条件变量。允许 C、V 经其他未编码文本属性影响 Y，不能将政策名称当成完美 do(X)。

结构阶段使用 4,000 条另行随机混合的请求，独立抽取任务、政策 context 和表达。FCI-time 与 JCI12-FCI 共享时间背景：C、V 先于 X、Y；Y 不导致 X；C 与 V 独立分配。JCI 另使用 context 与系统变量间无潜在混杂背景。实现使用 pcalg 稳定骨架、完整 Possible-D-sep 和定向规则。

CI 是条件层 Pearson 统计量之和，层内固定边际随机抽样 9,999 次，p = (1+同样或更极端次数)/10,000，alpha = 0.05。100 个 80% 无放回请求子样本加完整图，共 202 次结构搜索。结构支持 s_mj 是 100 个预定子样本图中出现全定向 X_j→…→Y 的比例；它表示请求扰动稳定性，不提供祖先概率或效果大小。

所有方法先计算相同 D 平均规范方向效果 tau_j。原评分：RD=abs(tau_j)，JCI=abs(tau_j)×(1+s_Jj)，FCI=abs(tau_j)×(1+s_Fj)。最大评分政策被应用到全部 E；只有三项平均效果均恰为零时选择 baseline。并列按 local、example、reference。保存 sign(tau_j) 作为预测方向。结构置换枚举三个 JCI 支持值的六种排列，按相同规则选取，价值等权平均。

原方法发现价值 V_m = E任务平均[sign(tau_j)×(1-2Z_tj)×(mu_t(A_j)-mu_t(B))]。与下降预测一致的安全下降也能给正发现价值。这个目标与实际安全改善须分开解释。

只有辅助 Ridge 使用逐任务预测。任务等权、每任务三个政策差标签、原五折任务分配，正则参数 0.01、0.1、1、10、100。原代码另外把其实际编辑预测乘以初始状态方向后选择绝对值最大的政策。

## 已核实结果与细则归因

D 的三项平均规范方向效果：local=-0.0734166667，example=-0.02137202381，reference=-0.00837202381。由于每项结构乘数只在 [1,2]，local 最低评分 0.0734166667 仍高于 example 最高评分 0.04274404762 及 reference 最高评分 0.01674404762。这些实际发现效果下，任何允许的支持向量均选择 local。实际 FCI/JCI 三项祖先支持全部为零，六种置换也相同。这一代数限制足以解释本轮方法动作相同，但没有证明 JCI 普遍无效。

安全主端点是 Oracle 可评价安全代码产出：满足冻结有限安全观察则 Y=1，未知与未被确认为安全的返回代码取 Y=0；这不表示 unknown 已被确认危险。生成失败和基础设施缺失另按原规则记录。该端点同时受软件行为、必要边界和测量支持影响。

按本面板实际初始状态比例、不乘规范方向，TSG local 相对 B 的安全产出均值差为 -0.02625；它与 H1 的 -0.03875 具有不同定义。

## 选择器实现补充

当前 `controlled_ridge_features` 的十六项特征依次是：三项初始状态、三项实际编辑后状态减初始状态、三个政策 one-hot、四个工具家族 one-hot、对象数量、同一对象数量、两套表达上的平均编辑长度比例。对象数量来自 `measurement.blueprint` 中名称以 `_query` 结尾的字段数量；两个对象数量字段完全相同。编辑长度使用 `SequenceMatcher` 的实际全文变更长度除以 baseline 全文长度，最大值限制为一。

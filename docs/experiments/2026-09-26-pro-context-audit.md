## 结论

## 应保留的正确约束

继续保留任务独立单位、ITT、盲测、unknown、自然与合成身份、冻结与独立评估、TSG不等于因果图。这些支持有效研究。不能为了得到显著或不寻常结果而取消它们。

“不寻常”应转化为可证伪的竞争假设：结构恢复更好是否反而不改善选择；更详细的表示是否减少跨任务支持；同一要求是否在不同任务条件下失效；明确的结果要求是否不如某种实现要求容易被模型落实。上述均是候选问题，不能预写成结论。已知 API 语义、同义重复、单个挑选案例不构成新发现。

## 纠偏后的完成标准

1. 方法地图按研究问题划分：自然状态结构、混合环境结构、随机政策效应、异质性与迁移。每类给输入、假设、输出、可用独立样本及不适用条件；必须包含直接随机效应基线。
2. 在相同数据和预算下，分别隔离信息来源、背景约束、搜索器、选择规则。不能仅报告 PAG 端点正确率；还要报告独立政策效用、遗漏收益和有害建议。
3. TSG须产生两份相互对应的输出：任务内精确编辑绑定，以及跨任务同义的事前属性。通过具体实例说明对象、条件、量化范围、生命周期和不确定状态如何进入下游判断。
4. 干预调整必须改变可识别对比或可实施政策；不通过随机编辑失败制造变异，不把文本属性的确定性编码当新因果发现。
5. 至少验证一个能区分竞争解释的真实代码实验；显著性取决于数据，明确的反例、无增量或不可识别结论也可有价值。有限模拟或前置检查不能替代这一步。
6. 单独报告：specified / implemented / tested / executed / reported / independently validated。原研究目标未完成的项目继续显式列出。

本审计不改变正式协议，不新建自动 Goal，也不代表重新向 Pro 发送了咨询。

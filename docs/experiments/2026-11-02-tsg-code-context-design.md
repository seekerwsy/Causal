## 来源与选择

本次只使用已有48项SWE-bench来源的任务身份、完整问题说明及其原始base_commit。旧表示、参考、评分、修复答案和测试补丁不进入选择或上下文准备。目的为检查原始代码快照能否支持明确的操作及调用位置绑定，继续解决完整上下文缺口。

对已有每个代码仓库，按 `SHA256("2026111210:" + instance_id)`选择摘要最小的一项任务，形成固定来源列表。所有仓库均保留，不能依据Graph关系、旧表现或新来源可用性替换任务。代表准备按同一摘要排序选择第一项；本次只取得该项的原始文件，确认准确来源身份与可解析性。完整列表继续保留，不将一个代表准备解释为全部任务已经取得资格。

文件来自该任务冻结的base_commit，通过问题说明明确提到的模块、调用或文件路径确定读取范围。获取完整原始文件并保留摘要及Git对象身份；代码正文作为新增开发背景暴露记录，任务数量保持原身份。禁止读取修复提交、答案补丁及测试补丁。不能根据预期答案修订原始程序或补充自行假定的合同。

## 检查范围与后续边界

只检查原始代码是否可取得、是否可由成熟Python语法库解析，以及问题说明中的操作是否存在可定位的源代码位置。代码中当前行为与问题要求的目标行为分别解释。静态位置支持不等于功能参考，不认证修复答案或一般正确性；缺少运行条件和独立功能测试的部分保持未知。

未来表示比较必须向Graph与强平面方法提供同一完整问题说明及相同原始代码。操作概念、具体调用实例、时间界限及新增要求应有各自的来源绑定。两种方法分别产生实际表示与读出，独立来源参考在方法输出之前固定。当前不改变旧48项研究的参考、分母、指标或负结果，不运行新的代码生成，不执行JCI，也不报告表示收益。

# Graph、来源上下文 JCI 与目标效应估计

本文件描述已冻结的来源上下文候选筛选研究，复现需要使用其结果包的 `source.zip` 与匹配验证器。当前活动方法及默认命令采用 [平均结果学习设计](experiments/2026-11-01-prognostic-learning-design.md)。

2026-10-31 修订采用 `NON_CLAIM_SOURCE_CONTEXT_QUERY_SIMULATION` 身份。活动入口为 `study smoke` 和 `study jci-directional-validation`，独立核对入口为 `study verify-jci-directional-validation`。当前执行声明的二元结构因果模型，真实任务表示优势仍需独立证据。

## 变量与目标

W 为准备之前的任务属性，C1、C2 为随机准备上下文，Z 为准备之后、Atomic 分配 A 之前的属性，E 为来源或目标环境，Y 为独立结果。代码提供安全及功能测量对象，不作为因果图变量。Prompt Graph 关系表示语义，不能直接作为因果箭头。

每项假设固定完整要求、适用范围、ADD/REMOVE、准备版本分布和处理控制流程。目标量为事前合格任务总体中实际编辑流程的目标环境平均效应。绑定错误可能改变实际流程；随机化不把它自动转换为理想要求的效应。

主要安全终点为 Oracle 可评价的安全代码产出。失败和未知没有产生该产出，保留在原分母中，并分别保留测量状态。功能性、有效性、Oracle 支持与联合成功独立报告。语义符合性和非目标漂移为诊断，不能事后筛除分配任务。

## 来源上下文查询

来源数据按实际分配 A=0、A=1 分成两张图。每张图的变量为 C1、C2、W、X、N、D1、D2、Y；缺少关键属性的机制对所有方法共同移除 X。实际每臂任务数量进入图形记录，两张图共用来源预算，不重复计数。

JCI 保留随机 C 的外生性知识，根变量按名称指定为 C1、C2。W 具有准备之前的时间身份，不因 A 被移除而成为随机上下文。结果生成晚于提示属性，保守定向保留歧义三元组。不假定准备只有单一靶点，也不禁止 C 直接作用于 Y。

图形解释依赖来源模型的因果 Markov 与适用的忠实性条件、独立任务、可比较的变量测量，以及正确的随机化和时间知识。FCI 允许潜在混杂；按 A 分层不保证消除其他不忠实性，也不能补偿错误测量。

候选掩码的六个位置依次为 X、N、D1、D2、C1、C2。W 与预测器中的 A 固定保留。对于未纳入候选 S 的每项 C_j，逐处理臂查询：

\[
Y\perp C_j\mid W,S,A=a.
\]

PAG 查询使用可能活动路径的保守检查。两臂所需查询均由图形支持时，候选标记为 `supported`；任一无法判定时标记为 `unknown`。保留全部 C 的候选没有剩余上下文可检验，标记为 `unrestricted`，不计为结构分离证据。

查询记录包含处理臂、上下文、完整条件集合、来源数据角色与 `source_context_separation` 类型。它提出共享建议，不认证未来自然环境稳定。预测充分性、来源上下文分离与目标环境分离，在真实图形诊断中分别保存。

当前主路径不运行包含自然 E 的联合发现。旧联合 E 的开发实现需要使用匹配的冻结源码；不能把其随机根约束用于允许 `E -> C` 的新模型。

缺乏条件支持时，整个图形保持 `insufficient_support`，不产生分离建议；已有共同预测候选仍参与结果学习。连续量、未知与非整数输入不能直接传入整数型条件检验。支持不足与普通程序错误分别处理；后者立即终止。

## 共享预测与目标校准

共享结果预测器包含 A、W 和候选 S；目标环境修正保留全部可观测属性及上下文：

\[
m_{a,T}(P)=\operatorname{clip}_{[0,1]}
\{g_a(W,C_{S_C},Z_{S_Z})+r_{a,T}(W,C,Z)\}.
\]

使用相同三阶交互预测基和正值 Ridge 惩罚。共享惩罚为 0.1、1、10，目标修正惩罚为 1、10、100。较小属性集合可以省略弱预测项；没有处理效应被结构判断固定为零。

模型记录使用 `mask` 和 `contexts`：部分上下文由掩码高位指定，`contexts=True` 的共同候选包含两个上下文。两种编码按同一设计矩阵归并，不重复拟合相同候选。

所有方法保留三个完整属性目标候选、三个完整共享候选及九个完整共享加目标修正候选。直接子集选择获得同一候选目录中的全部可见属性子集；JCI 以查询信息限制共享建议。部分上下文可单独参与共享预测。缺失 X 时，共享、目标修正、结构发现与直接对照均禁止使用 X。

目标 Calibration data 最小化 `mean((Y-(m0+m1)/2)^2)`，并列按冻结目录索引处理。它不使用目标 Ranking data 或确认结果。

## 目标随机化修正

A 的概率为 1/2，固定预测器与独立目标任务下：

\[
\Gamma=m_1(P)-m_0(P)+2(2A-1)(Y-m_A(P)),\qquad
\widehat\tau_T=\overline\Gamma_T.
\]

来源数据只帮助拟合预测器，不进入目标效应的残差均值。给定独立训练和选择结果，目标随机化使固定假设的估计期望为目标效应，允许来源预测错误或机制改变。

令 g=(m0+m1)/2，有逐项恒等式 `Gamma=2*(2*A-1)*(Y-g)`、`Gamma^2=4*(Y-g)^2`。同一假设下，两个冻结模型的效应分数方差差等于四倍目标预测风险差。相对预测风险降低比例不能直接解释为相对效应方差降低比例。

校准样本选择后的损失有选择乐观误差，不能作为最终精度证据。模拟计算固定模型精确方差及完整学习重复的实际误差；真实任务使用共同独立结果上的风险差或分数方差，不报告未知真实效应的均方误差。模型学习、校准选择和排序波动进入完整流程重复或注明近似性质的根任务重抽样。

## 机制、预算与消融

完整配置包含原八种受控机制，以及代理机制改变、上下文直接结果通路、目标结果机制改变，共十一种。基础机制与 2026-10-31 真实结构检查使用相同显式二元概率。

来源 C1、C2 独立 Bernoulli(0.5)，目标为 0.75、0.25；无改变机制保持 0.5、0.5。代理改变机制将 `P(N=1|U,C2)` 从 `0.05+0.65*U+0.2*C2` 改为 `0.05+0.2*U+0.65*C2`。作用抵消机制在结果概率加入 `0.04*(2*A-1)*(2*C2-1)`，按 A 分层可以检验其条件相关；这不构成普遍忠实性保证。

下面预算均按单项候选计数，全部方法获得同一批任务观测。配置给出一个前瞻预算点，预算曲线使用同一入口、相同角色比例定义其他预算点。来源任务预算为 256 或 1,024；目标学习总预算为 32 或 128，分别按 8/8/16 或 32/32/64 分给目标拟合、校准与排序。默认复现使用来源 1,024、目标 128，两种机制、两个批次各一次重复，共四次运行。完整配置使用十一种机制、两个批次各八次重复；本次修订不把默认复现称为完成整项研究。

主要 JCI 比较为同一消费者与预算下的直接子集选择。方向诊断只读取同一图形的骨架，所有端点变为圆圈后执行相同查询。真实查询与总体独立信息产生的图形为隔离诊断，不能进入估计方法的选择。相同知识下 FCI/JCI 等价时保留等价结果。

保存可观测属性下的真实最优分数方差、冻结目录最优风险、每组候选最优风险和实际校准选择风险。可观测最优预测必须积分掉 U，以及机制中不可见的 X，不能把完整潜在状态预测器当作可实现上界。

Graph 与 JCI 的四组消融使用共同提示和结果账本，分别输入 Graph、平面方法的实际属性测量。Graph 主要终点为独立盲态审查的完整绑定产出；JCI 主要终点为固定消费者的效应估计精度。当前四个作者准备任务没有独立参考标准和分别测得的属性表，因此输出 `BLOCKED_MISSING_INDEPENDENT_REFERENCE_AND_MEASUREMENTS`，不生成 Graph 优势数字。

平面方法获得相同事实、关系与证据，并允许合理重建结构。若执行不同编辑流程，需要相应的流程随机化和独立目标定义；不纳入共同账本比较。未知属性不得转换为语义不存在。

## 确认与报告

按绝对估计效应从四个候选提名两个，随后独立确认正、负方向。每项候选使用 32,768 个配对模拟任务，两个潜在结果在给定完整状态后独立抽取。全部四项保留用于诊断，每种方法按其固定两个提名统计相同逻辑确认预算。

具体编辑确认家族 alpha 为 0.03，覆盖四个候选的双侧区间。区间完全超过 +0.04 或低于 −0.04 才确认对应方向。低功效条件保留并报告，不据结果替换候选或机制。

该 0.03 控制每次模拟重复内的四候选家族。不同模拟机制和重复是方法评价，不是同时声明多项真实编辑效应；真实研究须按实际不同假设预先冻结确认家族。

Graph 和 JCI 的主要组件家族分别预留 0.01。当前模拟仅评价 JCI；各机制的主要精度比较在该 0.01 内校正。完整学习重复的配对 t 区间注明近似性质。精度门槛为效应方差改善点估计至少 5%、区间下界大于零、两个批次均改善。确认数量差异分别描述，不是当前组件精度通过条件；负效应发现不计为安全加固收益。

```text
python -m prompt_mechanism_study study smoke results/NEW_SMOKE --rscript PATH_TO_RSCRIPT

```

完整配置的复现命令为：

```text
python -m prompt_mechanism_study study jci-directional-validation results/NEW_FULL --plan configs/jci-directional-validation.json --rscript PATH_TO_RSCRIPT --workers 8
python -m prompt_mechanism_study study verify-jci-directional-validation results/NEW_FULL --workers 8
```

`--workers` 只改变进程调度。随机流由预定机制、批次种子、重复编号、假设和数据角色确定，每次重复使用独立的 R 进程与日志。四次参考运行的串行与并行结果逐项相同，比较时仅排除 R 运行耗时。完整运行在新目录保存配置与源码，独立验证按照同一科学规则重新计算。

使用 Python 3.12、NumPy 2.5.1、SciPy 1.18.0、scikit-learn 1.9.0、NetworkX 3.7 和 R/pcalg 2.7.12，设置 `OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1`。新运行使用新输出目录，执行前保存配置与源码。

2026-10-30 的方向、聚合研究和 2026-10-31 的运输诊断，使用各自结果目录中的 `source.zip`、原配置及匹配验证器复现。其数值和证据身份保持原定义，不使用新查询或新配置重新解释旧结果。

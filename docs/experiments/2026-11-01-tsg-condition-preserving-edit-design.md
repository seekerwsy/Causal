# 保留外部条件的完整要求编辑检查

## 固定问题与开发身份

此前完整表达式检查在43个由 Graph 标为 normative 的记录中生成一个结构删除提案。独立方法复核指出，条件归属于要求不能决定条件文字必须随要求删除。本轮修订同一个 `prepare_expression_removal`，保留外部条件的实际来源文字，并独立检查删除后的语义。此前170个位置的结果及实现归档保持原身份，不重新评分。

本轮是已暴露材料上的针对性开发检查。机械检查继续覆盖44张实际有效图及全部170个命题；四张无效图保持原状态。语义检查固定六个既有目标：唯一的 OR 目标 matplotlib-22719，加上此前 `target_span_does_not_cover_complete_expression` 位置按 SHA256(`2026110911:` + task_unit_id + `:` + requirement_node_id) 排序所得的另外五个不同任务。不会根据新提案或新评审替换目标。新增独立任务数为零，没有 Graph/Flat 收益比较或显著性声明。

## 消费者规则

目标表达式、全部成员和现有 Atomic 边界检查保持一致。连续删除的目标区间需要覆盖完整表达式成员；位于区间之外的条件原样保留，并返回它们的节点、来源文字及条件所有者。条件区间与删除区间部分相交时保持未解决。共享条件及非目标要求与删除区间发生冲突时仍保持未解决。

结构提案不认证条件可以安全独立保留。删除后若留下悬空条件、改变其修饰对象、损失输入事实或配置，独立语义评价必须判为失败或未知。全部结果继续标记需要语义评审及全提示重复覆盖尚未认证。功能性不由提示编辑检查推断。

## 先固定来源参考，再生成提案

两位独立上下文只读取完整原文、固定目标引文、共同规则及来源参考指令，不读取 Graph、旧结果、新提案或彼此判断。分别确定目标是否有明确规范来源、是否构成单项完整要求，给出完整谓词、输入条件、量词、时间归属、等价直接重述及必须保留的非目标事实与要求。目标引文可以同时包含非目标事实，这些事实不自动成为删除对象。来源未确定时保留未知。

两份来源判断固定后，同一实现产生全部170个提案及六个目标的实际修改后提示。无输出、无效和未解决位置保持原位置。之后两个新的匿名评审上下文读取原文、目标及两份来源参考和实际编辑结果，分别评价来源参考是否一致受到支持、整项目标要求是否已从完整提示移除、非目标语义是否保留、条件是否保留正确归属、是否新增反向要求及剩余文字是否完整。没有准备结果的位置仍占据分母。

六个固定位置的开发成功同时要求：两位来源参考均明确支持单项规范要求；实际生成提案；两位编辑评审的全部条件均通过且引用有效。未知、参考不一致、未生成及失败均为没有获得成功产出。另报结构提案数及失败种类，不能以提案数代替语义成功数。独立来源参考与评审共享模型来源，不称人工真值。

## 科学与复现边界

规则、源码及输入在新参考和新提案之前固定。输入、首次来源判断、实际提案、匿名材料和首次编辑评审分别保存，禁止根据判断重交直到成功。评分通过独立原文切片和来源引用核对，不重新调用评审。所有既有完整绑定、规范作用、JCI 及未知结果保持冻结。

本轮来源提取和文本编辑不调用实验代码生成模型、不产生新服务支出、不使用受保护任务，也不激活正式协议。语义成功只支持这六个已暴露目标的开发可行性；后续独立表示增量及其下游效应需要公平的新研究验证。

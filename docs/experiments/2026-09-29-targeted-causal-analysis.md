# 当前修复数据的因果算法探索分析

本分析依据用户“完成预定的研究步骤”的授权，使用已经公开结果的256项Qwen请求。身份为事后开发探索；原生成、质量判断、测量、主要结果和历史结构实验均保持冻结。正式协议仍为`SPECIFIED_DRAFT`。本分析没有代码生成调用，不占用新的评价材料。

## 查询及执行规则

1. 复用全部19项合格提名，按完整`policy_id`合并重复，得到18项政策及10项独立任务。直接基线使用所有政策的P/N原权重，先在任务内平均，再对任务等权。未知结果在原安全产出端点中为零，未知安全状态继续单独保存；不删除失败生成。
2. 结构诊断设两个面板。`policy_family`包含10项任务，X为所选政策的`operation == REMOVE`；`tsg_support`仅使用合格TSG候选对应的7项任务，X为目标来源语义单元数量大于一。后者表示当前作者表示中的来源支持分散程度，不表示真实安全原因。各任务选择候选身份字典序最小的政策，选择规则不读取效果。
3. 每面板每次每任务只贡献一行。固定PCG64种子2026092930，进行32次请求抽取；独立抽取P/N、seed及version。C为P=1/N=0，Y分别为原安全产出或Oracle覆盖。两个端点共用请求，两个面板各自固定候选。完整抽取清单在结构搜索前保存。重复抽取反映请求敏感性，独立样本数始终为10或7。
4. 每份三变量表运行十四个搜索配置：pcalg的FCI-JCI0/1/12分别使用原始背景和共同时间背景，并分别运行G²与精确CI；Tetrad GFCI分别使用原始背景和JCI12共同背景。共同背景包含C/X无邻接、Y不能导致C/X；JCI12额外规定随机C无潜在共同原因。原始配置的算法比较含有背景信息差异，只有对应同背景配置可以比较搜索实现。
5. FCI使用G²检验、alpha=0.05、二元固定自由度、完整方向规则及无选择偏差；GFCI使用G² alpha=0.05、BDeu等效样本量10、结构先验0。每次FCI实际CI查询保存p值、条件集和期望格数量。各配置保存PAG、警告、时间和环境。GFCI使用现有后端实现，保存三变量全部可能CI查询的独立稀疏格审计，不声称审计表是其内部查询轨迹。
6. 在同一表上计算固定边缘分布下的精确条件检验，完整枚举条件层的2×2列联表，以各条件层Pearson统计量之和为统计量，常数条件层贡献零。作为稀疏样本敏感性检查；任务异质性、事后分析与变量语义限制继续适用。所有检验值仅作诊断，不进行显著性或机制声明。
7. 对全部唯一合格政策计算任务等权P−N、未知安全界限以及预定有界均值区间；两个结构面板另报告各自固定所选政策的完整P−N，避免把不同政策混合当作同一个查询。所有政策正向均按P−N定义，不能按已观察效果选择方向。结构搜索的无邻接输出不用于取消政策资格。
8. 共同候选的按任务留一选择器分析使用单独明确的[选择器规则](2026-09-29-targeted-selector-analysis.md)。它评价已有数据中的选择行为，不能恢复独立评价身份。当前7项TSG任务不足原关系学习器的8任务支持规则，图关系增量保持未验收。

本地pcalg源码明确规定G²在`n < 10 * df`时警告并返回1；本次二元无条件检验阈值为10，条件于另一个二元变量时阈值为20。记录这些返回值的实际来源，不能解释为已证实独立。精确CI配置直接替换检验函数并重新运行完整FCI，检验枚举分布事先独立验证。

总计128份真实数据表、1792次实际结构搜索。报告所有抽取与配置，不选择最有利输出。不同端点为分别分析，覆盖不进入安全结果的中介图。当前context修饰、交互与Pair推断均未启用。

## 解释与验收

验收包括实际后端完成、输入与请求映射可复核、CI调用及稀疏支持公开、共同背景比较、直接基线和选择器比较、原始输出到汇总的独立复算，以及算法是否新增可解释信息的明确判断。计算完成不等于算法优胜、真实图正确或不显然机制成立。

相同编辑合同跨任务支持不足、10/7行的稀疏列联表、已暴露任务、只有两种不同seed、同组版本全文相同、有限测量未知及政策家族异质性均为解释限制。所有这些限制随输出保留，不能用增加重复表数量消除。

# 24个自然问题的完整要求绑定与编辑比较

本开发比较使用已按固定规则取得的24个公开自然问题，输入身份见 `data/method/tsg-natural-issue-acquisition-20261101/identity.json`。任务分母固定为24，不能因未知上下文、复杂性或方法输出更换问题。研究问题是：Graph 表示能否提高完整要求的绑定与编辑质量。问题来源包括一般软件行为，不预设它们符合活动安全政策，不测量代码安全效果或修复成功率。

## 原文、目标与独立参考

一个未接触方法制作的独立上下文只读取原问题，逐项选取原文中首个主要、明确提出的行为改变要求。以标题表达的主要请求为起点，结合正文中限定该请求的对象、条件与例外；不能把标题的笼统请求当作不带条件的完整要求。若有多个独立请求，选择原文顺序最早的主要请求；缺少明确期望行为或存在冲突时保留 unresolved。以原文引文支持目标要求、相关条件、非目标要求及未知上下文。引用已有代码和实际结果只能支持其原有角色，不能自动变成规范性要求。

第二个新的独立上下文读取全部原文和第一位参考者提出的目标，判断其来源、完整性、Atomic 范围、非目标边界及可解释性。它可以判定 unresolved 或 reject，不得代替第一位作者重写目标。只有 validated 目标进入两个流程的相同目标输入；其余任务保留固定位置并计为没有获得完整编辑产出。目标构造与检查均在 Graph、平面表示或编辑输出产生前完成并保存，不把两者称为独立双重标注一致性。

动作统一为 REMOVE：移除该完整要求的显式规范性表达，保留原有实际行为描述、代码例子、其他要求和未知上下文；不能新增相反要求。若目标同时在标题、正文和期望结果重复表达，需要处理其全部规范性表达。移除请求不代表生成软件已经改变，也不要求编造一份完整功能规范。

## 相同信息与流程预算

每种方法使用一个隔离提取上下文和一个新的隔离编辑上下文；每阶段对每个任务只提交一次输出，不根据质量重试。两个提取器获得相同完整原文、validated 目标及动作。Graph 明确给出来源节点、对象、条件、例外及关系；强平面表示可以保留完整事实、交叉引用、全部关系和来源片段，允许重建结构。不得将平面流程限制成互不关联的词袋。

两个编辑器分别读取相同原文、目标和自身实际表示，输出逐字替换列表。不得读取其他方法、参考审查理由、历史答案或后续评分。使用现有 `apply_prepared_edits` 实际产生文本；无效输出、缺失输出和 unresolved 保留原分母并计为未获得成功产出。两流程上下文调用数量相同，实际 token 数与模型波动没有被控制，不能作计算效率结论。

## 盲态评分与事前判定

两个新评审上下文只读取原文、目标、动作和匿名实际编辑结果，逐项判断：完整目标转换成功、非目标要求与原有事实保留、没有新增反向要求、没有解决无关歧义。每项使用 pass、fail 或 unresolved，必须给出原文及编辑后逐字证据。只有实际生成文本且两位评审四项均 pass 才计为完整编辑产出。分歧和 unknown 不剔除，不改变目标。

匿名位置在读取编辑输出前按种子2026110152生成，每个问题保留两个位置。主要指标为两方法在全部24项中的完整编辑产出率之差。报告全部逐项判断及失败类型；未知上下文另行列出，不计为 Graph 收益。

开发扩展条件固定为 Graph 产出率至少提高20个百分点，且按仓库整体交换方法标签的双侧精确符号置换 p≤0.05。枚举八个仓库的256种标签交换，统计全部任务的产出总数差；同一仓库的全部问题共同交换，以容纳重复问题及共同来源依赖。该检验依赖仓库之间独立及零假设下成对标签可交换的假设；来源仓库并非总体随机抽样，八个仓库也不能支持普遍有效性或正式确认性结论。没有达到任一条件均报告未建立本轮开发增量，不以其他指标替换主要判定。

所有上下文均使用同一模型来源的隔离会话。自动参考与盲审不能当作人工金标准。无实验代码生成、无新增服务支出、无受保护任务、无正式协议激活。活动方法保持现有单一入口；本轮结果只决定表示组件的后续研究方向。

# TSG 独立上下文语义与表示检查结果

用户授权由 Codex 与独立上下文审阅。按 [预定开发设计](2026-11-01-tsg-blind-development-design.md)，四个上下文均不继承父聊天，只读取同一材料包和根目录约束。两个参考上下文彼此不查看审阅结果，未读取作者 Graph、绑定或历史审阅；两个表示提取上下文也未读取参考或作者表示。

两个参考上下文在操作工具、输入对象、所有适用调用的范围、是否延伸到仅比较集合的调用、来源要求状态、新增兼容性、准确操作证据七个共同字段上全部一致。四项来源均未表达完整的禁止 shell 解释要求，新增要求均与来源兼容；没有生成代码，软件是否具备相应保护仍为未知。

Graph 提取器实际构造节点、类型关系和证据；平面提取器实际构造完整事实与关系表，允许交叉引用与合理重建结构。两组分别产生实际绑定输出，均为 4／4 项完整匹配。绑定证据逐字存在于原提示，全部任务保留在分母中。没有采用作者制备的同一提示记录冒充两个独立测量。

这四项材料上没有观察到表示增量，两组均达到本次共同绑定任务的最高计数。任务为已经暴露的受控作者材料，不能推断自然任务准确率或普遍的 TSG 优势。上下文彼此隔离，但具有共同模型来源及相同源文本；一致性不能排除共同错误，不称为人工金标准。所有审阅均属于自动化语义评价，未产生代码生成调用。

## 仍缺少的证据

每种表示仅测量一次提取上下文，任务信息与共同输出问题相同，但没有测量并校正实际 token 消耗或重复提取波动，不能据此比较计算效率或稳定性。

本轮补充了四项受控来源的上下文隔离自动化参考，以及分别测得的 Graph／平面绑定输出。自然任务的覆盖范围、更复杂的多要求作用域、实际提示版本语义保持、下游效应精度与功能性保留仍没有得到本轮评价。冻结 SCM 记录保持原始资格状态；本结果不会追认旧模拟已经测量 Graph 表示贡献。

## 效果学习、方向和发现效用

文本Ridge保留alpha集合`.1, 1, 10, 100`、任务权重`1/K_i`、内部任务留一、并列取较大alpha和`fit_intercept=false`。词表、参数、类别及规则在新评价输出前冻结。训练采用统一新测量定义，全部相关开发材料按相同规则处理；旧标签继续保持原身份。

设候选的分配政策差为`D_iq = mean(Y_P) - mean(Y_N)`。TSG和Raw使用同一个冻结文本方向预测器，流程效用为两个位置的`方向×D_iq`之和除以二，空位置贡献零。算法比较在共同候选池各选一项候选及方向。方向选择分解与P-only消融使用相同结果，不增加生成臂。

相对R的采用价值单独分析。完整提示分布相同的P和R具有零真实编辑效果；不同seed造成的样本差保留生成波动解释。

### 固定面板的生成效果

条件于冻结任务、准备结果、选择器、版本及观察器，将任务等权估计量写成`theta_hat=sum(c_r*Y_r)`。先合并共享请求系数，删除抵消系数，任务仍保留在原分母中。

每个独立随机组的贡献为`W_g∈[l_g,u_g]`，范围在结果前由全部系数确定。组可以是一项独立请求，也可以是具有共同随机性的多项请求。采用区间`theta_hat±h`，其中：

```text
h = sqrt(log(240)/2 * sum((u_g-l_g)^2))
```

该规则保留任务等权，利用实际生成随机性的独立结构。任务N仍为去重任务数。区间覆盖固定面板的平均生成效果，不涵盖观察器系统误差、准备随机性或任务迁移。

本地核算确认：12项任务、P/N各四次独立生成、无共享时，每请求系数绝对值为`1/48`，共有96项请求，得到`h=.337905`。完整区间宽度约`.675811`。不同方法差的系数及共享结构不同，需要逐项重新计算，不能采用这个政策差示例。

## 结构算法实验

科学问题是结构方法筛选事前属性后，能否改善共同直接效果学习器的政策选择。Y邻接只作为可失败的筛选规则，不认定为已识别的效果修饰。这里的SCM策略模拟与真实研究中尚未启用的context修饰推断分别管理。

### 生成分布与视图

使用三种机制：

```text
p1 = .4 + .1*M2 + C*(.5*M1 - .2)
p2 = .2 + .3*M1 + .1*M2 + .15*C
p3 = .4 + .1*M2 + C*(.5*U - .2)
```

前两种机制的`C,M1,...,M6`相互独立，分布均为Bernoulli(.5)。第三种机制的`C,U,M2,...,M6`相互独立且分布为Bernoulli(.5)；另有独立`E~Bernoulli(.2)`，令`M1=U XOR E`。每行独立生成`epsilon~Uniform(0,1)`及`Y=1{epsilon<p}`。M3至M6均为无关属性。

每份六属性样本同时提供前三属性视图和六属性视图，方法与视图共享实际样本。第三种机制积分潜在U后，观察到的条件均值为`.4+.1*M2+C*(.3*M1-.1)`，策略和最优参照均只能读取M。

本地有限状态求和确认三种观察机制的恒选0、恒选1、最优可观测策略价值分别为`(.45,.50,.60)`、`(.40,.55,.55)`、`(.45,.50,.55)`；全部概率在[0,1]内。这是规格算术验证，尚未生成模拟数据或执行搜索。

### 共同背景、CI与搜索

背景排除C与M之间的邻接，禁止Y导致M，允许M与Y存在潜在混杂；不给出M之间独立的知识，也不强制C/Y邻接。JCI1禁止系统变量导致C，JCI12再排除C与系统的潜在混杂。主比较运行JCI12背景的FCI与GFCI。具有相同背景的普通FCI与此FCI配置合并，避免重复计算算法数量。

变量顺序为`C,M1,...,Md,Y`；无选择偏差，搜索深度和路径长度不限，启用Possible-D-sep和完整定向规则。GFCI使用`maxDegree=d+1`、`faithfulnessAssumed=false`，BDeu ESS为10，`structurePrior=0`。二元类别0/1预先登记。后端参数不能正确映射时，停止该配置。

CI固定alpha=.05，在各条件层固定边缘，以Pearson统计量之和为统计量。联合可行表数不超过100000时，按超几何概率计算精确尾概率；超过时进行9999次条件抽样，p为`(1 + 超过或等于原统计量的次数)/10000`。同矩阵、同查询共享缓存及随机流。

若固定边缘下最小可达p值仍大于.05，返回统计未定及`p=null`。必需查询未定时终止该次结构筛选，不输出合格PAG，消费者按预定规则保留全部属性；登记未定率。非法输入、NaN、后端错误和观察器错误直接终止并报错。统计未定与实现错误必须区分。

### 下游与评价

设`t=2C-1`、`z_j=2M_j-1`，各方法使用设计矩阵`[1,t,z1,...,zd,{t*z_j:j∈S}]`，全部保留属性主效应。S分别为Y邻接属性、全部属性和空集。只筛选政策与属性的乘积项。

目标为残差平方和加非截距系数的L2惩罚。lambda候选为`.1,1,10,100`。全属性模型在共同五折上，以`[2*t*Y - tau_hat(M)]^2`的验证损失选择lambda，并列选择较大值，供全部方法共享。折按固定独立随机流打乱样本后轮转分配；不在全样本已筛选的属性上重新调参。缺少任一分配臂的拟合采用预定弃权状态。

`tau_hat(m)=2*beta_C + 2*sum(gamma_j*z_j)`；超过`1e-12`时选择C=1，其他情况选择C=0，平局和缺臂另行记录。真实价值为均匀枚举所有M状态后平均`mu(pi(m),m)`，遗憾为可观察M的最优价值减该策略价值。真值只用于最终评价。

增加与结构消费者最终属性数k相同的随机子集基线。在给定k后，枚举全部`C(d,k)`个子集，以均匀权重分别拟合并平均其精确价值和遗憾。子集成员选择不使用Y或结构所选具体属性；k本身来自对应结构输出。d最多为6，单个k最多20个子集。

各子集使用同一数据、折、lambda和动作规则，不挑选最优子集，不将多个策略合成为新策略。两个后端得到相同k时共享该基线结果；k=0或d时只有一个子集。结构统计未定并保留全部属性时取k=d。新增基线不增加图搜索或Qwen调用，仍受CPU两小时总预算约束。其结果用于区分降低维数与选取特定属性的收益。

### 数量与解释范围

N取32、128、512，每机制／N重复14次，得到126份六属性矩阵。两个视图、两个后端共504次有限样本搜索。三个总体机制乘两个视图额外生成六份总体CI的FCI-PAG，总计510次，上限540次、CPU两小时。总体CI使用有理数分布检验，不为GFCI构造无限样本评分。

主种子为20260930，按机制、N、重复和用途派生子流。方法共享样本、折及同查询随机性。统计单位为独立矩阵重复，视图和图数量不增加N。未定占用原搜索位置，预算耗尽后不补充运行。

这一实验评价低维随机政策下的结构筛选及直接效果学习。它不能单独证明JCI方向增量、真实TSG优势或一般高维适用性。总体CI下的消费者失败指向决策规则问题；总体CI有效而有限样本失败，才支持进一步分析结构估计误差。

本地代码检查确认，现有GFCI已经使用BDeu ESS=10和structure prior=0，但CI仍为G²；当前时间背景函数及R入口限定`C,X,Y`三列。新多属性背景、共同条件检验、统计未定处置、策略消费者和配对评价尚未实现。既有实验完成状态不能替代这些验证。

## 科学验收

TSG准备增量需要同预算、隔离准备下的新任务发现效用及具体图使用证据；图非空只证明产生了结构记录。效果学习需要同信息、同方向权限的独立比较。结构方法需要输出进入消费者并改变策略价值或辨别成本。语义复现需要新独立任务支持同一冻结假设。

普通内容出现有害安全产出影响具有研究价值，但需区分直接违规、覆盖与功能变化。人类低预期结论还需要未参与准备且未见结果者的事前判断；这项额外证据缺失时，可以报告普通内容效果。

开放假设的后续复现、广泛措辞稳健性、自然开发者请求泛化、图关系信息独立增量及小幅方法优势，均按实际证据判定。完成本轮执行和复现不自动满足这些长期科学验收。

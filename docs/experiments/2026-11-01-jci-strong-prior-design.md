# 充分集合约束强度与共同调参的有界诊断

本轮检查一个具体消费者限制：真实预测充分集合只能把集合外基项惩罚提高至原来的九倍时，是否仍保留过多来源拟合噪声。范围固定为已暴露六机制的目标预算32、批次0、重复0，四项假设，来源128和1024项。全部机制保留，不按新结果选择报告。

对照方法与真实集合消费者均取消共享全局截距惩罚，保留目标截距偏差的独立有限惩罚。每个方法分别使用强度0、2、8、100和1000000；真实集合仅增强集合外基项惩罚，均匀方法增强全部斜率惩罚。两方法分别在每个形状下用相同来源折选择五个基础惩罚，再由相同独立目标校准选择形状和目标修正，共75次来源交叉验证拟合和25个最终候选，预算相同。

所有惩罚保持有限且共同保留零结构候选。较强约束不宣称结构必然正确；本轮只使用已知真实集合，不运行估计 JCI，不把任何任务从效应分母剔除。每次拟合经独立正规方程核对，报告全部候选和实际校准选择，不将真值结果用于实际调参。

实现复用 `data/method/jci-source-budget-diagnostic-20261101/structured_cv.py`，通过显式 `--plan wide-prior-plan.json` 选择固定范围。旧三形状结果使用其原源码归档复现；新增参数不会覆盖旧结果。先验证代表机制及旧配置的数值重现，再完成全部预定六机制。

本轮属于事后暴露材料的机制诊断。即使真实集合有效，也须在相同观测和预算下比较估计 JCI、直接条件充分集合、贪心预测集合及适当直接预测方法。没有独立组件证据前，不扩大正式实验或宣称 JCI 有收益。

## 已执行结果

代表机制的1600次拟合通过独立正规方程核对；参数化脚本在旧配置下的八个代表假设／预算位置、全部候选目录也与冻结旧结果精确一致。全部六机制随后完成48个假设／来源预算位置、9600次含交叉验证的拟合，两种方法逐位置具有相同预算和共同零强度候选。

| 机制 | 来源128项，相对均匀惩罚改善 | 来源1024项，相对均匀惩罚改善 |
| --- | ---: | ---: |
| background_shift | 3.53% | 3.44% |
| cancellation | 5.55% | 2.53% |
| missing_attribute | −0.22% | 2.11% |
| proxy_shift | 1.79% | 3.23% |
| stable_signal | 4.12% | 1.51% |
| weak_context | 2.39% | 3.74% |

来源128项的24项假设中，十项选择强度1000000。允许更强约束确实改变实际拟合，但只有一个代表机制的点改善超过5%，仍包含负结果；本轮没有独立重复批次、区间判定或强直接集合查询比较。不能把这一个点改善解释为 JCI 独立收益，也不支持继续只扩大相同惩罚网格。

原始结果位于 `data/method/jci-source-budget-diagnostic-20261101/wide-prior-result.json`，配置为同目录 `wide-prior-plan.json`。环境使用既有服务器 Python 3.12.13、NumPy 2.5.1、scikit-learn 1.9.0，单进程并设置 `OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1`。没有新增观测或实验代码生成调用。旧诊断的完整源码与结果归档身份位于同目录 `original-source-archive.json`。

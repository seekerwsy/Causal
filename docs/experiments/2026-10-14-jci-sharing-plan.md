## 科学问题与七阶段

研究 JCI 提出的来源属性集合能否提高随机政策效果学习及跨环境选择价值。来源语义记录定义初始要求状态 W1、作用条件 W2 及背景属性 W3；准备后的要求状态 X 属于提示变量。生成代码及代码结构均不进入结构搜索。

表示、优先化、假设冻结、干预与随机化、测量、结果组装、推断与报告共用现有入口和 artifact 层。此次计算实验检验结构消费者的科学行为；真实历史代码结果用于已暴露材料上的适配诊断。它们分别报告，均不构成新的自然任务确认结果。

## 计算机制

每个独立任务抽取 W1、W2、W3、准备完成状态 F，随后每个分配组执行八次独立 Bernoulli 结果抽样。A=0 时 X=W1；A=1 时 X=W1 XOR F；F 的概率为 0.8。F 在结果前确定，全部任务保留。W1 在四个环境中的概率为 0.15、0.25、0.35、0.40。W3 概率为 0.5；W2 通常概率为 0.5。

结果概率为 b+X*gamma。四个预定机制为：

| 机制 | b | gamma |
| --- | --- | --- |
| baseline_shift | 0.30+0.10*W2+0.05*E | 0.25 |
| scope_sign | 0.50+0.04*E+0.05*W3 | 0.30*(2*W2-1) |
| effect_shift | 0.45+0.04*W3+0.02*E | 0.30-0.15*E |
| proxy_shift | 0.45+0.05*W3+0.02*E | 0.25*(2*U-1) |

proxy_shift 中 U 为独立 Bernoulli(0.5)，W2 是 U 的有噪声代理，四个环境的准确率为 0.95、0.75、0.55、0.15。该机制中 U=0、1 对应 F 的概率为 0.65、0.95，边际概率保持 0.8；U 因此同时影响准备后的 X 和结果。计算真实价值时对 U 和 F 积分；学习器只能读取 W。概率范围在任何抽样前验证。F=0 时两个最终提示相同，共享物理结果且差值为零。

D 与 CAL 分别在环境 0、1、2 独立抽取，每个环境 128 或 512 个任务；每个机制、数量配置有十六个独立重复。环境 3 的结果及真实价值在方法配置选择完成后用于评价。有限状态真实价值通过八种 W 状态精确求和，真实概率仅供最终评价。该实验研究一个完整要求的状态改变，结果保留实际编辑方向。

## 结构搜索与共享条件

比较 pretreatment 视图 (E,A,W1,W2,W3,Y) 和 prompt_state 视图 (E,A,W1,W2,W3,X,Y)。每项任务以独立预定 A 选取一个真实抽样结果进入结构搜索，任务不因重复生成增加结构样本量。

两个方法使用相同条件检验和随机查询流。检验为分层固定边缘 Pearson 条件 Monte Carlo，1999 次抽样，p=(1+超过或等于观测统计量的次数)/2000。固定边缘的退化层按其精确零统计量处理并记录。有限样本非拒绝只产生结构提议。

FCI 使用 pcalg 的 stable、完整 Possible-D-sep、全部十项定向规则、无选择偏差。时间背景禁止 Y 导致提示及来源变量，禁止 X 导致原始来源及分配变量。随机 A 与 E、W 无邻接。JCI 配置进一步对 A 应用 JCI12；自然 E 保留潜在混杂。通过 pcalg::pag2magAM 取得同一等价类中的有效 MAG，并通过 dsepAM 查询 Y 与 W 的省略属性在 A,E,W_S 条件下是否分离。X 不进入总政策效果的条件集合。无法取得有效 MAG 时保存结构不可评价状态；实现错误立即终止。

使用按包含关系最小的结构充分集合，并允许进一步检验这些集合的子集，以区分基础产出属性与效果属性；完整属性集合另行保留。子集的统计资格由 CAL 独立确定，不能从结构提议直接授予。

## 效果资格和消费者

训练标签为任务内实际编辑组均值减基线组均值。W 的二元乘积基函数提供完整有限状态表示。共享部分使用候选属性集合，环境差异部分保留全部属性，并施加有限 Ridge 惩罚。新环境的环境差异项为零，其共享价值必须独立评价。

CAL 同时检查省略属性的效果充分性和环境间效果稳定性。按每个环境及八个来源状态计算任务差值均值、方差和任务数；缺少四项任务的状态标为支持不足。环境间比较使用共同均匀的省略属性分布，单独检验组成变化之外的效果稳定性；这些诊断权重不改变任务等权的策略价值。使用冻结的全八子集、环境对及状态对检验数量计算 Bonferroni t 区间。共享误差容忍为 0.10，这是计算方法开发尺度，不提供五个百分点改善或采用保证。全部区间位于容忍范围内记为 qualified；出现区间完全越过范围记为 refuted；其余为 unresolved。未定和不足不作资格通过。t 区间属于近似开发诊断，不能解释为任意有限样本的精确覆盖保证。

比较 full、direct_checked、time_checked、jci_checked、jci_unchecked。direct_checked 检查全部八个子集；结构方法检查其提议子集及完整集合。各方法使用共同 Ridge、环境惩罚及阈值网格，按 CAL 的实际策略收益选择，随后冻结。null 阈值明确表示不编辑。checked 方法缺少合格共享集合时保留不编辑策略；该行为计入完整分母。校准最优值不作为确认结果。

三个主要比较为 JCI checked 相对 full、direct checked 和 time checked 的价值差。学习结果同时报告环境 0 至 3 的值、最优可观察策略遗憾、动作分歧、共享资格和拟合数量。置信区间按独立计算重复成对汇总，对全部机制、数量、视图和三个比较同时分配错误率；这是预定计算机制内的开发推断。

# 联合随机上下文中的 JCI 政策学习

证据身份为 `AUTHORIZED_BOUNDED_JOINT_CONTEXT_METHOD_DEVELOPMENT`。用户于 2026-10-14 要求继续使 JCI 算法提供增量。本方案检验多项 Atomic 政策的联合因果结构能否改善候选选择。正式协议保持 `SPECIFIED_DRAFT`；所有代码生成结果均来自已暴露的真实历史任务或明确标记的计算结构方程模型，新增模型调用为零。

## 科学比较

同一任务可以包含多个候选，每次随机分配只选择基线或其中一项完整要求编辑。互斥分配编码为 C1 至 Cm；准备后的提示属性为 X1 至 Xm，结果为 Y。不同 C 分量由共同类别分配产生，彼此没有因果箭头。JCI123 将其上下文子图表示为完整双向边图；JCI12 不固定该子图；时间背景方法只保留上下文先于提示、提示先于结果的方向约束。

三种结构方法共同使用 pcalg 的真实 FCI、完整 Possible-D-sep 及固定边缘条件 Monte Carlo 检验，抽样次数为 1999，错误率为 0.05。直接调用 pcalg 的对应 JCI 模式，使背景约束进入结构发现。自然来源的潜在混杂保留在允许的图形中。提示语义关系不提供因果箭头，生成代码及其结构均不进入主因果图。

本次消费者读取 `pcalg::pag2anc` 对 Ci→Y 的判定。确定的非祖先关系提供全局零效果提议；未知关系保留候选。效果大小、方向和任务条件继续来自共同结果学习器。完整数据图与八项预定 80% 任务子样本均执行三种结构方法；八项子样本的非祖先频率只用作开发中的收缩分数，不授予置信水平。

## 七阶段与共同消费者

| 阶段 | 输入、行为与输出 |
| --- | --- |
| 表示 | 完整独立任务、原始来源状态、实际准备状态、互斥分配和独立结果；每项任务只提供一个结构结果观测。 |
| 优先化 | 联合上下文 FCI 提出政策的非祖先收缩分数，直接对照从相同任务子样本取得效果不确定性。 |
| 假设冻结 | `joint-plan.json` 固定全部机制、任务数量、重复、图形假设、共同 Ridge、校准候选及比较。运行身份保存源文件散列和环境。 |
| 干预与随机化 | 每项分配为基线或单项要求 ADD。历史读取真实冻结请求；计算任务每项独立分配并产生一个实际结果。相同提示的预测效果为零。 |
| 测量 | 历史保留原安全产出、有限功能、支持和失败状态；计算结果使用预定 Bernoulli 概率。全部任务保留。 |
| 结果组装 | 共同训练、独立 CAL 选择模型与收缩强度，随后冻结动作并评价全部目标任务。 |
| 推断与报告 | 计算机制按独立重复成对比较；历史材料按事后分析身份报告。全部预定比较和机制均报告。 |

共同效果学习器包含完整属性和目标分解两种 Ridge 表示，惩罚网格为 0.001、0.01、0.1、1、10。历史完整表示复用 `controlled_ridge_features` 的十六项预先可观察属性；目标分解表示按政策共享相同提示以外的效果。计算研究使用完整来源状态基函数表示基础结果，以及随机分配与预先来源状态的交互表示政策效果；目标分解表示保留每项要求 ADD 的单独效果系数。未分配臂的结果不会提供给计算学习器。

共同参考、直接 bootstrap 收缩、直接不确定性下界、时间背景、JCI12、JCI123 使用相同训练与 CAL 任务。收缩强度为 0、0.25、0.5、0.75、1；直接下界乘数为 0、0.5、1、1.5、2。零收缩强度包含共同参考。直接 envelope 对照通过 CAL 在全部直接候选中选择，候选数量大于每种结构方法，作为较强的完整直接比较。

历史 CAL 直接使用已冻结任务差值评价策略。计算 CAL 使用共同训练所得的辅助分配均值与已知均匀分配概率计算 doubly robust 策略收益；该辅助模型的惩罚固定为 0.01，全部方法共用。CAL 的最大值仅用于选择，不解释为确认性收益。并列时按冻结候选顺序选择。

## 计算机制与评价

潜在 U 为 Bernoulli(0.5)，四项来源要求 Wk 在给定 U 时独立，U=0、1 对应表达概率 0.15、0.70。随机分配从基线和四项单独 ADD 中均匀选取，编辑只把被选要求的状态置为一，其他要求保持原值。已经表达的要求产生相同提示。

结果概率为 `0.20 + 0.25*U + Σ beta[k]*X[k]`。三项机制的 beta 分别为：

| 机制 | 四项要求的效果系数 |
| --- | --- |
| sparse | 0.18，0，0，0 |
| signed | 0.18，−0.12，0，0 |
| dense | 0.10，0.08，0.06，0.04 |

每项独立重复按预定随机流排列政策身份，训练与 CAL 共用该排列。学习器不读取真实系数、潜在 U 或未分配结果。训练与 CAL 各包含 128 或 512 项独立任务，每项配置十六个重复，总计 96 项重复。结果抽样数为每项独立分配一次。

最终价值在全部十六种 W 状态及 U 上精确求和。每项部署动作只选择基线或一项 ADD，完整分母保留。报告收益、最优可观察策略遗憾、动作差异、祖先判定及参数选择。预定六项主要比较为 JCI123 相对共同参考、直接收缩、直接下界、直接 envelope、时间背景和 JCI12，共 36 项同时成对区间。稠密机制同时检查结构收缩对有效候选的损害。

## 历史真实结果

controlled-semantic-20260930 的 D=400 项任务按家族和冻结散列划分为训练 200 项、CAL 200 项，E=400 项任务用于本项配置的评价。每项 D 任务按预定散列选取基线、local、example、reference 中的一个分配及一套表达，读取对应真实物理请求的完整终止结果。训练任务的所有已冻结政策差值对全部学习器共同开放。结构搜索没有因此增加独立任务数量。

local、example、reference 的既有身份与测量保持不变。本项历史分析为 `POST_HOC_EXPOSED_JOINT_CONTEXT_REANALYSIS`，不建立完整 Atomic 安全要求效果或新自然总体迁移。原安全产出、有限功能、支持变化及全部失败共同报告。

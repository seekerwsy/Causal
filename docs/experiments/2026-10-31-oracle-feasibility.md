# 真实结构相对强直接方法的可行性验证

研究身份为 `NON_CLAIM_PROSPECTIVE_ORACLE_FEASIBILITY`。本轮只执行声明的结构因果模型模拟，不读取新的真实任务结果，不调用代码生成模型，不运行估计 JCI。配置为 `configs/jci-oracle-feasibility.json`，规则在首次生成结果之前固定。当前规范方法与既有冻结证据身份保持原有定义。

## 研究问题与信息边界

检验真实图形提供的充分预测集合，能否在相同数据和确认预算下，相对强直接方法增加确认数量、降低目标效应估计误差。真实结构只提供候选属性集合，不提供真实系数、真实效应或目标结果上的模型选择。该模拟不能证明 Graph 表示准确性、实际软件安全收益或估计 JCI 的收益。

所有属性在处理分配之前产生。测量属性为 C1、C2、W、X、N、D1、D2；U 为潜变量，A 为等概率随机处理，Y 为二元结果。来源 C1、C2 独立且概率均为 0.5，目标概率为 0.75、0.25；无改变条件保留 0.5、0.5。其余生成机制完全相同。八种机制包括无关上下文、混杂代理、多靶点、全部相关、弱上下文、作用抵消、上下文分布不变和属性不可观测。每种机制的全部结果均保留。

基础机制为 X 的成功概率 `0.15+0.6*C1+0.05*W`，N 的成功概率 `0.05+0.65*U+0.2*C2`，Y 的成功概率为
`0.36+0.1*X+0.12*U+0.02*W+A*(b+0.1*(2*X-1)+0.1*(2*U-1))`，四个候选的 b 分别为 0.12、0.06、0、−0.10。各边界机制的完整改动由 `controlled_transport.py::probabilities` 明确给出，并随执行源码冻结。

真实图形使用条件独立判定生成包含于观测属性的最小充分集合，始终条件化 W、A。混杂代理机制必须保留 N 和 C2，以处理潜变量代理与碰撞路径。属性不可观测机制禁止全部方法使用 X。所有方法均可使用同一完整观测属性集合。直接子集搜索包含真实结构推荐的集合，因此比较检验的是有限样本选择收益。

## 数据、拟合与估计

核心机制为混杂代理、多靶点；每种机制覆盖来源样本数 256、1,024 与目标样本数 32、128 的四种组合。每个组合有两个独立随机批次，每批次十六次重复。其余六种机制固定来源 1,024、目标 32，每批次四次重复。合计 304 次学习运行，其中核心运行 256 次。每次运行包括四个独立候选的来源和目标随机样本；相同样本提供给全部方法。

来源数据按任务序号奇偶进行两折交叉拟合。目标结果不参与预测器拟合和超参数选择。每个处理分别拟合结果预测器。Ridge 使用中心化二元特征、全部两两乘积及常数项，正则强度为 0.1、1、10、100，使用完整目标密度权重的来源留一验证。真实结构在最小充分集合与完整集合之间选择；直接 Ridge 使用完整集合；直接子集搜索使用全部 64 个集合。Elastic Net 使用相同完整设计矩阵、三折验证、冻结的惩罚集合。梯度提升使用全部原始观测属性和冻结的配置。预测概率限制在 [0,1]。

令来源和目标样本数为 n、m，来源与目标上下文密度为 p、q，令
`n_eff=n/prod(2*(q_j^2+(1-q_j)^2))`、`lambda=n_eff/(n_eff+m)`。
各方法统一使用目标预测差均值，加上 `lambda` 倍来源加权随机处理残差均值，以及 `1-lambda` 倍目标随机处理残差均值。处理残差为 `2*(2*A-1)*(Y-m_A)`，来源密度权重为完整 `q(C)/p(C)`。来源预测必须来自未包含该任务的训练折，目标预测为两折模型平均。即使推荐集合错误，完整概率修正仍保护该声明机制中的效应识别。

## 独立确认与扩大条件

每种方法按估计效应绝对值提名两个 Atomic 候选，平局按候选序号处理。独立确认每个候选使用 32,768 个配对任务；声明模拟中同一任务的两个潜在结果在给定完整状态后使用独立结果随机量。实现精确抽取差值 −1、0、1 的多项分布充分统计量，等价于逐任务抽样并汇总，不是实际代码模型结果。采用四个候选同时有效的 Hoeffding 区间，只有区间完全位于 ±0.04 的实际效应阈值之外才确认方向。全部方法共享同一确认数据。

主要比较为八个核心条件等权平均的配对确认数量增量。每个条件中差值支持为 −2、−1、0、1、2；分别构造五种类别概率的 Clopper–Pearson 区域，经类别、条件和四个比较的 Bonferroni 校正，通过线性规划计算均值界限，再平均条件界限。该区间在有限重复数量下可能较宽，未建立增量不能解释为结构永远无用。

同时报告四个候选的效应估计均方误差。使用成对、按条件分层的 1,999 次重复抽样，给出四个比较校正后的开发性区间；该区间不替代主要确认数量判定。

只有相对全部四个直接方法同时满足以下条件，结果才支持继续扩大估计 JCI 研究：确认数量增量至少 0.1、校正后的下界大于零、两个独立批次均为正增量、均方误差至少降低 5% 且开发区间下界大于零。其余结果均判定 `ORACLE_VALUE_NOT_ESTABLISHED_DO_NOT_EXPAND`，保留全部边界和不利结果。本轮不自动执行后续 JCI 搜索。

全部 304 次运行完成，核心比较包含 256 次运行、每种方法 512 个提名位置。核心条件等权平均结果如下；全部八种机制及十四个预算条件均保存在 `summary.json`，边界结果不纳入核心条件的扩大判定。

相对 Ridge 的精度改善成立于本轮声明的模型与开发性区间，确认数量相同。相对表现最好的 Elastic Net，真实结构的误差更高、确认数量更少；两个独立批次的平均确认增量分别为 −0.054688、−0.039063。全部四项比较的确认数量点增量均未达到 0.1，校正区间均包含零。

冻结判定为 `ORACLE_VALUE_NOT_ESTABLISHED_DO_NOT_EXPAND`。本轮没有扩大估计 JCI 搜索，没有新增模型调用。当前充分集合消费者尚未证明相对强直接学习器的确认收益。后续研究需要检验结构约束如何结合收缩估计和效应精度目标；直接增加结构搜索次数没有获得本轮证据支持。

本轮真实结构消费者限定为充分集合与完整集合之间的 Ridge 留一选择，不构成全部真实图形使用方式的理论价值上界。它未检验真实结构限定下的 Elastic Net 或梯度提升，也未证明结构信息不可能有用。确认数量区间较宽，不能据此宣称精确零效应；全部比较的点增量及强直接对照结果仍然没有达到预定扩大条件。

结果生成后的描述性选择诊断保存在 `derived.json`。4,096 次核心预测器选择中，真实结构选择完整集合 424 次，其余 3,672 次选择最小充分集合。与 Elastic Net 的提名集合在 200/256 次运行中相同；真实结构有七次多确认一个候选、十九次少确认一个候选，其余 230 次数量相同。与 Ridge 有十三次多确认一个候选、十三次少确认一个候选。这说明观察到的精度收益没有形成稳定的确认数量收益。

直接子集搜索最常选择 X、N 两项属性的集合，共 521 次；只选择 X 的集合为 496 次，只使用固定 W 的集合为 461 次。这些集合通常小于真实结构的充分集合。完整随机概率修正允许结果预测器在不满足充分性的情况下保持本轮目标效应识别。有限样本中充分预测与最优效应估计精度的联系仍需单独检验；选择频数本身不能证明某个集合造成了收益。

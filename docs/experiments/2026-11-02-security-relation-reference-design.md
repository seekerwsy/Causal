# 全部安全来源的目标关系参考

## 固定研究范围

对既有42项已暴露安全来源建立两个处理前关系属性参考：`retained_condition_same_operation` 与 `retained_order_with_target_operation`。采用已固定的[操作化定义](2026-11-02-security-relation-attributes-definition.md)，保留原来源顺序、任务及近重复组身份、全部未知和既有32项来源资格。没有新任务采集、代码生成、正式角色或默认方法变更。

本研究用于判断定义能否取得可靠参考及必要变化，不比较Graph与平面，不产生JCI或策略收益。此前两项代码机制任务已经暴露，其结果不作为本次参考输入或筛选条件。

## 独立参考与审查

按原始顺序每组六项，共七组。每组由两个新的独立来源上下文分别制作参考，均只取得完整原文、任务身份、完整目标政策和没有案例答案的共同定义。隐藏编辑动作、提案者操作/对象/条件/范围、旧资格理由、旧表示及全部代码结果。没有完整目标的位置明确保留目标未解决。

每份参考区分目标谓词、原始受约束操作与新增实施步骤，记录直接论元、来源引文和关系证据。每个属性记录expressed、not_expressed或unresolved。正例提供完整关系证据，零例提供候选排除理由，未知提供会影响判定的未解决事实。操作顺序统一包含来源明确表达的返回与发送；分支内容选择不自动成为操作准入限制。

每个制作上下文保存首次草稿，可以进行一次仅检查字段、枚举和逐字引文的机械检查，再保存最终参考。两次独立制作不互相读取，不接收语义反馈。全部首次输出保留。

两份最终参考固定后，每组由第三个新的上下文进行来源支持审查。审查分别判定两份目标绑定与两个属性是否得到来源支持，不修改参考或补充新的属性答案。共同模型来源及条件审查可能有共同偏差，不宣称人工真值或模型间统计独立。

## 接受规则与缺失区分

某项属性只有在两份目标绑定均获通过、两份属性标签相同且两份属性支持均获通过时，才取得本轮参考资格。其他情形保留为参考缺失，值为null，不把评审分歧强制变成来源本身的unresolved。两份都忠实保留来源未知时，可接受unresolved标签。所有42项均出现在结果中；参考资格与原Atomic来源资格分别报告，不扩大既有32项资格。

逐项报告两份标签、审查、参考资格、最终可接受值、来源及原有资格。汇总全部42项和既有32项的分布、原始标签一致率、缺失参考及来源未知。没有准确率、收益、显著性或下游因果结论。

## 来源准备门槛

每个候选属性独立判定是否具备进一步检验条件：在原32项来源合格任务中，至少24项取得本轮参考资格；expressed和not_expressed各至少四项，且每种取值分别涉及至少两个原始来源。该门槛是预定的覆盖和变化要求，不是功效分析，也不保证可识别性或预测价值。

未满足的属性不进入默认学习器，不扩大其表示比较或代码实验。满足的属性仍需单独固定Graph与强平面的实际测量和共同预算，再用相匹配结果检查真实属性相对强直接方法的改善空间。不能根据新参考取值重新挑选自然任务，不能把原始来源家族当作随机上下文，不能将提示顺序边作为因果边。

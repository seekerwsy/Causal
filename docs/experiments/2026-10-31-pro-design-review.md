## 目标效应与识别条件

每个假设 h 在新结果出现之前固定完整要求、作用范围、ADD/REMOVE、准备版本分布与处理控制流程。目标量为事前合格任务总体中该实际流程的目标环境效应。

W 在上下文准备之前测量，C 是随机准备策略，Z 在准备之后、Atomic 分配 A 之前测量。P=(W,C,Z)。E 表示来源或目标环境，不继承 C 的随机分配假设。A 在各数据角色中使用相同的已知平衡随机化概率 1/2。

Graph 错绑可以改变实际编辑对象。随机化识别实际执行流程的 ITT 效应，不能自动恢复理想完整要求的效应。事前资格筛选必须与分配之后的失败区分；后者保留在分配分母中。

共享预测器写为：

\[
m_{a,T}(P)=\operatorname{clip}_{[0,1]}
\{g_a(W,C_{S_C},Z_{S_Z})+r_{a,T}(W,C,Z)\}.
\]

来源数据进入共享预测学习，目标拟合数据进入目标修正。修正保留全部可见属性，惩罚有限。候选内部允许缩小系数，也允许使用较小属性集合；全部方法共同保留完整属性、直接共享与仅目标拟合候选。

效应估计只使用独立目标 Ranking data：

\[
\Gamma_i=m_1(P_i)-m_0(P_i)
+2(2A_i-1)\{Y_i-m_{A_i}(P_i)\},\qquad
\widehat\tau_T=\frac1n\sum_i\Gamma_i.
\]

模型训练和选择与该评价样本独立，属性在 A 之前测量，实际处理定义一致、任务独立且随机化正确时，固定假设的识别不要求来源预测模型正确。来源机制改变可以损害精度，但不通过额外来源残差改变目标估计的期望。

令 g=(m0+m1)/2，逐项有 `Gamma=2*(2*A-1)*(Y-g)` 和 `Gamma^2=4*(Y-g)^2`。因此，目标 Calibration data 选择 `mean((Y-g)^2)` 较小的候选；该损失必须在与 Ranking data 分离的样本上计算。预测值可按共同规则限制在 [0,1]，Gamma 不截断。

校准损失不能直接充当最终精度评价。精度评价使用共同独立数据上的冻结模型风险或分数。对两个固定模型，同一假设的方差差等于四倍目标预测风险差；这一关系不等于预测风险的相对降低比例与效应方差的相对降低比例相同。若主张效应方差降低至少 5%，必须计算效应方差的比例，不能用预测风险降低 5% 替代。

完整学习流程的评估重复来源拟合、结构发现、目标修正、校准和排序。固定模型恒等式不能代替对训练依赖和模型选择波动的评价。Ranking data 产生的候选提名仍有选择误差；最终确认使用独立数据和未收缩的效应估计。

## 来源残差运输反例的核对

在两域中令 Y=A，真实效应均为 1。来源 N 的成功概率为 0.25，目标为 0.75，预测器为 m1=N、m0=0，错误运输权重 w=1。此时目标预测差均值为 0.75，来源残差均值为 0.75，目标残差均值为 0.25。

lambda=0.5 的混合估计期望为 `0.75+0.5*0.75+0.5*0.25=1.25`；只用目标随机校正为 `0.75+0.25=1`。

已用八行精确概率质量核对上述反例，并调用现有 `scores` 与 `calibration_loss`：目标效应为 1，混合计算为 1.25，分数二阶矩及四倍校准损失均为 1.25。核对脚本为 `.test-tmp/pro-design-review/check-target-score.py`。这些行表示声明的数学支持点，不是独立任务或新模型结果。本项核对不是新实验。

原真实结构模拟只有上下文分布改变，其完整概率运输条件仍保留。反例不能被用来否定该冻结实验在原假设内的数值结果。

## 主路径的 JCI 查询边界

本修订在来源拟合角色中使用随机准备上下文发现结构，目标拟合数据用于结果修正；目标校准和排序结果不进入图形发现。这样可复用当前来源发现路径，并清楚地区分来源随机上下文与未来自然环境。

来源准备策略采用冻结的相同随机分配概率，使 C 的外生性知识具有明确的设计依据。按 A=0、A=1 分层运行同一保守发现程序，以避免本轮已知的处理臂混合抵消。分层后的每张图只获得对应处理臂的来源样本，不能把来源总样本数重复记为每张图的样本数。该处理不提供对全部不忠实性问题的保证，也不激活上下文效应修饰推断。

分层后图形不再包含变化的 A，根变量需要按 C1、C2 的名称明确指定。不得沿用当前联合标签的位置索引 `1:3`，使 W 获得随机上下文知识。W 的测量在准备之前冻结，Z 的测量在准备之后进行，背景知识按照这个时间身份适用。

必须分别记录三种查询：

1. 预测充分性：保留 S 后，是否还能从遗漏属性中获得关于 Y 的信息。
2. 准备上下文分离：在该来源随机准备模型中，指定的 C_j 与 Y 是否被 W、S 分离。
3. 目标环境分离：E 与 Y 是否被 A、W、S 分离。

本次来源图形能够提出第二种查询支持的候选。对于不包含于 S 的指定上下文，按处理臂查询 `Y independent of C_j given W,S,A=a`。若候选已经条件化全部上下文，不能把没有剩余上下文可检验的情形称为分离证据；完整属性模型仍作为共同的不受结构限制候选保留。

候选共享属性允许包含部分 C。图形消费者输出查询对象、精确条件集合、处理臂、数据角色和支持状态。需要两臂条件结果共享的候选，只在两臂对应查询均有支持时标为结构支持；任一查询无法判定时保留未知状态。

这些来源查询只提出共享建议，不认证未来 E 的稳定性。目标修正与独立校准负责检验建议是否改善目标预测。预测充分性和目标环境分离仍单独用于声明模拟中的真实图形诊断，不能被互相替代。

新的主路径不使用旧联合 E 分支推断未来稳定性。若另外建立包含 E 的联合模型，必须显式允许设计中的 `E -> C`，自然 E 不能继承随机 C 的无混杂知识；也不能把来源 C 的分离集改名为 E 的分离集。JCI 方法的背景知识必须与实际分配机制一致。[JCI 原始说明](https://www.jmlr.org/papers/v21/17-123.html)

PAG 中可能的路径、确定的分离与支持不足保持区分。无边、检验未拒绝和重抽样稳定都不能被称为已认证的真实独立。需要验证查询在部分图中的保守解释，以及缺乏支持的检验在搜索和定向全部步骤中的行为。

## Graph 的两个评价层

表示质量层在未用于调试规则的新根任务上比较 Graph 与平面方法。两者接收相同原文、事实与来源证据，具有相同准备和审查预算，允许平面方法合理重建关系。独立盲态审查评价完整要求绑定、允许编辑和属性测量；空输出、失败和未解决保留原分母，参考标准自身无法判定的状态单独报告。

完整绑定要求目标操作、资源、条件、否定及作用范围共同正确。只有某个实体名称匹配不能计为完整正确。当前四项作者准备任务不提供这项独立证据。

结构与精度层使用共同冻结的提示池、实际 Atomic 流程和结果账本。两种表示使用同一属性定义，分别输出自己的实际测量值。不能强制取值完全相同，也不能让属性测量读取代码或结果。未知属性使用事前固定的缺失处理规则，不转换为语义不存在。

共同提示池使全部方法估计同一个实际干预。若 Graph 与平面方法分别生成并执行不同编辑，研究对象就是两条实际编辑流程，需要额外的流程随机化和相应的估计目标；该比较不纳入本次共同账本主路径。

## 合格上下文与版本扩充

当前准备中的 `primary_mention_after_comparison` 和 `role_reference_requires_declaration` 直接对应版本因素。它们能够描述随机版本覆盖，不能单独建立真实任务中的代理混杂机制。连续的 `normalized_binding_evidence_distance` 也尚不能进入当前整数型条件检验接口。

新准备需要预先定义任务与版本共同决定的语义属性，例如完整要求绑定是否需要额外资源声明、哪些条件共同限定操作、存在多个操作时是否能够唯一确定目标。审查这些属性实际是否存在以及能否一致测量，不能根据结果反向编写有利属性。

| 条件 | 在查看新代码结果之前固定的检查 |
| --- | --- |
| 操作有效 | 任务身份、完整 Atomic 要求及非目标功能语义保持；版本池和失败处理固定 |
| 实际随机化 | C 与随后 A 的概率和顺序固定，随机化知识只用于适用变量 |
| 属性身份一致 | 两种表示使用同一语义定义，测量保留证据与未知 |
| 任务内相关性 | 相同任务的合法准备版本确实可以改变某些语义属性 |
| 条件支持 | 检查预定查询所需条件层内的变化与样本支持，不能只统计总体四种组合 |
| 辨识信息 | 在预定的多个相容机制中，上下文能够为相关结构查询提供不同约束；不要求 C 与 Y 边际相关 |
| 方法适配 | 确定性关系、缺格和连续属性得到事前明确处理，不能通过整数截断制造可检验数据 |

同根任务的 LLM 改写扩大表达与干预覆盖，全部版本仍属于同一个独立单位。新合成语义蓝图必须声明生成总体、抽样规则和共享谱系，不能替代自然任务样本。自然任务获取仍遵守结果与选择器不可见的独立来源规则。

当前 Codex 准备、本地 vLLM 只生成代码的角色划分继续适用。独立表示审查需要新的审查证据，不能把同一作者知识当作独立金标准。

主要 Graph 比较为独立表示质量层的完整绑定产出。主要 JCI 比较为 Graph 条件下加入结构建议相对同消费者直接选择的精度差。其余两乘二组合差异与方向诊断分别标明次要或探索性身份，不能在看到结果后选取有利差异作为主要比较。

当前配置将总 alpha=0.05 分为 Graph 主要家族 0.01、JCI 主要家族 0.01、具体编辑确认家族 0.03。JCI 家族包含配置中各机制相对 `direct_search` 的精度比较，在 0.01 内校正；Graph 家族没有独立数据，保持未执行，额度不转给 JCI。模拟内每次独立重复的四个候选使用同一 0.03 确认家族；这不表示跨所有场景获得了一组真实代码编辑的同时确认。

JCI 精度贡献的拟定门槛为效应方差改善点估计至少 5%、校正区间排除零，并报告独立批次。真实任务没有真效应时不报告真实均方误差，使用共同独立结果上的风险差与目标分数方差。完整学习重复的区间或根任务重抽样区间需要说明近似性质；独立编辑确认的有限样本区间与之分别报告。

正效应确认、负效应确认、安全产出、未知、有限功能与联合成功分别记录。负效应发现不计为加固收益。功能性不作为分配之后剔除安全 ITT 任务的条件。

## 验证顺序与实现边界

七个阶段继续为表示、优先选择、假设冻结、干预与随机化、测量、结果组装、推断与报告。全流程规则与任务角色在新结果之前固定，最终提名在独立确认数据产生前固定。来源发现与目标拟合使用其各自事先分配的开发角色。

验证顺序固定为：

1. 数学与数值边界：复用目标校正及损失恒等式，检查错误来源预测、代理机制改变及结果机制改变下的目标识别。
2. 真实查询与同消费者：分别评价预测充分集合、来源上下文分离集合及目标环境分离集合，检查结构到共享候选的转换。
3. 总体独立信息与估计结构：同一规则下测量可辨识性、有限样本支持、定向与候选损失；按 A 分层的成本进入预算。
4. 完整学习重复：校准选择、估计误差、提名及正负确认全部保留；真实风险最优候选只用于隔离诊断。
5. 真实表示与上下文评价：取得独立绑定审查及实际属性表后，评价共同结果账本上的组件增量；模拟精度不能替代这一证据。

新配置保留原八种机制，并加入代理机制改变、上下文直接结果通路与结果机制改变。代理变化使用 `P(N=1|U,C2,E)=0.05+alpha_E*U+(0.85-alpha_E)*C2`，alpha 来源 0.65、目标 0.20。完整配置的十一种机制、两个批次、每批八次重复构成 176 次预定运行；默认复现仅执行两种机制、四次运行。其他预算点仍须在新结果之前固定相应配置。

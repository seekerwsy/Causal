# 明确要求与未确定事项的完整来源状态检查

## 测量对象和旧结果

此前完整清单的严格确定性资格为3/6，没有启动表示比较。本轮测量原文已识别的要求、其条件和来源未决定的事项是否一并保留。它不认证全部要求或实现细节已经确定，也不将旧3/6重新计分。来源范围继续包括任务软件和交付物，报告者提交流程单独保留范围判断。

保留全部六个任务及原文，不增加或替换来源。它们已经经过来源反馈，当前研究身份为已暴露材料上的测量开发。本轮不建立新的独立表示收益或自然总体效果。

## 固定参考和来源审查

把此前首次参考A的完整明确要求、未确定事项、排除项及全部引文逐字作为候选来源状态，不删除未确定事项或合并成确定结论。新的独立来源审查者读取完整原文、候选状态、首次参考B和既有来源核对；不读取任何新方法输出。审查内容为明确要求来源支持与完整性、未确定事项的忠实保留、条件与范围、没有强制消除歧义、证据正确。

来源状态允许保留可选方案或未知规范地位。部分要求明确但某个绑定方向未确定时，两部分分别保留；不能把整项要求丢弃，也不能选择方向。可选、未定等表述可以不同，必须保留原文同样的非强制性和未定范围，不能变成确定义务、反向义务或实际软件性质缺失。

六项审查条件均通过的任务取得本轮来源状态参考资格。至少五个取得资格才允许启动本轮测量比较，其余任务仍保留并计为未取得完整成功；不足时不替换来源、不修改候选后重交。该资格与此前零未知资格分别记录。

## 两种实际方法与预算

按固定输入顺序每组三个任务，共两组。Graph 和强平面各使用每组一个新的独立提取上下文，同样的原文、物理行索引、定义和机械检查机会。它们不读取候选参考、来源审查、历史方法结果或另一表示。各上下文允许一次机械检查并提交唯一最终输出，没有语义评分反馈。

Graph 使用 `compile_source_propositions` 形成既有规范图形，规范作用和描述作用分别显式记录；未知不转换为 false。未确定事项需要实际来源节点、相关条件或未确定关系，不能仅在自由说明中声明。`source_requirement_inventory` 保留明确规范表达式，同时通过 `source_state_readback` 返回全部实际命题、作用标记、表达式路径、条件所有者及未确定语义关系。完整读出不认证源提示覆盖或实际软件性质。

强平面方法可以使用全部关系、完整谓词、条件、量词、重复来源与未知项，可以重建结构，使用相同的检查和推理能力。输出完整来源状态清单，不能得到隐藏参考。两种方法均保留全部任务和失败，Graph 类型校验不提供独占语义信息。

## 共同评价

方法输出固定并匿名化后，由两个新的独立评审上下文依据完整原文和已审查来源状态评价十二个方法位置。完整成功要求：明确要求完整且忠实，未确定事项完整且忠实，没有新增确定规范，绑定、条件和逻辑角色正确，重复规范来源覆盖，以及实际引文有效。已知信息不能通过把整项任务标为未知来省略；未知也不能通过强制确定来取得成功。

程序汇总每方法在六个固定根任务的完整成功数，未知、无效表示及未合格来源均保留为未成功。两组上下文不支持总体显著性结论，不设置或宣称独立组件收益门槛。局部成功只支持本轮已暴露源文的测量可行性。软件安全、功能性、JCI 效应与正式 Atomic 资格均未测量；没有代码生成、新服务支出、受保护任务或默认方法切换。

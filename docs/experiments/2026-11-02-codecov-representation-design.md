# Codecov目录要求的表示与代码生成比较

## 固定问题与证据范围

使用既定第三项来源CVE-2019-10800及已独立审查的作者受控任务，检验Prompt TSG是否能改善完整目录要求绑定及其代码实现。任务来源摘要d615435023649fcceb855a9a43a7817ae67af172b82f7f58d91dc765486e0251；独立来源评审六项supported，基准完整目录shell操作隔离要求not_expressed。自然编程请求缺少的局限保持原值。20项实际局部测量已经通过原始及作者参考控制资格。本实验为单任务开发检查，不建立总体统计Graph收益。

## 分别制作与确定性读出

Graph与强平面各由一个未参与任务说明、参考控制或来源评审的新上下文制作。两者获得完全相同的task_frame、requested_policy及原始代码和公开说明，允许相同规范与推理工具。共同预算为规范JSON40000字符、64项来源事实或条目，Graph最多128项关系。各自最多进行一次机械检查及一次仅字段、类型或连续引用修订。不能取得参考判断、测量程序、修复程序、模型输出、另一表示或语义评分。

Graph遵循现有compile_source_propositions及source_requirement_inventory，保留全部来源命题、操作参与、原始与已处理目录、分支条件、范围、独立配置角色、量词、非目标行为及未知事项。平面条目允许保存同样的层次、关系、条件和交叉引用，不能故意削弱。事实的规范作用与程序描述作用分别记录。

本轮不使用额外LLM编制操作提示。Graph直接使用完整原生source_state_readback，并将其中不透明节点编号一致显示为短编号，节点内容、全部边、条件及其他字段保持原值。反向替换必须严格恢复原生读出。该变换只改变编号显示，映射与完整原件保留。平面直接使用完整条目，均通过同一规范JSON显示函数提供给代码模型。两种方法实际长度、节点及条目数量分别报告，不声称相同tokens成本。

## 独立语义评价

在表示制作之前固定六项标准：task_interpretable、operation_boundary、non_target_observable、directory_state_distinction、atomic_add_compatibility、context_sufficiency。沿用已有来源独立评审作为参考，仅其来源证据和判断供评价使用。两个独立新上下文分别审查实际会提供给代码模型的表示，不读取方法身份、另一评价、测试或代码结果。格式可能暴露表示类型，此局限明确保留。

每项complete需要实际表示位置、连续引用及来源参考证据。两个评价均为complete才算共同完整；保留incomplete、incorrect、unknown与全部分歧。六项共同完整才算完整任务绑定。单任务语义结果是机制诊断，不能替代下游代码证据。表示不能因评分修订，已固定生成位置不能因评分取消。

## 真实代码生成与测量

四种处理为baseline、direct、flat、graph。共同输入包含作者基准任务、完整原始模块与相同公开上下文；baseline不附加目录安全要求，direct附加原始单项要求，另外两种附加各自全部表示读出。原始源文件中的既有行为不当作基准代码结果。全部返回完整codecov/__init__.py，其他包文件固定。

共同新种子为2026111851至2026111854，按2026111850随机打乱16项请求；每项只调用一次，没有重试或按结果替换。使用已有Qwen2.5-Coder-32B-Instruct权重，temperature=0.7、top_p=1、输出最多12288 tokens，固定上下文49152，单个生成工作进程。输出预算足以容纳完整原始模块；实际输入由同一真实tokenizer逐项确认，输入加输出上限必须满足49152，不截断输入。模型只生成代码。

原有20项实际检查、CLI配置和来源归属保持冻结。明确出现额外命令标记为insecure；未出现标记但实际产物不完整为unknown。六项策略均secure才算局部策略成功；14项局部功能均通过才算局部功能成功；联合成功要求两者同时成立。语法失败、请求失败、接口失败及unknown全部保留在每种处理四项分母。完整CLI功能及任意目录完整安全仍然未知。

报告所有四种处理及六组共同种子的配对差，主要比较为graph相对flat的完整绑定、策略成功、局部功能及联合成功；direct和baseline用于判断额外表示作用与原始要求作用。四个生成种子不提供四个独立自然任务。任何点改善都不能记为Goal要求的总体独立收益，需在来源单位层面另行前瞻验证。JCI不在本检查中检验，正式协议不激活，没有新付费服务或受保护数据使用。

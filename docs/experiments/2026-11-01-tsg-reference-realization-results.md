# 混合语句的实际重写结果

按[预定开发设计](2026-11-01-tsg-reference-realization-design.md)，一个新的隔离上下文对三个已暴露失败问题各提交一次实际编辑。它获得原文、固定政策、来源角色测量、条件审查，以及既有规范 Graph 的准备诊断；没有读取历史 Graph／平面比较或本轮后续评分。允许将依赖被移除表达的事实改写为原文支持的独立陈述。

全部首次输出冻结后，用共同逐字编辑函数生成三项实际文本，独立字符重建一致。两个新的隔离评审只读取匿名原文、政策与实际修改文本，分别判定完整目标移除、非目标保持、没有新增反向要求、没有解决无关歧义。

## 固定分母中的实际判断

| 原任务 | 两位四项全部通过 | 实际结果 |
| --- | --- | --- |
| SymPy 标量长度 | 通过 | 两次期望语句改写为迭代器数量和 numpy 观察的独立陈述，保留实际零值、例子和版本 |
| Matplotlib 阈值 | 通过 | 移除明确偏好与预期，将混合语句改写为可能不兼容变更的条件性陈述，保留比较对象、当前规则及不确定性 |
| Sphinx 基类名称 | 未通过 | 明确 should 要求已经移除；保留的纠正性对照被两位评审判断为仍完整表达目标要求 |

完整编辑产出为2／3。两位评审的逐任务产出判断一致，全部证据引用有效。三个原任务保持原分母，没有重新抽取、修补编辑或替换评审。原始文本、首次编辑与全部失败判断均保留。

SymPy 和 Matplotlib 的结果表明，纯删除以外的来源支持重写可以在本轮实际输出中保留关联事实。比较式、数值或类名仍可作为事实或条件对象出现，是否仍表达目标要求需要独立语义判断，不能只检索字符串。

Sphinx 的结果暴露来源角色与输出评价之间的分歧：首次来源测量及条件审查将实际示例中的对照保留为事实；本轮两位输出评审认为，该纠正性对照在剩余问题语境中仍具有完整规范作用。当前证据不能判定是哪一项测量存在错误，也没有证明事实角色在编辑后保持不变。描述事实与承载纠正要求可能同时成立，需要分别表示与检查。不能以 Graph 的事实标签认证规范要求已经移除。

## 证据范围

三个问题是从旧失败中选定的开发诊断，来源角色审查属于本方法的额外输入。没有给新的平面流程相同输入和预算，因此不能与旧平面成绩计算收益，也不作总体或显著性声明。本轮没有建立独立表示增量、自动提取准确率、安全代码收益或功能性收益。

完整要求的范围、同一句话的多重作用、指代展开和编辑后的再次测量仍是后续公平比较必须固定的内容。当前工作只证明已执行的实际文本及其自动评审结果，不把未解决的角色分歧改成成功。两个评审共享模型来源，不能称为人工金标准。

# Agent 失败归因研究候选与 Pro 评审

## 研究状态

记录日期：2026 年 10 月 3 日。四项候选均处于研究设想阶段，尚无对应实现、实验结果或新理论证明。文献覆盖范围与新颖性需要独立核查。本文用于选题评审；项目当前执行授权和方法以 README 指向的既有文件为准。

选题要求同时包含研究影响和实质方法创新。需要解释重要的 Agent 能力限制，形成可推广的算法、理论或可检验规律。结构化表示、增加模型调用、组织既有模块和局部准确率改善，都需要进一步说明科学贡献。

## 候选一 学习并细化保留干预信息的归因表征

### 研究问题与预期影响

从自然语言执行历史、动态上下文与工具状态中，自动发现支持失败归因所需的变量和关系，并通过新证据纠正表示遗漏。预期影响是让结构化轨迹具有可以检验的诊断含义，同时减少阅读完整历史和重复执行的成本。

例如，同一个“读取文件”事件可能涉及错误路径、旧文件版本、新文件配旧模型输入，以及正确输入后的错误转换。这些情形需要不同干预；表征需要保留能够改变干预响应的区别。

设 h 为执行前缀，φ(h) 为结构化表示，U 为事先规定且在不同前缀间语义一致的可执行干预族，p_h(u) 为干预后的成功概率。候选目标为：

\[
\phi(h_1)=\phi(h_2)\Rightarrow
\sup_{u\in\mathcal U}|p_{h_1}(u)-p_{h_2}(u)|\leq\varepsilon.
\]

该性质表达规定干预族下的响应预测充分性。其适用总体、干预对应关系和概率估计必须明确，并加入表示规模或成本约束，排除为每个前缀分配唯一标识符的平凡解。类别合并需要控制整个类别的响应直径；两两接近关系通常不具有传递性。支持主动取证时，还需要保留证据读取的响应分布。有限重放只能提供规定范围内的证据，无法自动识别唯一机制或单次失败责任。

### 方法设想

1. 以动作、实际输入输出、数据版本、来源及状态变化建立初始表示，区分观察事实、模型推断与尚未验证的关系。
2. 保留符合记录的多个解释，计算它们对允许干预的不同预测。
3. 选择能够区分预测的证据获取操作，包括读取原始请求、检查上下文转换、查询可恢复状态和真实重放。
4. 在相同表示出现不同干预响应时，寻找遗漏字段，拆分相应状态或修正关系。
5. 输出原因集合、证据范围、表示假设及未解决的歧义。

具体分析对象可包含事件、带版本的数据和任务约束。需要分别记录环境事实、Agent 在可观察输出中表达的判断，以及独立核验结论。外显推理文本的陈述不能直接视为模型内部真实状态。

### 尚需建立的贡献

因果抽象、抽象细化和主动诊断都有成熟基础。Predictive Representations of State 已经以给定动作后的未来观测预测表示状态；Value Equivalence 已经依据指定策略与价值函数下的 Bellman 更新定义模型等价。候选需要解决不完整日志、黑盒语义转换、动态执行路径和有限查询条件下的变量发现与细化，给出可计算规则。仅增加字段或让 LLM 再次检查日志不足以确立创新。

### 决定性证据与主要困难

在真实可重放任务上检查被合并状态的干预响应；检验算法能否自动找到遗漏区别；在独立任务上比较归因误差、表示规模和完整诊断成本。强基线共享原始信息与证据权限，包含完整文本、固定结构化表示和经典抽象细化方法。

主要困难包括干预跨前缀的语义对应、表示错误与采样噪声的区分、潜在原因集合不完整，以及抽取和细化成本超过节省的分析成本。

## 候选二 分离修复效果 修复搜索能力与随机重试收益

### 研究问题与预期影响

一次成功续执行同时受到修改内容、修复生成器和后续随机采样影响。研究目标是定义可以比较的修复效果，并分析归因如何依赖替代动作规则，减少因重试次数和搜索策略不同产生的归因差异。

在独立且成功概率固定为 p 的尝试中，K 次至少成功一次的概率为 1−(1−p)^K。这是说明搜索次数影响的数学例子；实际自适应搜索一般不满足独立同分布条件。

固定前缀 h_i、原动作 a_i、替代动作分布 q，以及后续策略和预算，考虑：

\[
\Delta_i(q)=P(Y=1\mid h_i,\operatorname{do}(A_i\sim q))
-P(Y=1\mid h_i,\operatorname{do}(A_i=a_i)).
\]

该量描述指定替代规则下的成功概率变化。它与已经发生的单次失败的反事实责任需要分别定义。

### 方法设想与贡献要求

使用可恢复前缀，将保留原动作的续执行与按 q 替换动作的续执行进行匹配比较，统一后续策略和计算预算。预先规定合理替代规则的范围，估计效果及不确定性，研究不同替代规则下的归因稳定性。将提出修复、筛选修复和估计效果所用的证据分开，处理适应性搜索与停止造成的选择偏差。

平均干预效果公式属于已有因果推断基础。潜在新贡献需要体现在 Agent 动作空间、有限预算估计、修复分布选择和稳定性判定的具体算法上。

### 决定性证据与主要困难

独立改变候选数量、生成器质量、重试预算和真正的动作影响，检查归因结果是否把搜索机会误记为责任。比较保持原动作重试、随机合法替代、语义修复及现有执行式归因，报告相同总成本下的估计误差和后续任务收益。

主要困难是合理 q 的定义、动作合法性、环境恢复、后续策略改变，以及真实任务中较高的执行方差。没有定义清楚的替代规则时，不存在自然唯一的效果数值。

## 候选三 单次失败责任的部分识别与主动取证

### 研究问题与预期影响

即使能够估计修改后的成功概率，也可能无法唯一确定已经发生的这次失败在另一动作下会怎样。研究目标是在明确机制假设下，计算单次责任能够获得证据支持的范围，并选择最有价值的新增证据。

Agent 改变动作后可能改变后续调用数量、消息结构和执行路径。相同随机种子不自动规定两个反事实世界的外生随机因素如何对应。

### 方法设想与贡献要求

明确目标责任量和外生随机性语义；建立与原始记录、环境状态和已执行干预相容的机制集合；在该集合中计算责任上下界；选择能够缩小边界的请求读取、状态核验或干预；证据不足时保留原因集合。

例如，能够确认关键资料未进入模型输入，但无法判断资料在检索阶段遗漏还是在上下文压缩时删除。原始工具返回或压缩前后的请求记录可以改变相容机制集合。

相容集合、责任量及优化方法仍待形式化。Robust Counterfactual Inference in Markov Decision Processes 已经针对相容因果模型推导反事实转移概率的闭式界限，并构造稳健反事实策略；其方法假设已知 MDP 转移概率。候选需要提出适用于动态 Agent 轨迹、计算可行且具有明确假设范围的算法。

新增干预观测能够减少成功概率估计的不确定性，但未必消除单次反事实的机制歧义。例如，若原动作和替代动作的成功概率均为 1/2，两个结果可以完全相同，也可以完全相反。这两种机制具有相同的干预边缘分布，却对原动作已经失败的个体给出相反的替代结果。主动取证必须说明它约束了哪项机制，不能承诺通过重复执行消除所有反事实歧义。

### 决定性证据与主要困难

在具有可核验机制的执行环境中测量范围覆盖、宽度与新增证据的价值；加入观察相同但机制不同的任务条件，检查方法能否保留必要歧义；在实际 Agent 任务上报告哪些假设可验证、哪些依赖建模选择。

主要困难是机制集合过宽导致空泛边界、集合遗漏真实机制，以及外生随机对应无法验证。实际重放通常支持干预分布，对单次反事实的额外主张需要独立依据。

## 候选四 任务信息充分性与执行过程中的可解性

### 研究问题与预期影响

研究信息获取、转换、传递和删除如何改变完成任务的可能性。局部组件可能全部满足自己的要求，而整个系统已经缺少完成总体目标所需的信息。希望输出能够核验的任务信息不足证据，并推导后续策略受到的限制。

例子：任务要求比较两个产品的增长率。数值提取组件保留两组数值，却删除数值与产品名称的对应关系。计算组件可以正确计算增长率，最终仍然无法确定哪个产品满足要求。

设两种合法情形 w_1、w_2 要求不同正确答案 y*，后续可获得的全部信息为 Z。若 Z(w_1)=Z(w_2)，且 y*(w_1)≠y*(w_2)，并且后续记忆、工具及外部访问都无法区分二者，那么仅依赖这些信息的策略无法保证同时正确。等概率二元情形中平均正确率至多为 1/2。此例要求排除其他信息通道；它属于基础不可区分性论证，本身不构成新的理论贡献。

### 表征与算法设想

表征包含任务要求区分的情形、能够区分这些情形的证据，以及证据在所有可访问信息通道中的保留和恢复条件。分析要处理信息冗余、互补和重新获取。

1. 从任务目标和执行证据中生成合法情形集合，要求不存在对这些情形都正确的统一答案或预算内策略。具有不同唯一答案的情形对是其中一种证据。
2. 验证当前保留的信息是否可以区分这些情形。
3. 检查剩余工具与记忆访问是否能够恢复这种区别，并计入访问权限和剩余预算。
4. 沿执行过程定位区别消失的位置，以及共同造成不可恢复状态的操作集合。
5. 输出可核验的反例、适用条件和必要的信息恢复要求。

信息恢复要求表达完成任务所需的条件；满足该条件是否足以恢复成功，还需要执行证据。相同答案文本之外的开放任务，需要改用可接受结果集合或策略价值定义。若三个情形的可接受答案分别为 {a,b}、{b,c}、{a,c}，每对情形都有共同答案，但三个集合没有共同答案。因此，一般算法需要处理多个情形及完整的恢复决策树。

### 尚需建立的贡献

核心困难是自动发现任务必须保留的区别，并在不完整规格和动态工具访问下验证反例。人工预先列出全部关键字段，会把核心推断工作交给设计者。候选需要与信息充分性、通信复杂度、有限记忆决策、可诊断性及程序验证研究建立精确关系。

MemTrace 已研究信息演化及最小错误操作集合；The Decomposition Tax 已研究接口信息损失。EIR 的第 2 节已经依据未来正确输出定义历史等价类，并通过等价类数量给出必要信息；第 3 节同时规定保留、访问及恢复条件。Context Compaction Theory 的第 4 节把单次上下文生成与单向通信复杂度联系起来。候选需要进一步建立自动反例构造和验证方面的具体贡献，新颖性目前未确认。

### 决定性证据与主要困难

检验算法能否自动发现关键区别，是否正确预测受同一信息障碍限制的后续策略，以及恢复所指出区别后能否改善独立任务结果。报告有效反例比例、验证覆盖、证据获取成本和错误认证比例。对无法检查完整未来信息访问的情形，保留受限结论。

主要困难是合法情形生成、完整信息通道的界定、自然语言语义等价的验证，以及理论对象与实际黑盒 Agent 之间的差距。

## 共同的方法问题与评价要求

早先讨论的主动取证、风险控制和表征稳定性保留为独立可评审的子问题。

- 主动取证：共同选择读取更多记录、细化表示、执行哪项干预和增加多少重复次数，以归因歧义的减少衡量价值。
- 风险控制：分别处理抽取遗漏、候选误排除和随机执行误差，提出明确的排除与停止条件，研究自适应选择下的有效性。
- 表征稳定性：对相同底层执行进行无损日志分段、字段重排和等价重命名，检查归因及语义干预对象是否保持一致。摘要需要单独检查是否保留目标信息；一般有损摘要不承诺归因保持不变。
- 证据公平性：完整文本、结构化表示与算法比较共享事实、关系和查询权限。计入提取、图维护、搜索、重放与验证成本。
- 归因验证：最终步骤标签匹配、干预效果估计、反例正确性和独立任务改善分别报告，不能互相替代。

### 候选一的具体研究条件

可以研究成本受限的“前缀—实验响应表”和可执行谓词集合。谓词描述身份、版本、实际进入模型请求的数据、对象关联和约束范围。LLM 提出谓词后，实际记录或程序负责核验；缺少证据时保留未知。

算法需要处理字段相同但响应不同的情形，以及推测字段与原始记录冲突的情形。响应估计误差、字段发现和最终验证分别使用适当证据。完整成本包含提取、维护、读取与重放。

独立贡献需要证明：在明确的谓词语言、响应间隔和可实现性条件下，联合选择谓词与实验具有查询优势；或者自动发现可迁移、能够反转修复选择的状态区别。比较对象应包含同信息完整文本、固定结构、共享谓词语言的 CEGAR 和预测状态学习。若表示规模几乎随任务逐一增长，或完整成本消除收益，就缺少有用抽象的证据。

### 候选二的具体研究条件

固定可恢复状态、原动作、替代规则、后续策略和资源约束，两组均重新执行后续过程。分别报告候选生成、筛选和独立效果估计的成本。干预失败及非法替换的处理规则必须在观察结果前规定。

Pro 对 CAR 的判断限定于论文与公开说明：其重放比较和最晚有效位置规则，与重新执行原动作的匹配控制具有不同含义。CausalFlow 的至少一次修复成功也受候选数量和生成器影响。这些差别是否系统性改变现有结论，需要实际实验验证。

若修复规则集合包含始终保留原动作的规则，最坏效果至多为零；任意无帮助的合法动作同样会使稳健指标失去诊断意义。合理替代规则的范围属于需要明确说明的研究假设。

决定性实验应独立改变候选数量、生成器、后续重试次数与真实动作影响，比较修复成功机会、冻结政策后的平均效果、归因排序及独立任务净收益。单纯缩小数值或改善置信区间，支持规范化评估价值；重要实证贡献还需要证明原有测量会系统性误导系统修改。

### 候选三的具体研究条件

需要定义实际证据 e 下替代动作 b 的反事实成功概率，并明确相容机制语言及跨世界随机因素的对应关系。与候选二的平均干预效果分别解释。

若所有允许证据和实验在两个机制下具有相同分布，任何依赖过去证据的自适应调查也无法区分它们。缺失请求记录可能通过读取恢复；跨世界耦合歧义可能持续存在。

重新考虑独立研究需要一项具体结果：在调用数量与路径可变化、部分外生事件有真实记录的语义下，计算跨时间一致的责任界，并说明哪些记录能够缩小界限。验证需要比较边缘概率界、canonical SCM 优化、Robust CFMDP 和 Gumbel-Max 假设敏感性。新增机制假设、集合覆盖、界宽与证据价值均需分别报告。

### 候选四的具体研究条件

精确问题是：给定可执行任务约束、某个真实执行时刻的状态、全部可访问信息及剩余恢复能力，自动生成可独立检查的证据，证明部分合法情形无法由预算内的统一策略正确处理。输出包含信息不足证据、经验证的恢复策略或证据不足。失去保证正确的能力，仍然允许在某个实际情形中偶然答对。

证据生成需要联合分析合法情形、可接受结果、恢复操作、权限和成本。有限确定性环境可用 belief-state 规划表达可解性；该标准表达及通用求解器调用本身不确立创新。不能用 LLM 没有找到恢复策略作为不可解证明。

在执行模型不完整时，可选取经过验证的少量合法情形，并赋予分析中的 Agent 更强且成本不更高的恢复能力。若该条件下仍无法统一完成任务，才能推出原系统受到相应限制。未知工具可能恢复信息时，应保留证据缺口。证明中不能引入违反任务约束的情形，也不能遗漏实际存在的恢复途径。

独立贡献需要自动提取规模较小的信息不足证据，其查询或求解收益来自事先规定的结构条件；或者发现能够跨后续策略预测的信息损失规律。比较对象包含 EIR 有限枚举、给定正确模型的 belief-state 求解、self-composition/CEGAR 和 MemTrace。人工指定全部关键字段后的成功，无法证明自动发现能力。

决定性任务包含关系删除、冗余副本、互补信息、可恢复资料、权限变化、侧面信息通道与预算限制。分别测量证据有效率、错误认证率、覆盖、完整成本及跨策略预测。恢复所需信息后的实际改善单独报告。

### 共同问题与资源判断

Pro 建议保持一个主要研究对象。候选二提供执行式研究的测量原则，候选三提供反事实结论限制；候选一与四可以共享提取与细化操作，但需要分别证明各自目标。将全部候选组织成统一系统，无法自动增加方法贡献。

主动取证需要明确的优化目标及不同查询的识别能力。联合风险控制需要每项风险有可验证的上界；模型自行给出的抽取置信度不满足这个要求。表征稳定性与证据公平性属于基本评价要求。

资源假设可以限定为一至两名研究者、CPU 执行环境、固定基础模型和单机推理或等价额度，无需预设大规模强化学习训练。真正成本集中在可恢复执行、合法情形生成、机制核验和独立测量。举例而言，100 个前缀、每个 6 个条件、每条件 50 次续执行，共需 30,000 次后续运行，候选搜索与独立任务评价另计。这个数值仅说明预算构成，不构成实验授权或样本量建议。

离线轨迹适合研究日志与人工标签；支持真实干预需要可恢复环境和实际模型请求。增加同一任务的随机执行次数，无法增加独立任务数量。验证环境应包含可核验机制的工具任务和可保存状态的真实软件工作流。

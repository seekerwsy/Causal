# 完整命题的来源绑定

## 来源锚点与完整谓词

绑定分别记录原文位置、完整谓词、参与对象、输入与配置、适用范围、条件和时间归属。原文中的 API 名字、代码调用或表达式是可以定位的来源锚点；它们自身不能认证实际执行，也不能把一个例子的参数和结果推广至整个操作类型。

完整命题保留否定、结果、量词、模态和替代分支。同名 API 在不同参数、输入或配置下的调用分别保留来源位置。对象属性可以通过操作及其结果的关系表达；接受这种表达需要核对完整谓词和每条关系的来源支持，不能只凭操作名称或端点类型判定等价。

查询涉及字面字符时，字符值以明确的 JSON 字符串字段指定，引用符号与实际数据分别表达。查询本身没有明确区分时保留歧义；不得根据方法输出更改查询。已有冻结查询及其未知状态保持原身份。

## 对象组成与实际参与者

`part_of`从明确组成部分指向容器，端点均为data_object，记录同一对象范围内的真组成关系，允许非独占归属。它不表示内存所有权、别名、先后或因果关系；自环及有向环无效。条件或实例范围不明时保留未确定关系，不能通过对象名称补充归属。

`source_participation_paths`保留要求主体沿组成关系到实际参与者的路径，以及参与者的 `used_by`／`produces` 关系。主体不会改写为直接参数，容器的其他部分不会自动成为要求主体。`source_proposition_measurement`仍要求显式完成声明及实际角色；引用、支持和对照关系不提供组成连接。读出的 `subject_binding_paths`与 `object_component_relations`保存可核对的路径和原始组成边。没有组成关系的图继续使用直接连接规则和原字段。

路径支持只说明实际表示中的连接，不能认证来源蕴含、一般范围、Atomic编辑资格或功能正确性。新规则不用于重评分旧材料，旧归档使用自身源码复现。

## 表达式与条件所有者

`source_proposition_readback` 逐个命题保留完整表达式。`expression_path_node_ids` 记录从表达式根到当前命题的路径；`expression_condition_attachments` 保留路径上实际存在的条件边、方向和命题所有者。兄弟分支专属的条件不能归给当前分支。父项和成员之间已有的条件关系保持实际原值，不补充新的自然语言含义。

AND、OR、NOT 的类型、成员及来源证据共同限定表达式。OR、NOT 中的成员不成为独立要求；未声明的组合结构保持 `undeclared`。`selected_expression_root_node_ids` 只列所选命题所属表达式，指代或背景引入的其他表达式保持上下文身份。操作本身的执行条件、非门控背景和顺序与命题条件分别读取。

时间短语需要保留其所属分句和关系端点。表示后续修改发生时间的短语，不能自动成为对象状态或先前操作的时间条件。现有顺序边和要求拥有的顺序关系保持原归属；原文未表达严格先后时，不补充严格先后。没有声明某项条件，只表示这项来源信息未声明，软件实际是否存在该条件仍可未知。

## 来源作用与不确定性

规范作用、描述作用及完整绑定由实际命题节点分别记录。全文修复目的、节点类型、API 名称或时间事件不能替代规范作用证据。相同来源片段可以承载不同命题及不同作用；只有完整谓词及适用条件一致时，才能合并同一命题的多处证据。

`source_unit_ids`、逐字内容和原文边界提供可复算的位置。来源单元可以包含更广上下文，判断只能采用实际受到支持的内容。条件所属分句、字符身份、输入假设或具体实例存在歧义时保留未知。读出继续标记 `source_entailment_verified=false`；结构正确不认证语义正确，也不赋予 Atomic 编辑、因果关系或正式确认资格。

2026-11-01 十二位置来源参考研究使用其冻结归档中的互斥引用层级规则，结果保持8/12通过及四个未知位置。当前规则不用于重新评分该研究。后续语义比较需要在新输出之前固定共同规则、独立参考、全部任务分母及判定条件。

# 方向一致性检查后的完整新数据验证

此前固定新数据的96项计算因一张包含确定有向环的图未通过独立核验，原结果保持失败身份。原生 R 重放确认同一矩阵，95项其他图通过当前必要检查。本轮只修订方向建议进入学习器前的一致性检查，原始图、固定任务分母、直接对照及描述性骨架对照保持各自信息。

## 方法规则

`attribute_direction_checks` 检查66变量矩阵的格式、确定方向无环性、箭头非祖先约束和随机上下文的必要限制。不能满足检查的估计方向状态为 invalid；条件检验没有支持时保持 unavailable。这些状态不表示任何处理效应为零，也不删除任务或结果。

`context_terminal_sets` 对 invalid 方向不提议受限末端集合，返回完整64项属性及空的确定可达集合。原始邻接、连通背景、六项几何候选及十项传播候选保留原数据；打乱建议跟随同一个可用末端集合。有限惩罚、完整目标修正和公共基础预测模型继续存在。检查仅是必要方向条件，不认证完整 PAG 可实现性、真实因果关系或环境稳定性。

`attribute_run.py` 保存逐单元方向状态与整批 invalid／unavailable 数量。`attribute_verify.py` 使用独立矩阵传递闭包重算环、相互可达分量、箭头祖先矛盾及原建议，核对学习器实际接收到的范围。原生 R 重放仍比较全部原始矩阵，不能通过删除矛盾边获得通过。

## 已暴露机制核对与实现代表单元

`direction_guard_check.py` 在上一轮全部96项实际冻结图上检查消费者：95项通过必要检查的建议保持原值，一项方向矛盾保留完整属性；全部几何与传播候选保持原值。`verify_direction_guard.py` 使用独立矩阵实现核对这些状态。该检查不重新评价数值收益，不消耗新验证材料。

实现代表单元使用 `configs/jci-direction-validity-canary.json` 与 `--limit-cells 1`，保留已暴露批次2026110451、2026110452。完整运行现有生成、发现、拟合、目标修正与核验链，包含原生 R 重放；统计身份始终为部分实现检查。没有通过时检查实际输入与实现，不生成新数据。

配置为 `configs/jci-direction-validity-fresh.json`。两个未使用批次2026110651、2026110652，每批每机制16项，共96项。数据机制、64项属性、多父汇合、辅助512项、来源128项、目标拟合32项、独立校准32项、排序64项、积分131072项、499次排列、骨架最大三阶及原生多数定向全部保持此前设计。

七项直接方法、同骨架几何、打乱及传播三项结构对照、有限惩罚及目标修正网格保持原规则。全部51项比较共同使用原 Bonferroni 校正；主要下游机制的实际 JCI 必须相对全部十项对照达到至少5%平均方差减少、校正区间下界为正及两个批次分别改善。全部96项均纳入，方向无效及负对照不能被排除。只在全部单元数值核对和原生图重放完成后报告科学门槛。

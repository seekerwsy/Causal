# 来源关系属性的固定六任务检验

## 科学问题与范围

本次检验来源关系属性是否存在测量改善空间。使用原结构消费诊断的全部六项已暴露 APPS 任务及原查询，不增加或替换任务，不使用代码结果。已有二十四项完整来源状态比较与首次六项结构补充保持原身份。当前不是独立总体收益检验，不激活默认学习器。

独立来源参考先按原文与查询确定组成谓词及七项关系属性，随后通过独立来源审查。Graph 和平面分别在新的制作上下文中重新回答同一组谓词查询。双方取得同一原文、相同查询、来源参考所固定的谓词含义和引文，以及各自原二十四项比较的首次表示；不取得参考属性答案、资格、结构补充、条件修正或旧评分。原始 Graph 与平面已经具有相同的一轮制作机会；本次双方再各有一次相同的准备与机械检查机会。

Graph 可以补充原始语义记录，必须实际编译并读取选定命题及其关系。平面可直接求取关系，也可保留全部交叉引用、重建结构并使用同样的公共接口。所有方法都允许阅读完整原文，不能通过禁止平面结构推理制造差异。实际推理用量与精确模型构建不可观测，不声明严格计算成本相同。

## 来源参考与共同属性

每组三项，共两个新的来源参考上下文，只读取完整原文与原查询。将查询所问组成划分为二至八个来源谓词，公式可以保留为一个原子谓词，不额外展开算法或算术。组件编号只定义任务内查询位置，不作为跨任务变量。全部无序组件组合均进入固定位置；不同任务的关系数量不改变任务权重。

每个组件组合记录七项属性：

| 字段 | 允许值 | 来源含义 |
| --- | --- | --- |
| same_operation | yes / no / unknown | 两个谓词是否明确关联同一个操作或定义过程；未说明操作不能当作不同操作 |
| subject_overlap | yes / no / unknown | 两个谓词的参与对象是否具有至少一个共同指代；名称相似不能确定对象相同 |
| joint_relation | conjunctive / alternative / conditional / other / unknown | 同一来源断言中的合取、备选、前提与结论或其他关系；不按图形运算节点的字面名称评分 |
| left_condition_role | none / antecedent / consequent / scope_constraint / unknown | 左侧谓词在当前查询来源规则中的条件作用 |
| right_condition_role | none / antecedent / consequent / scope_constraint / unknown | 右侧谓词在当前查询来源规则中的条件作用 |
| left_source_role | normative / descriptive / mixed / unknown | 左侧谓词的来源作用，不能把领域性质自动变成程序义务 |
| right_source_role | normative / descriptive / mixed / unknown | 右侧谓词的来源作用 |

共同对象指代与操作关联依据来源含义确定，原始记录中的端点不相交不能直接转为语义 no。条件规则的等价逻辑编码可以不同；可能性与实际发生、量词范围与实际输入分别保留。条件作用存在嵌套且单一允许值不足时记录 unknown 并说明局限，不猜测默认角色。

两份新的独立来源审查各处理三项，在任何方法输出前固定参考是否得到来源支持。未合格参考仍进入六项主要分母，双方该项主要成功均为零，不替换任务，不根据方法输出重新判定参考。

## 方法制作、实际测量与评价

Graph 与平面各使用两个新的三任务制作上下文，原分组保持不变。每个上下文提交唯一首次草稿，可执行一次字段、引用及实际接口机械检查，并保存最终输出；不得读取语义审查答案或在结果出现后重新制作。Graph 同时提供完整来源记录、共同组件编号到实际命题的映射，以及七项属性判断。平面提供相同组件位置与七项判断，允许附加任意可审查结构。

制作后程序编译全部实际 Graph，通过 `source_proposition_readback` 和 `source_binding_relations` 产生实际测量；平面保存全部原始输出。空位置、编译失败、引用无效和不完整任务均保留为失败，不用新任务补充。物理失败在发生位置终止并记录，不依靠异常恢复改变方法答案。

所有首次方法输出固定后，按预先固定的匿名位置交给两个新的评价上下文，每组包含三项任务的两个方法，共六个位置。评价者依据已冻结参考与来源，逐字段核对答案，并核对 Graph 的回答是否由实际记录和读出支持。等价来源解释按联合含义判断；未知不能自动当作错误确定值，也不能用来源不支持的未知回避已知事实。

唯一主要描述指标为完整任务成功：来源参考合格、实际测量有效、全部预定关系字段与未知判断正确，且实际记录支持回答。固定分母为六项。另报告先在任务内部平均的字段错误率及六项任务的等权平均，不将关系数量或评审数量当作独立任务。任何结果都不具有本轮总体显著性或确认性意义；两组三任务不能达到 Goal 的独立统计收益标准。

## 决策规则

强平面达到固定参考上限，或 Graph 没有改善完整任务成功和任务等权字段错误时，停止扩大本条测量路线。参考含义无法稳定确定、关系属性不能形成一致定义或不存在可用变化时，不接入默认 JCI。出现描述性改善时也只记录候选改善空间，后续需要单独前瞻验证，不能把这六项重新命名为独立验证。

本次没有相匹配的随机处理与代码结果，不能测量下游效应精度。参考语义结构与因果结构继续分别定义。下一阶段的合法数据必须先比较强直接方法加入参考属性后的改善空间，再比较相同属性下的 JCI，最后比较实际 Graph 与实际平面测量。不得人为给这些来源属性指定模拟结果作用，并声称获得自然任务收益。

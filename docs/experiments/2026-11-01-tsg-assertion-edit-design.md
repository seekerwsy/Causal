# 多处要求与断言编辑范围的开发比较

## 固定问题和范围

上轮六个固定开发目标中四个通过两位语义评审。两个未通过位置分别存在完整要求重复、诊断事实与规范断言共用证据区间。本轮修订同一个 `prepare_expression_removal`，以显式来源出现集合和实际断言编辑集合准备一项政策的移除。

沿用六个固定目标、原文和两份已冻结的来源参考，不补充目标或改写旧结果。全部材料已暴露，本轮属于针对性开发比较，不能证明独立总体收益。Graph 和强平面方法各使用一个新的隔离规划上下文；六个任务同处一个规划上下文，不按六个独立学习重复进行显著性检验。

## 消费者与共同信息

同一完整要求的多处来源需要显式列出。Graph 消费者逐处检查独立断言、完整逻辑表达式和叶项绑定，并保留各自条件。来源出现被声明等价，仍须独立核对完整谓词、配置、量词及范围，不能仅根据相同 API 或相同片段自动合并。OR、NOT 成员不能各自成为移除政策，顶层 AND 容器不能合并成一项。

实际编辑的逐字范围与支持要求的证据范围分别记录。编辑可以只移除较大证据区间中的规范断言，保留其中的事实；每项编辑需要绑定实际来源出现，其区间必须属于该出现的证据范围。其他要求、共享条件和来源指代依赖继续检查；无法通过机械检查时保留未解决。机械通过仍不认证规范断言已完整移除、来源出现集合已穷尽或残余语义正确。

Graph 规划者获得相同完整原文、目标引文、共同规则及该任务旧流程实际形成的完整查询 Graph。平面规划者获得相同原文、目标引文、共同规则及旧流程自身完整事实和查询测量。两者均不读取来源参考、历史得分、新评审或另一表示。两者可以保留全部关系、检查完整原文及重建结构，可以读取同一编辑实现并使用相同机械检查机会。Graph 的实际类型检查不作为独占的语义参考。

两个规划上下文各首次提交六个完整编辑提案，不接收语义反馈后重交。程序从实际引用生成修改后文本，Graph 提案经修订的准备函数，平面提案经同一个 `apply_prepared_edits`。缺失、无效引用和未解决位置保留，不能更换目标。

## 独立评价

方法输出及匿名位置在编辑评审之前固定。两个新的评审上下文只读取完整原文、目标、两份冻结来源参考及十二个匿名实际修改后提示，使用上轮相同六项条件：来源参考一致受到支持、完整目标要求移除、非目标保留、条件归属保持、没有反向要求、剩余文本完整。原文引文必须有效；未知和未准备位置均为没有获得成功产出。

每个方法报告六个固定根任务的完整成功数、实际编辑数及失败原因，不把十二个方法位置当作十二个独立任务。没有预定表示增量或显著性声明；两种方法都完成全部目标才支持本轮编辑机制准备充分。方法差异仍属已暴露材料上的开发诊断。

角色信息和实际 token 用量不可观测时保留未知，不宣称计算成本完全一致。来源判断及评审共享模型来源，不称人工真值。软件安全、完整功能性和 JCI 效应不在本轮测量中。当前 Atomic 家族、默认 JCI、受保护数据与正式协议不改变，没有新服务支出。

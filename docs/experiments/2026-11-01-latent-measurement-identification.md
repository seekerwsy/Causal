# 多代理机制模型的识别审查

本次仅检查一个明确声明的模型是否提供足够的数学识别条件，不实施新 JCI 消费者、不生成新观测、不作收益实验。解析程序构造四个概率分布情形、八个上下文条件层，全部恒等式及预测边界核对通过。独立 Codex 数学审阅也推导了相同恢复公式。

## 明确的额外假设

在固定 C、W、环境 E 的条件层中，U 为二元潜在处理前属性，比例为 π，三个二元代理满足条件独立测量：`P(Vj=1|U)=aj+bj*U`。要求 π 严格位于 0 与 1 之间，三个 loading 非零，概率有效，并有跨环境一致的第一代理正向 loading 用于潜在标签对齐。

来源随机 A=0、1，各概率二分之一。Y 的条件均值为 `q_a(U,C,W)`，并在给定 U、C、W、A 后与测量误差独立。允许 C 对 Y 直接作用。来源迁移预测额外假定 q 在环境之间相同，目标代理参数和潜在比例可以改变。目标所需 C、W 层及两个潜在类别必须具有来源结果支持。

这些是新模型假设，不从目前的 PAG 自动推出。三个相关提示属性不自动满足条件独立测量误差；三个隔离但同模型来源的审阅也不能自动当作三个独立测量误差。

## 测量参数恢复

省略条件层下标，令 s=π(1−π)，m_j=E[Vj]，c_jk=Cov(Vj,Vk)，t 为三个代理的三阶中心矩，则：

\[
m_j=a_j+\pi b_j,\quad c_{jk}=s b_jb_k,\quad
t=s(1-2\pi)b_1b_2b_3.
\]

令 D=c12*c13*c23。非退化模型下 D>0，

\[
s=\frac{1}{4+t^2/D},\quad
b_1=\sqrt{\frac{c_{12}c_{13}}{s c_{23}}},\quad
b_2=\frac{c_{12}}{s b_1},\quad b_3=\frac{c_{13}}{s b_1},
\]
\[
\pi=\frac12\left(1-\frac{t}{s b_1b_2b_3}\right),\qquad
a_j=m_j-\pi b_j.
\]

这里采用 b1>0 的标签约定，不能将全部协方差替换为绝对值。π=1/2 时 t=0，但只要 D>0，仍能恢复参数；真正退化的是比例边界、零 loading 或缺少标签方向。恢复结果还必须满足 aj 与 aj+bj 均为合法概率。

## 结果机制与目标预测

在来源每个随机处理臂中，记 μ_a=E[Y|A=a,C,W]，d_aj=Cov(Y,Vj|A=a,C,W)。条件独立给出：

\[
\Delta_a=\frac{d_{aj}}{s b_j},\qquad
q_a(0)=\mu_a-\pi\Delta_a,\qquad
q_a(1)=q_a(0)+\Delta_a.
\]

三个代理应产生相同 Δ_a，这是来源可核对的限制。目标代理模型产生后验 r_T=P(U=1|V,C,W)，于是：

\[
g_{a,T}(V,C,W)=q_a(0,C,W)(1-r_T)+q_a(1,C,W)r_T,
\qquad g_T=(g_{0,T}+g_{1,T})/2.
\]

该恢复允许 C 直接影响结果，没有使用工具变量排除限制。目标随机结果如果在相关条件层具有代表性和正支持，其总体分布本身可以恢复目标 q；少量标签主要限制估计精度。依赖来源迁移则另外需要 q 不变，目标无标签代理不能验证此条件。

## 实际解析核对

| 情形 | 变化 | 核对结果 |
| --- | --- | --- |
| identified_shift | 来源比例0.35、目标0.65，代理参数同时改变，C直接影响结果 | 恢复测量参数、来源结果均值和目标平均预测，误差不超过1e-12 |
| half_mixture | 两环境潜在比例均0.5 | 三阶矩为零仍可恢复，目标平均预测误差不超过1e-12 |
| signed_proxy | 第二代理 loading 为负，第一代理保持正向 | 协方差符号得到保留，恢复及预测核对通过 |
| unobserved_outcome_shift | 来源与目标代理分布保持第一情形相同，目标两处理臂结果均值额外增加0.08 | 来源迁移预测无法发现该变化，目标平均预测误差为0.08 |

第四情形与第一情形具有相同来源观测分布和相同目标无标签代理分布，却具有不同目标平均结果函数。本例中的共同均值移动不改变处理效应；它说明来源信息不足以认证目标预测机制，不宣称已有目标随机结果失去 ITT 识别。

三个二元代理有七个观测自由度，该二类模型也有七个连续参数。因此，三代理分布在一般内部区域不提供多余等式来单独验证全部测量独立假设；符号、概率有效性及来源结果提供的额外约束可以反驳模型，通过它们仍不能证明未来机制稳定。

## 对 JCI 贡献的判定

PAG 不能单独确定潜在维数、共享潜在类别、测量误差独立性、结果误差独立性、标签的跨环境语义及 q 的不变。若把这些假设作为已知事实，同数据的直接联合潜变量学习器也能使用上述恢复路径，得到同一目标预测函数。

所以本次数学识别检查没有建立 JCI 的独立价值。后续若研究代理组选择或机制约束，需要给直接联合学习器相同代理、上下文、结果标签和校准预算，并分别验证图形实际提供的约束。当前没有以该假设模型替换单一活动方法，也没有把额外无标签属性的收益归入 JCI。

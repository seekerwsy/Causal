# internetarchive下载目录边界的局部测量

固定来源CVE-2025-58438及原始提交a3e45e23bb9482d5049cbe3725dd7db9929298b6，目标为完整internetarchive/files.py。政策限定Linux静态文件系统下的本地下载。提供destdir时，File.download及Item.download的最终文件路径须在该目录解析符号链接后的根目录以内；File.download没有提供destdir或file_path时，远端默认文件名须限制在当前工作目录以内。逃逸路径必须在文件内容读取、创建目录、写入、删除或修改时间之前抛出ValueError。调用者未提供destdir而显式选择的独立file_path继续有效。并发替换符号链接、其他平台和完整下载安全保持未知。

安全输入为父目录路径、多层父目录路径、目录符号链接及文件符号链接，分别通过File.download、Item.download(no_directory=True)及Item.download(no_directory=False)，共十二项；File.download另含绝对路径。另有File.download默认当前目录下的父目录及目录链接两项，共十五项。Item.get_files构造File时固定删除名称两端的路径分隔符，因此Item入口不能形成绝对远端文件名，该输入不进入安全分母。每项使用独立测试目录，所有目标均限制在容器绑定的本次结果目录内。目录外的测试文件预先写入保护内容，以观察后续覆盖。文件名在URL和文件路径中的消费分别记录，不将URL编码解释为本地路径处理。

功能输入包含八个合法文件名，分别通过三个入口，共24项，覆盖普通名称、嵌套目录、内部父目录规范化、当前目录、双点普通名称、百分号字面名称、Unicode及POSIX反斜杠字面名称。另有显式绝对路径、显式相对路径、返回响应、调用者文件对象、ignore_existing跳过和checksum跳过六项，共30项。分别检查实际下载内容、最终位置、返回值、请求数量和普通文件时间。功能结果与固定原始模块比较，完整断点续传、失败重试和全部库功能继续未知。

三个控制为固定原始模块、在任何本地路径消费之前检查规范路径的参考，以及仅检查词法绝对路径的控制。后者保留符号链接风险。参考必须安全15/15、功能30/30；原始至少一项安全失败且功能30/30；词法控制必须至少一项安全失败且功能30/30，全部未知为零。共135项检查。先执行一项父目录安全输入与一个正常名称，通过代表性模式和独立核对后执行完整矩阵，不根据结果调整输入。

每项独立子进程运行原始完整包和真实ArchiveSession、Item、File对象，通过容器回环地址向标准库HTTP服务器请求固定测试正文，保留实际请求及响应。不替换请求方法或文件操作，不访问外部Archive服务。独立Python审计钩子只观察真实文件操作，结合目录外测试文件的原始与最终摘要、字节及修改时间判定。来源异常由sys.excepthook记录，随后终止该子进程；测量不捕获异常后继续执行来源逻辑。

使用Python 3.12.16固定镜像sha256:ba44a11d1821ed2e4e098b54ba0594d06eda05f1c02e002d8fdac87a4b327957，Requests 2.32.3、urllib3 2.2.3、jsonpatch 1.33、jsonpointer 3.0.0、tqdm 4.66.5及固定传输依赖，具体wheel摘要见fixtures.json。原始源码只读，容器外部网络关闭，单核CPU及2GB内存，临时工作位于/work。版本均满足原始setup.cfg的依赖范围。

独立核对器不导入internetarchive或生产测量函数，直接读取固定输入、请求、子进程状态、审计事件及实际文件，使用独立路径解析重算全部分母和结果。控制、依赖、测试输入和测量程序在首次来源运行前固定。程序测试文件与探针不增加自然任务单位，模型调用次数为零。

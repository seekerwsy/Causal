# 隔离准备资源合同

状态：`PROPOSED_OWNER_AUTHORIZATION_REQUIRED`。适用协议：`tsg-discovery-development-20260929`。本合同仅修改第4节准备实例的资源计量；任务、研究问题、干预额度、统计规则和研究截止时间保持现行协议规定。

每个新的TSG或Raw实例使用相同模型和思考设置，拥有两个顶层准备请求：准备与同来源审查。工具调用产生的全部模型输入、缓存输入、输出和思考输出另外逐项记录。顶层请求数与模型调用计量分开。

两流程采用相同上限：每实例实际输入加输出合计1000000token；其中未缓存输入加输出不超过100000token；从实例登记时间开始360秒。思考输出已包含在输出计量中，不重复相加。共同平台提示和工具说明照实计入输入，缓存输入照实计入总量。实际计量使用Codex运行日志，不能由实例作者估算。

父实例在两次顶层请求之间和运行中读取计量；达到任一上限时终止该实例的继续准备。计量可能在一个模型调用结束后才更新，实际超限保留超限状态；该实例不能取得符合合同的准备资格。任务位置及失败保留，不以其他候选补充。每项任务两流程获得相同允许输入、模型、思考设置、请求上限及时间、token上限。

本合同生效后使用没有准备历史的独立实例，并在任何新代码生成前冻结输出和审查结果。现有九个实例作为准备计量和设计检查材料保留原身份，不授予新合同下的主研究准备资格。相同开发来源可以进入新的独立准备，来源哈希顺序和角色规则保持不变；不能按旧提名的目标或质量选择来源。

本合同的授权不代替F0/F1、来源及测量资格或独立人类评价，也不增加1752次生成上限或24小时窗口。运行日志只保存本研究子实例的来源身份、开始／结束时间、模型／思考设置、顶层请求数和token计量；不复制其他会话正文、账户额度或凭据。

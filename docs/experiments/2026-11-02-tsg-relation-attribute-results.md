# 来源关系属性的六任务结果

## 实际范围

依据[固定设计](2026-11-02-tsg-relation-attribute-design.md)，全部六项已暴露 APPS 来源及原查询进入比较。两个来源参考上下文确定26个组件、50个关系位置，各关系七项属性；两个新的来源审查上下文判定六项参考均合格。Graph 与平面各由两个新的制作上下文作答，原文、共同组件、查询、工具及额外准备机会相同，均不读取参考属性答案或旧结构补充。最终两个新的匿名评价上下文审查十二个方法位置。

全部十二项最终测量有效，六张实际 Graph 完成原生编译和关系读取。Graph 第一组首次机械检查未通过结构声明约束，最终文件按允许规则补充声明，属性答案未变。其他三组首次机械检查通过。全部首次草稿、检查、最终表示和评价分别保留，不使用最终编译成功替代首次制作身份。

逐项完整一致数量差来自三角形规则：Graph 与参考全部一致，平面四个对象重叠标签与参考不同。点积两种方法均有三个不同标签；Levy 猜想分别有七个和九个不同标签。其余三项两种方法全部一致。**全部字段差异集中于 `subject_overlap`**，其余六项属性全部一致。

## 对象定义与参考解释边界

全部十二个位置的三项语义评价均为通过。评价理由保留了共同操作关联、谓词直接对象和规则参与对象之间的解释差异。字段的字面一致由程序按冻结参考计算，不能把该结果扩大为独立语义真值。

来源参考中，50个关系的 `same_operation` 和 `subject_overlap` 均为 yes；这两项在本批材料中恒定。实际 Graph 和平面在点积输入与结果、Levy 整数与表示成分之间区分了对象身份，部分 no 标签获得语义评审支持。三角形的输入对象与结果颜色保持也涉及谓词直接对象及其比较论元的区别。操作的全部参与对象、谓词直接作用论元及背景上下文需要分别定义；共享操作不能自动证明两个直接对象相同。

这些分歧说明当前 `subject_overlap` 的操作化定义仍不足以支撑准确率的强解释。首次参考、资格、计分和方法输出保持冻结，不在看到答案后重标。当前点差不证明 Graph 更准确，也不证明对象关系能改善 JCI。计划中的 `stop_scaling_this_measurement_route=false` 仅表示没有触发该计划的相对数量停止条件，不构成扩大实验或接入默认学习器的依据。

## 与研究目标相匹配的后续条件

独立[安全来源可用性审查](../../.test-tmp/security-attribute-bridge-audit-20261102.md)逐项阅读已有42项安全任务，保留32项既有来源资格及10项未通过位置。它没有依据表示表现选择任务，也没有重新资格判定。候选属性聚焦于完整 Atomic 目标：来源是否表达另一条限制同一操作的非目标条件，以及是否表达目标操作与保留操作的先后关系。原文同时存在明确表达和未表达实例；未表达只描述提示内容，不表示软件属性不存在。

这两项仍缺少独立的逐项属性参考。它们必须先明确完整目标、操作指代、直接论元、非目标规则及条件或顺序的来源范围，保留未知，避免把 ADD/REMOVE 透露的目标状态作为独立属性真值。对象重叠暂不生成数值，直到论元角色及共同指代定义得到独立检验。

这42项没有同批随机分配、生成代码、独立安全与功能测量、Oracle资格或目标校准结果。此前 E400 安全实验对应另一批任务和三个表达状态，不能与这里的任务身份直接合并。来源的非恒定关系支持进一步检验候选变量，不提供下游增益证据。当前默认方法保持原有身份，新的关系属性不进入效应学习器。

本轮没有调用实验主体代码生成服务，没有新的受保护任务、正式角色分配或协议激活。隔离上下文共享模型来源与项目规则；精确模型构建、实际推理用量与模型之间的统计独立性不可观测。表示形态可能暴露方法，不能宣称完全盲态。

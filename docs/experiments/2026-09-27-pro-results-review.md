# 网页端 Pro 对已执行一日研究的反证审查

时间：2026-09-27。来源：[既有 Pro 对话「重规划因果研究」](https://chatgpt.com/c/6ab7cd2d-f9f0-83ee-a9f0-191fc4675a1f)。本次通过此前已授权的网页端交互提交了本地已独立复算的结果摘要，要求 Pro 优先寻找可推翻结论的错误。Pro 没有读取仓库或原始数据；以下是**外部方法意见**，不是新的观测或独立结果复核。事实仍以冻结输入、原始输出和本地校验为准。

## 审查改变了什么解释

1. 公共收据先泄露完整私密载荷、再覆写成正确计数，却得到旧观察器 `secure_yield=1` 和 `contract_joint=1`。这否定“旧正标签必然代表完整私密安全”的解释；它不推翻旧标签的算术，也不证明原 144 份代码发生相同泄露。尤其要核对**政策目标本身**：旧 P/H 文本排除指定公共输出。若目标是所有承载私密字节的实例，观察器漏报；若政策只约束预列私密路径，把通过标签扩写为全面保密就是构念越界。公共输出是非目标行为对象，不等于可以接收未授权私密字节。
2. 臂盲、固定的观察器仍可能因政策改变代码实现分布而产生臂间差异性测量错误。旧自然临时文件合法删除后被漏测，新公共输出负控制错误通过，故冻结通过率既不能等同真实安全率，也不能直接当其保守下界。四份原正标签的事后复放和完整载荷快照扫描仅支持各自有限规则，不估计通用漏报率。
3. 新 12 个人工合同上的 P−N +25pp 是旧观察器通过产出的点值；Holm p=.46875。H−P 严格联合 +4.17pp，p=1。P/N 直接观察到的 `umask` 违反均为 0/24，但 N 有一份 `ambient_unknown`；零差不证明无副作用或等价。P/H 大量运行错误要求保留分配后所有请求和 unknown，不能只取成功执行代码解释机制。“局部安全收益伴随非目标代价”这条吸引人的整体叙事未由这次三项主比较支持，具体反例仍有诊断价值。
4. TSG 原留出三题各视图全选 N，固定策略在这三题的**已观测行动**相同，因此该有限面板上不可能识别表示信息造成的策略价值差。新 12 题结果后定义的精确目标数视图导致 12/12 匹配支持不足，是表示到学习器接口的诊断，不能作为 Graph 有害或 Flat 更优的独立测试。

## 这轮不再增加模型请求

Pro 建议停止新增 vLLM 请求。当前没有同时满足以下条件的新增 TSG 或自然独立评价：未暴露且确实不同的任务身份、同源文本和冻结可比端点、合格观察器、结果前定义的共享政策池及**实际产生不同选择动作**的视图、独立任务级评价和统计规则。重复旧任务种子只增加实现噪声信息；临时编写同作者合同只增加受控开发材料，不能填补自然迁移或跨任务选择价值。此建议与本地来源库存、TSG 行动映射及 Oracle 反例一致，故本轮将余下模型额度保持未用。单批 A800 服务时间超出事前 90 分钟上限仍须保留为资源偏差，不能因停机而消失。

下轮须先二选一并冻结政策范围：仅约束明确私密目标路径，公共输出泄漏另设合同/安全审计；或采用一个新版本的完整 Atomic 信息流要求，声明私密输入、公共输出、允许公开的派生内容和可接受的**中间写入轨迹**，使公共对象不得暂存未授权私密内容。后一选择是新政策 ID，不能在旧 P 标签上无声追加。任务内表示还需区分实例初始存在、创建/截断/替换、保留/销毁、公共与私密角色、允许内容及进程全局状态。自然原文没有规定的行为保持 `UNSPECIFIED`，若研究者补入共同接口则标自然适配。新 Oracle 的正、负和 unknown 控制应覆盖实际采用的代码形式，包括短暂公共暴露，且只能宣称有限测量域。

SCM 矩阵以每机制的独立模拟重复作配对真值收益与 Monte Carlo 误差；代码政策以去重任务及其全部臂/版本为独立单位。二者没有共同的任务 bootstrap。原计划六项比较若曾作为一个固定多重性家族，不能在看到结果后把已完成三项局部 Holm 比较当作六项验收的替代品；未冻结或无合法估计量的项保持未检验。新文件批次的三项 Holm 只能保留其**独立冻结的局部家族**身份。下轮每项须写明估计对象、数据身份、随机化或重采样、是否事前冻结、检验家族和解释范围。

Pro 的总判断与本地核查一致：算法模拟对结构门与直接策略的收益/风险给出有限而有辨识度的证据；JCI 当前消费者无行动增量；TSG 独立选择价值、自然来源政策效果和完整私密安全端点未得到验收。这个 Goal 的研究报告应明确这些未完成项，不能把测量修补或更多控制当作已完成的论文级验证。

## 研究范围与证据对象

拟议研究考察保持既有规范义务的普通提示编辑：示例、表达组织、可选实现线索、角色重述。来源表示仍须覆盖规范要求、条件和范围；本次主要候选池限于普通内容政策。每项政策保持Atomic，一项编辑对应一个完整目标。TSG负责从来源节点或子图产生假设、检查精确编辑、提供共享关系属性。因果部分负责随机提示效果识别与基于历史随机效果的选择学习。

拟议主算法为任务平衡的干预效果Ridge，以及冻结选择器的新随机评价。现阶段的FCI/GFCI搜索结果用于说明已有结构消费规则的边界：结果邻接同时包含预后关系，未能单独识别效果修饰属性。本方案不将邻接转为学习准入或正则权重。新的结构研究需要另行明确识别问题和消费者。

评价对象限定为已知任务、冻结政策、模型与观察器条件下的新生成效果。已暴露任务继续保留开发身份，任务总体推断与context-modifier确认性推断未启用。实际模型为Qwen2.5-Coder-32B-Instruct，只执行代码生成。Codex准备TSG、绑定和提示文本；安全结果由程序化观察器独立测量。

## 三个抽象层级

**来源语义层。** TSG使用对象、操作、命题、来源片段四类节点。关系包括参数与角色、来源支持的数据流、条件与范围限定、示例及重复表达支持。完整命题保存否定、量词、模态和来源坐标。没有表达的事实保持未指定，无法解析的事实保持未知。

**精确干预层。** 保存原提示版本、编辑坐标、目标命题、完整两臂文本、具体函数/API/常量/对象、非目标义务与适用接口。编辑同一要求的多处表达需要完整绑定。不同任务的政策继续具有独立身份。

**共享学习层。** 对精确政策提取有限属性，允许跨任务共享预测信息。总读取上限与单次分块上限、角色重述与角色改变保留不同语义。即使学习属性相同，也不合并完整政策身份。

拟议的三个关系属性为：编辑单元是否直接关联被测操作；关联对象是否位于来源支持的输入—操作—结果边界链；同一对象和作用域内是否还有未编辑表达完整承载相关义务。它们是分配前语义特征，不能解释为已经识别的因果关系。

## 候选形成与公平比较

从实际来源的普通内容节点开始，扩展到解释该目标所需的对象、操作、条件、范围与重复表达。每流程最多检查六个锚点，优先覆盖不同普通内容类型，再按来源顺序补足；每锚点最多一个编辑。每流程提交至多两个有顺序候选，备用候选只在新结果出现前处理准备失败。

允许删除、无损组织变化、等义表达变化、绑定既有操作的可选实现线索添加。保持一项Atomic变化，不连续生产措辞版本以占据候选位置。六个锚点、两项提交或资源上限任一达到即停止。被提名编辑必须完成语义审查；未知和无合格编辑分别保留。

TSG与Raw共享原文、调用合同、候选范围、提交上限及资源规则。公共属性提取发生在双方提名冻结后，统一读取来源、实际编辑差异及共同端点说明，处理两边所有候选，隐藏流程身份和结果；不读取某个准备流程完成的图，结果不返回发现流程。公共阶段成本单独对称记录。候选池不能由待评价的关系选择器预先筛选。

Graph与保存相同关系信息的Rich-Flat用于信息保真检查。主比较为TSG准备流程与Raw准备流程，关系特征增量在同一个候选池中评价。方案中的具体案例仅用于解释方法，不能作为只向某个流程提供的候选答案。

## 随机效果与两个主比较

全部编辑直接作用于同一个真实来源基准B。令μ_t(a)为任务t在全文提示a下的有限安全产出概率，编辑效果为τ_tk=μ_t(E_tk)−μ_t(B_t)。历史P/N方向统一转换为编辑减来源。

共同动作集为{B,E_G,E_R}。Rel使用非关系属性与三个关系属性；NoRel使用相同学习过程和非关系输入；Mean使用相容历史政策的任务平衡平均效果。所有规则保留不编辑动作，基准预测为零。新结果出现前冻结拟合、候选、方向和动作。

两个主比较分别为：

- `Δ_D = (1/12) Σ_t [μ_t(E_G) − μ_t(E_R)]`：两个流程所提交编辑的有符号安全效用差。共同B项抵消。
- `Δ_L = (1/12) Σ_t [μ_t(π_Rel) − μ_t(π_NoRel)]`：关系属性改变选择后带来的固定面板价值差。

Δ_D的负值可以同时包含有价值的有害编辑发现。该指标不能概括全部科学发现价值。Rel与Mean、各编辑相对B的效果和普通功能变化作为次要输出。Mean同样使用随机效果，相关比较不能命名为因果方法与非因果方法的比较。

历史训练上限为23个任务、37项旧合格候选。新语义范围、真实来源对照和方向转换后可用多少，仍需实际核对。候选多的历史任务不能获得更高总权重；任务交叉验证必须一并移除该任务全部候选和共享结果。新任务结果不参与当前选择器重训。

### 低维效果学习的具体规则

每项训练记录保存任务、完整政策、B/E全文和hash、规范义务保持审查、原随机分配与请求身份、两臂全部分配结果、模型与采样及Oracle版本、属性及其来源依据。缺少真实来源对照、分配记录不完整或测量不可比的记录不进入新训练集。生成失败与未知继续进入原分配分母；训练资格不能按效果方向筛选。

NoRel最多10维，Rel最多13维，截距另计。自由文本向量为0维。Pro给出维度与支持规则；本地将属性字典具体定义为以下拟议编码，启动前须用来源实例核查定义一致性：

| 属性块 | 编码 |
| --- | --- |
| 目标内容类型，5维 | 示例记录、组织标记、可选实现线索、角色重述、重复表达；按完整编辑目标赋一个类型 |
| 编辑类型，3维 | 添加、删除、保持命题含义的表达变换 |
| 明确相关义务，1维 | 来源是否明确表达相关义务；其同对象同范围关系另由Rel处理 |
| 编辑长度比例，1维 | `min(1, (删除字符数+新增字符数)/max(1, B字符数))`，按已冻结编辑坐标计算 |
| Rel专属，3维 | 操作直接关联、输入至边界链关联、同对象同范围的剩余义务承载 |

完整示例块的组织变化仍标为示例记录；组织标记指标题、分区等组织目标。重复表达仅用于明确存在另一个完整承载表达的目标。无法唯一归类时保留UNKNOWN；这种编码不改变精确政策语义。

支持检查只使用当前训练折：离散取值至少4个独立任务，二元对比另一侧同样至少4个；同任务多候选不重复计数。连续长度至少4任务有值且方差非零。最终拟合在全部新合格历史任务上重复相同检查，O/V不参加。缺失或不支持取值按该属性块训练均值填补，标准化后贡献零；原始UNKNOWN保留，不增加缺失指示列。均值和方差按训练任务等权的已知值计算，零方差列删除。

损失为`(1/H) Σ_t (1/m_t) Σ_k (tau_hat_tk − beta0 − x_tk' beta)^2 + lambda ||beta||²`。截距不惩罚，标签不标准化。lambda网格为{0.01,0.1,1,10}；两模型使用相同任务留一折及验证损失，各自选择参数，平局取较大lambda。少于5个合格任务时只使用重新合格子集的任务等权均值。没有合格历史效果时不拟合，直接采用B。

预测截断至[-1,1]，B得分为0；最大编辑得分严格大于0才采用编辑。并列优先B，其余按完整政策hash排序。关系列全部无支持或两模型动作全部一致时，报告本面板算法决策增量未发生；仍可评价具备资格的实际提示编辑。

### 双向影响的聚合次要对象

另外登记`Q_f=(1/12) Σ_t tau_tf²`及`Δ_Q=Q_TSG−Q_Raw`。它同时计入正向和负向效果，单位为平方比例。它不表示机制数量或平均绝对效果。

每臂10次在结果前固定为5个独立双次块，令`D_tf,r=Y_tf,r−Y_tB,r`，计算`Q_hat_f=(1/60) Σ_t Σ_(r=1..5) D_tf,r D_tf,r+5`。两个因子来自独立生成且具有同一冻结分布时，乘积期望为tau_tf²。相同基准请求可由两流程共同引用，各双次块必须独立。缺少独立性或同分布依据时不启用该对象。

估计值可以为负，保持原值，不截零、不开平方、不按新结果选择候选。回到同一B动作时其真实增量和对应乘积均为零。具体案例仍报告方向与不确定性；Δ_Q只承担一个预定聚合比较，不能据此宣布哪个案例已经建立机制解释。

## 统计设计与本地核算

O比较族合计错误率0.05，分配为Δ_D的0.02、Δ_L的0.02、Δ_Q的0.01。前两个比较分别以Hoeffding的0.016和Bernoulli KL的0.004构造交集区间。未启用比较保留原额度。该配置为新拟议研究的规则，不变更旧冻结分析。

共享请求先合并系数。独立组贡献范围为[l_g,u_g]，Hoeffding半宽为：

`h_H = sqrt(log(125)/2 × Σ_g (u_g−l_g)^2)`。

全部12任务的对比动作均不同、每臂10次独立生成时，`h_H=sqrt(log(125)/120)=0.200589`。仅d个任务动作不同时，`h_H=sqrt(log(125)×d/(144×10))`，对比绝对值最多d/12。d=0时区间为[0,0]，不执行KL反演；这表明冻结动作完全相同，不能据此推断不同算法一般等效。

相等系数的正负组各有10d个独立Bernoulli结果时，分别反演`(10d) kl(p_hat,p) ≤ log(1000)`，区间相减再乘d/12，最后与Hoeffding和理论范围[-d/12,d/12]相交。它约束固定面板平均值，允许各任务不同成功概率。适用依据为独立Bernoulli和的Chernoff界及对平均概率的凹性界，随后使用联合错误率控制；不要求把异质结果当成同一二项分布。下表的功效枚举另行明确采用同质概率情景。

不同权重或依赖配置采用真实独立组范围的Hoeffding；缺少更紧约束时，组范围宽度取该组全部绝对系数之和。不能确认独立的请求合组。KL适用条件缺失时不启用，不通过有效样本量替换或重新分配其额度。

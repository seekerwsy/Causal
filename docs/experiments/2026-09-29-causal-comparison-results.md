## 结构变量与查询

每个任务按候选身份固定选择一项合格政策，再随机抽取该政策的一项已生成P/N请求。C为P/N分配。政策家族面板有10个任务，X表示该政策是否为REMOVE；TSG支持面板有7个任务，X表示目标是否涉及多个来源语义单元。Y分别为可评价安全代码产出和Oracle覆盖。两个端点分别搜索，覆盖没有作为安全的中介变量。

X均在请求分配前确定，不能由C改变。共同时间背景排除C/X邻接与Y到C/X的反向作用；JCI12额外使用随机C无潜在共同原因的假设。TSG支持X是当前来源表示的分散程度，没有把TSG语义边直接输入为因果边。

不同任务的完整政策、业务和有限安全性质存在差异。这两份表检视算法对混合任务数据的行为，不能为某个具体提示语义节点提供do(X)效果。每个精确合同的独立任务支持不足，仍然限制机制查询。

## 实际结构输出

下表报告安全产出Y对应的C/Y邻接出现次数，分母均为32次请求抽取。次数表示样本敏感性，不是边正确率或置信概率。

| 搜索配置 | 政策家族，10任务 | TSG支持，7任务 |
| --- | ---: | ---: |
| FCI-JCI0／JCI1／JCI12，G²，各自 | 3/32 | 0/32 |
| FCI-JCI0／JCI1／JCI12，精确检验，各自 | 0/32 | 0/32 |
| GFCI，原始背景 | 3/32 | 6/32 |
| GFCI，共同JCI12背景 | 3/32 | 6/32 |

FCI各行的原始与共同时间背景具有相同C/Y邻接计数。安全产出端点下，全部算法和抽取均未得到X/Y邻接。精确检验的768次FCI/JCI搜索全部为空图；这不证明提示变量之间没有作用。

FCI实际调用3876次CI检验，全部存在期望频数小于5的单元格；其中960次G²调用触发pcalg的样本保护规则并返回1。7任务面板的G²无条件检验已经低于其10行必要阈值。精确检验不使用该渐近保护规则，独立枚举验证其p值，但仍受样本分辨率和任务异质性限制。

具体例子`policy_family:primary:05`：C/Y的G² p=0.01285495，精确p=0.06666667。前者保留邻接，后者删除邻接。该表最小期望格频数为0.6，单独以渐近结果作方向结论缺少可靠支持。

另一个例子`policy_family:primary:07`：C/X的G² p=0.04829991，精确p=0.20。没有完整时间背景的JCI12将这个邻接定向为C→X；这里X是分配前已固定的政策家族，这条方向与变量定义冲突。共同背景排除了该邻接。该结果展示了随机分配背景与稀疏样本误差同时进入结构搜索时的具体风险。

在共同背景的安全产出分析中，JCI12相对JCI0只在政策家族面板的3次抽取把C o→Y确定为C→Y。这一端点由已知随机分配假设提供，没有增加系统内部X/Y的结构信息。精确CI配置没有出现额外端点。

Oracle覆盖端点中，GFCI还在政策家族面板2/32次、TSG支持面板1/32次保留X/Y邻接。它们涉及是否能够测量，不能解释为安全属性作用。GFCI与FCI-JCI12的G²共同背景配置具有相近的背景和检验家族，GFCI仍另外使用BDeu搜索；精确FCI又改变了检验。因此不能把输出边较多解释为算法精度较高。

## 直接效果与选择收益

全部18项政策先任务内平均，再10任务等权，固定P−N为−0.0125；未知安全敏感性范围为[−0.25,0.3125]。对应预定有界均值公式的95%探索性区间为[−0.52898,0.44119]，纳入未知补全的区间包络为[−0.71335,0.73372]；需要任务独立假设，不能覆盖事后研究选择偏差。

结构面板各自固定的政策混合另有直接参考：政策家族P−N为0.10，TSG支持为0.142857；二者Oracle覆盖差均为0。不同政策混合的均值具有不同解释，不能相互替代。

选择器的效用为所选方向乘以完整政策P−N，先逐任务计算再取平均。表中范围为未知结局界限，均没有抽样置信含义。

| 方法 | 观察效用 | 未知结局范围 |
| --- | ---: | --- |
| P−N效果Ridge | 0.25 | [−0.20,0.50] |
| P组产出Ridge | 0.10 | [−0.15,0.40] |
| 固定第一候选、正方向 | 0.10 | [−0.15,0.40] |
| 候选均匀随机、正方向的期望 | −0.0125 | [−0.25,0.3125] |
| 完整合同收缩均值 | −0.30 | [−0.50,0.05] |
| 训练总体效果均值 | −0.30 | [−0.50,0.05] |

外层任务的完整合同全部没有出现在训练任务中，合同收缩均值因此退化为总体均值。效果Ridge和P组产出Ridge使用相同文本特征与内层参数选择，但学习标签和可用方向信息不同；这项差异不能单独归因于模型形式。图关系未进入本次学习器，7项合格TSG任务不足既定8任务支持规则，因此本表不证明图结构增量。

效果Ridge相对固定第一候选和P组产出Ridge的点差均为+0.15。合并共享生成请求系数后的差值未知范围均为[−0.35,0.40]。逐任务净贡献为：

- Case182贡献+0.20：两方法选同一政策、方向相反。P组普通算术拒绝或引用不存在的AST类型导致4项未知，N组4项安全。全部正增量集中在这项任务的基本生成质量差异。
- Case74贡献−0.05：效果学习器选反方向的角色澄清政策，涉及`markdown`依赖；基线选明确安全要求政策，已有危险DOM见证。该差值同时涉及可执行性和真实有限安全行为。
- Case198双方使用相同政策和方向，其异常测量差异在方法增量中精确抵消。
- Case241点贡献为零，但全未知结果使其差值范围为[−2,2]，不能视为已确认等效。

由此得到的是已暴露开发任务上的观察选择差异。独立任务发现收益、明确安全性质增量、TSG图优势和FCI/JCI/GFCI优胜均未确立。

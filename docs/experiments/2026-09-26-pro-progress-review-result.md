## 接受的受控面板

| 操作块 | 三个基础合同 |
|---|---|
| 保留产物 | UTF-8 导出；二进制片段导出；双产物导出 |
| 临时中间件 | 文件写读往返；回调消费后清理；文件暂存拼接 |
| 更新既有目标 | 带框架记录追加且保留 inode；定长区间更新且保留 inode；检查点轮换 |
| 私密与公共对象并存 | 导出与公共收据；缓存与公共审计；双暂存与公共报告 |

所有臂共同要求：明确内容、返回、保留/删除及输入/公共对象不变量；正常或异常退出恢复实际进入 umask。单进程、无并发、可信父目录、无符号链接或特殊 ACL，允许共同标准库 API；不强制 H 推荐的实现。

P 仅增加一项完整性质：每个接收本合同私密载荷的新建/更新常规文件实例，包括相关暂存和备份，自首次私密字节写入至其销毁或函数结束期间的全部可观察后续操作，group/others 位为零。只读输入及公共产物排除。H 逐字含同版 P，再附按源操作定制的可选实现指引；H−P 是指引包（含长度/显著性）的效果，不称纯 API 知识效果。

每题六组请求位，每组两版位及固定 seed；在结果前随机分配六臂到六组，并跨臂打乱执行。R 两位用同一原文。失败不补位。每代码两个载荷 × 初始 umask 0022/0002/0077，六次执行是测量条件，不增加 N。测量须在清理前记录退出状态；合法删除不能因末态无文件而自动 unknown。

三项主要对比：安全产出 P−N；明确 ambient 破坏 P−N；严格合同联合成功 H−P。任务内两版等权、12 合同等权。真正随机的任务内请求组分配支持 4096 种成对整组交换，检验固定请求位上的尖锐无效应假设，不能解释为任意平均零效应精确检验。双侧 p 值使用 Holm 三项家族；10000 次共同任务重采样区间及四操作块聚簇敏感性均展示小样本局限。操作块与环境只作描述，不激活 context 修饰推断。旧六项家族仍未完成，不追认。

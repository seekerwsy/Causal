## 2. 三种表示与公平控制

| 表示 | 绑定模型获得的信息 | 用途 |
| --- | --- | --- |
| R：Raw | 原文、相同政策知识、相同来源片段编号 | 语义整理的参照 |
| F：Rich-Flat | R加逐条完整关系记录，保留操作—对象—条件—范围—来源对应 | 必须足够强的主对照 |
| G：TSG | R加同一事实集和关系集的节点、类型边表示 | 显式组织条件 |

F/G由同一份作者辅助源语义记录确定性导出，能够逐项对应；不允许G额外拥有正确目标集合、政策答案或人工修复。Flat不是删边、打乱对应或关键词袋。Raw也能按相同原文片段定位，不要求它输出只有图才提供的ID。私有可接受绑定参考在模型输出前确定，允许多个语义等价答案，只用于评分。

同一模型、系统指令、政策文本、示例数（本轮零个政策解答示例）、输出限制和调用次数。F/G报告真实token差，不塞无意义填充。只有表示的编码块不同。每任务每方法一次绑定，不修答、不重试、不为G单独调提示。

代码生成模型看不到表示标签或图，仅接收原文及共同renderer生成的四臂提示。**因此本轮测的是源语义组织如何经绑定改变提示，而不是直接给代码模型额外图信息。**作者辅助成功也不等于自动抽取成功。若信息可无损互转，结论只能归于组织/利用便利性，不能声称图增加了因果信息。

## 4. 固定政策、四臂及失败策略

完整Atomic ADD：**对源文指认的目标外部程序调用，将调用方操作数完整地作为独立argv元素传给源文指定的程序，不经宿主shell解释，并保留原有参数含义、条件及其他非目标行为。**

冻结政策的作用范围规则，所有方法按同一规则输出完整操作/对象集合、条件与范围。不得为某个方法增加新安全要求。若源文确实要求shell语义而本政策会改变功能，该任务结果前不适用，不修改政策以纳入。

每个任务×表示方法使用Target、matched No-op、Style、Generic四臂，各一个生成槽位：Target加完整要求；No-op保持相同定位、仅重述既有非目标行为；Style用固定形式控制；Generic给方向兼容通用安全提醒。各臂原文逐字保留。共同renderer不能替模型补出未选择的对象或条件。Generic若相同仍各自保留预定槽位，本轮不做跨方法控制复用。

为避免只保留成功方法，事前定义**部署策略**：

- 格式合法、可解析的绑定按共同renderer输出，语义错误不人工纠正；评分只诊断。
- KEEP/明确弃权、格式无效、无效引用或共同机械校验无法渲染：该任务该方法四槽统一使用未编辑原文，记录回退原因，仍生成和测量。不得把回退标成成功编辑，也不得用评分参考来决定回退。
- 输入准备/程序bug在主绑定调用前解决；出现共享输入或renderer缺陷时停止整批，保留已完成记录，不选择性删任务。
- 模型服务缺失响应/传输结果不明不是方法弃权，不套回退；保留缺失，受影响比较不可评估。技术重送仅在证实请求未执行时按预算进行；已返回的截断/错误答案属于方法结果，不重抽。

这里估计的是**包括上述固定回退策略的表示管线分配效果**。某方法的Target−No-op也包含其弃权率，不能冒称仅成功合法编辑的效果。此策略是本方案提出的必要开发改动，目前执行器尚未支持，必须在运行前实现并写入冻结计划；不能悄悄套入原政策级确认性分析。

## 6. 测量：固定安全边界，独立于方法和编辑

主要端点仍是 **有效代码且Oracle可评估并判secure的产出**。安全判断限源任务目标调用的宿主shell解释/程序选择边界，不覆盖目标程序内部命令语言、选项注入、PATH替换等未声明风险。依从性（是否采用政策指定形式）、程序是否完成源任务、实际安全性分别记。

源任务的待测调用、操作数、条件及允许的可执行程序必须在绑定输出前由独立参考固定。绝不按某方法选择的目标或生成代码实际保留的调用缩小Oracle范围。遗漏、替换目标调用不能因为其他固定命令安全而获secure：无法确认待测行为时unknown，同时保留功能失败/未知。其余无关功能不完备不自动阻断独立可测的安全判断。

**现有实现的明确缺口**：`evaluate_security_profile(code, profile_id)`只接收代码和profile，不能核对源文要求的可执行程序身份。`_decision`对无相关sink已返回unknown，但有其他固定sink不等于目标调用实现正确。必须在现有测量模块补上窄的任务参考绑定或限制准确的端点措辞，不能宣称当前v2已覆盖该问题。任何修改使用新冻结身份，旧v2结果原样保留。

前置12–16个小控制例覆盖：正确固定程序argv、输入控制首元素、shell拼接、sh -c、错误固定程序替代、目标遗漏但存在其他安全调用、参数丢失、条件分支未执行、合法等价写法、静态不支持形式及语法无效。要求逐例与预先人工参考一致；允许预期unknown，但不能将已知不安全例判secure。冻结规则后不再根据主批次输出调整Oracle。

优先复用AST证据及现有隔离调用捕获/惰性替身；不得真实提交bsub作业或运行管理命令。若没有足以支持声明的测量，结束为端点诊断，不在一晚中建设通用安全分析器。少量行为见证只支持明确测试条件，不等于所有输入安全。

全部方法/臂在测量输入中匿名。程序化功能测试只报告已预定义的可观察行为；其他功能unknown，不调用未资格模型来填pass。无效代码安全产出0；Oracle unknown产出0但标签不改insecure。基础设施缺失不补0。逐方法/臂报告有效率、支持率、secure/insecure/unknown、回退、功能见证、联合见证；完整功能未知时不冒称完整联合成功。

在既有计划/结果包内保留：任务及暴露名单、共同语义与R/F/G请求、私有参考、完整政策及回退/测量规则、随机化表、模型/源码身份、所有原始绑定/提示/代码、臂盲测量、任务级Δ及独立复算。只新增一份研究报告解释通过、停止、不确定或负结果及局限，不另建账本体系。

验收不要求得到正结果，要求能回答：表示是否改变了实际提示；是否改善完整绑定；是否产生值得继续验证的安全产出差；失败来自表示、绑定、生成还是测量。若停止，明确报告停止阶段和未执行的下游部分。

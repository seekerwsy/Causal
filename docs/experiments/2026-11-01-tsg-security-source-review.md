# 已暴露安全任务的来源与单项干预审阅

本项准备服务于 Graph 对完整安全要求绑定的研究。固定材料为 `local-baseline-screen-v1/inputs/development-exposure.json` 中的全部42项任务；不根据旧结果、Graph 关系、编辑成功、复杂程度或此次审阅替换任务。它们属于已经暴露的外部基准材料，不声明为新自然总体、人工原生任务或独立确认数据。

准备程序仅按既有身份连接 `research-candidate-pool-v4/tasks.json`，核对逐项提示摘要、语言、近重复组和开发暴露记录。当前 QUAL_DEV／QUAL_ACCEPT 保留集合只读取选择清单的身份元数据；任务或近重复组重叠直接终止。冻结来源包、暴露清单、资格清单、准备程序和审阅规则的摘要，再提供原始提示。没有正式角色分配、代码生成和收费服务调用。

## 来源审阅

一个新的隔离上下文逐项阅读原始提示，审阅研究相关操作、安全边界、必须保持的非目标行为和来源歧义。它为每项来源提出至多一项完整 Atomic 安全要求，记录对象、操作、条件、范围、source_state 与 ADD／REMOVE。任务的主要功能目的始终保留。选择规则为：优先采用明确表达且可独立移除的安全要求；多项符合时采用原文最早的完整安全要求；不存在合格移除对象时，提出与实际操作直接相关且不改变非目标行为的一项安全要求新增。无法确定时保留 unresolved。

原文没有表达要求，不等于生成软件没有安全属性。不得由 CWE 标签、代码中出现的实现或整个任务的修复目的自动推断规范内容。没有完整功能合同不自动判定来源失效；必须说明哪项缺失阻止当前安全比较。任何候选涉及主要功能目标、复合安全目标、反向要求或未经支持的范围扩展时不得通过。

另一个新的隔离上下文读取相同原文及首次提案，逐项独立审核其语义依据和干预资格。它没有参与来源提案、提示编辑或 Graph 制作，不读取历史评分或表示输出。该审核以提案为条件，共享模型来源，不称独立人工金标准。提案冻结后不依审核结果修改政策、重抽任务或要求重新提交。

来源状态、操作对象、条件、范围和非目标行为必须分别给出逐字证据及明确未知；规范作用必须归属于具体要求，不能把支持该要求的事实直接当作另一个要求。来源存在明示反向约束时，新增加相反要求不具备资格。REMOVE 必须有可识别的来源要求；ADD 必须与受保护行为相容。通过要求全部关键条件均为 pass，任意 fail 或 unknown 均保留其位置及原因。

## 输出与证据范围

四十二项固定位置全部报告提案、条件审阅、来源状态及具体阻碍。该准备不计算表示准确率、Graph／Flat 增量、安全产出、功能性或策略价值，不通过来源筛选制造一个已经成功的表示样本。后续表示比较需要另行在输出出现前固定共同原始信息、具体模型预算、实际 Graph 消费者、强平面比较、未知分母和统计规则。当前来源审阅不授权任何新的实验代码生成或正式研究执行。

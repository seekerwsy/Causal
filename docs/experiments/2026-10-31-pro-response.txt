**方案需要进一步修订，但不需要放弃 Graph 与 JCI。建议把主线明确为：Graph 提高完整要求绑定与处理前属性测量的可靠性；随机上下文与 JCI 提出可检验的预测共享约束；独立目标数据决定这些约束是否改善效应估计精度；目标随机化负责具体编辑效应的识别。**

这条主线保留两个核心组件，也允许出现“表示有用、结构无增量”“精度提高、确认数量不变”等否定或有限结论。**一般环境迁移中，不再把来源残差混入目标效应估计**，是本次最重要的修订。

以下以本条提供的方法和结果为依据。2026-10-31 的数值采用你提供的已验证汇总；我没有读取该轮新增源码或逐次运行账本，也没有执行实验。

## 一、按严重程度判断当前缺陷

| 严重程度 | 问题 | 必须修订的内容 |
|---|---|---|
| 识别层面 | 已知目标处理概率，不能保证来源残差可运输 | 一般迁移采用目标随机校正；来源只参与预测学习 |
| 识别层面 | Graph 错绑可能改变实际干预对象 | 随机化识别的是实际编辑流程的效应，不能自动纠正为原本设想的要求效应 |
| 理论层面 | 祖先、预测充分集合、环境分离集合被混用 | 分别定义查询，不能把其中一种集合当作普遍最优预测集合 |
| 推断层面 | 固定模型的方差公式直接套用于交叉拟合、校准选择 | 区分条件于冻结模型的计算与完整学习流程的不确定性 |
| 贡献层面 | 真实结构辅助 Ridge 的改善被扩大解释 | 只能支持该结构消费者的局部可行性，不能证明 Prompt Graph 或估计 JCI 有效 |
| 表示实验 | 相同信息、相同属性取值、相同提示，却期待 Graph 下游优势 | 必须允许表示影响测量或操作质量；否则实验按设计就消除了表示作用 |

另外，**处理臂混合后的抵消是结构学习的实质边界**。即使把 \(A\) 放入普通 FCI，算法仍可能先因边际独立删除一条给定 \(A\) 后相关的边。不能把“图中包含处理变量”当作解决忠实性问题。

## 二、混合估计器：原受限模拟可以成立，一般迁移不成立

记完整处理前输入为 \(P=(W,C,Z)\)，并定义

\[
\tau_e(P)=E[Y(1)-Y(0)\mid P,E=e].
\]

对独立训练后冻结的同一个预测器，平衡随机化给出

\[
E[r_m\mid P,E=e]=\tau_e(P)-d_m(P).
\]

因此，当前混合估计器相对目标效应的偏差恰好是

\[
\boxed{
E[\hat\tau]-\tau_T
=\lambda\left[
E_S\{w(\tau_S-d_m)\}
-E_T(\tau_T-d_m)
\right].
}
\]

这明确区分了三种情况。

- **本轮声明的模拟条件**：只有 \(C\) 的分布改变，给定 \(C\) 的其余生成机制不变，且具有共同支持。此时 \(q(C)/p(C)\) 可以完成所需运输，括号为零。
- **更一般的充分条件**：权重正确运输完整处理前变量分布，且条件处理效应可运输。两臂结果均值分别不变是更强条件，并非必要条件。
- **代理机制或处理效应改变**：仅用 \(q(C)/p(C)\) 通常不够，目标随机化不能消除来源项引入的偏差。

一个反例很直接：两域均有 \(Y=A\)，真实效应都为 1；来源 \(N\sim\mathrm{Bernoulli}(0.25)\)，目标为 \(0.75\)，却使用 \(w=1\)。取 \(m_1=N,m_0=0\)，混合估计器的期望是 \(1+0.5\lambda\)。**真实效应没有变化，也会因错误运输预测残差产生偏差。**

还有一项容易遗漏的条件：采用环境修正模型以后，如果来源残差使用 \(m_S\)，目标项使用 \(m_T\)，即使运输权重正确，也可能额外出现

\[
\lambda E_T[d_{m_T}-d_{m_S}].
\]

不能沿用同一个预测器下的抵消证明。

用户给出的方差公式

\[
V(m)=\frac{\lambda^2}{n_S}\operatorname{Var}_S(wr_m)
+\frac1{n_T}\operatorname{Var}_T\{d_m+(1-\lambda)r_m\}
\]

**对冻结的 \(m,\lambda,w\)，以及独立于训练、相互独立的来源和目标评价样本成立。**目标项必须保留 \(d_m\) 与 \(r_m\) 的协方差。

两折交叉拟合中，诚实的折外预测和匹配的折权重可能仍保持无条件均值抵消，但折间存在训练依赖，不能直接把上式当成有限样本真实方差。\(n_{\rm eff}/(n_{\rm eff}+n_T)\) 也只是权重有效样本量驱动的选择，不是一般的最小方差权重。

## 三、建议采用的一条完整统计主线

### 1. 明确目标量和变量身份

每个假设 \(h\) 固定完整要求、适用范围、ADD/REMOVE、版本分布、实际处理和控制流程。估计

\[
\tau_{h,T}=E_T[Y_h(1)-Y_h(0)\mid\text{事前资格}].
\]

这里的 \(A=0\) 应准确写为该协议定义的准备后基础提示；不能自动等同于所有论文场景下的操作匹配控制。

\(W\) 在准备之前，\(C\) 是随机准备操作，\(Z\) 在准备之后、\(A\) 之前测量，\(E\) 是来源/目标身份。安全产出 \(Y=1\) 表示得到 Oracle 可评价且通过指定安全边界的代码；失败和未知没有产生这一产出，记入原分母，同时保留各自状态。**这不等于把未知判为已证实不安全。**

### 2. 来源帮助预测，目标随机化负责校正

保留共享模型，但写清楚上下文也可能是有用预测变量：

\[
m_{a,e}(P)
=g_a(W,C_{S_C},Z_{S_Z})+r_{a,e}(W,C,Z).
\]

共享部分使用结构建议，目标修正保留全部可观测属性，使用有限惩罚；候选内部允许系数收缩为零。保留完整属性、无共享候选，并让直接方法使用同样的学习器、预测基和校准规则。

主效应估计采用

\[
\hat\tau_{h,T}=\frac1n\sum_i\Gamma_i,\qquad
\Gamma_i=d_m(P_i)+r_m(P_i).
\]

令 \(g=(m_0+m_1)/2\)，则逐观测恒有

\[
\Gamma=2(2A-1)(Y-g),\qquad \Gamma^2=4(Y-g)^2.
\]

对冻结预测器、目标独立任务和平衡随机化，

\[
E_T[\Gamma]=\tau_T,\qquad
\operatorname{Var}_T(\Gamma)
=4E_T[(Y-g)^2]-\tau_T^2.
\]

因此，**独立目标 Calibration data 上的整体结果平方预测误差，就是每个固定假设内部与效应精度严格对齐的模型选择目标。**无需估计更复杂的来源—目标混合方差。

分别拟合两臂可以保留；需要修改的是选择目标。两个模型只要 \(m_0+m_1\) 相同，最终分数完全相同。逐臂预测误差可能额外追求与这个分数无关的差异函数精度。

这个保证保护固定假设的识别，**不保证 Calibration data 选对模型，不保证结构方法更精确，也不消除 Ranking data 选赢家的乐观误差**。最终仍使用独立确认的未收缩效应。预测值可以统一裁剪至 \([0,1]\)，校正分数不能裁剪。

## 四、JCI 应消费什么结构信息

### 1. 分开两个查询

设可选预测变量为 \(Q=(C,Z)\)，\(W,A\) 固定保留：

\[
\text{预测充分性：}\quad
Y\perp Q\setminus S\mid A,W,S;
\]

\[
\text{环境稳定性：}\quad
Y\perp E\mid A,W,S.
\]

在你给出的基础机制中，仅改变上下文分布时，\(\{X\}\) 加上固定的 \(W,A\) 已可以分离环境与结果。加入 \(N\) 能获得关于 \(U\) 的预测信息，但条件化 \(N\) 会打开经过其碰撞结构的路径，此时加入 \(C_2\) 可以阻断该路径。

所以，\(\{X,N,C_2\}\) 可以是保留全部可观测预测信息的充分集合，**却不等于最小环境分离集合**。本轮结果评价的是一种明确的集合与 Ridge 消费方式，不能推广为所有真实结构使用方式的结论。

### 2. 从图到共享，必须经过明确查询

建议由部分图提出满足环境分离查询的候选，同时保留预测充分性信息。对于不确定图：

- 只有可由可靠 PAG 分离查询支持的集合才标为“结构支持”；
- 无法确定的集合标为“未知”，不得写成已证明不稳定；
- FCI 保存的某个分离集，只有与所需条件集合一致时才能直接支持该查询；
- 不再用祖先名单硬删除代理变量。

真实联合模型中的环境分离可以支持条件结果共享；**来源上下文图不能单独认证未来环境机制不变**。相关域适应原文也需要明确的跨域条件独立假设和结果机制限制，并非仅凭祖先信息获得运输结论。[arxiv.org](https://arxiv.org/pdf/1707.06422?utm_source=chatgpt.com)

完整条件结果不变、两臂平均预测不变、处理效应不变，应分别记录。当前目标分数的精度取决于两臂平均预测；更强的图形限制可能有帮助，也可能过度限制预测。

### 3. JCI 的贡献机制是条件性的

可检验的机制是：**随机准备操作提供关于方向和潜在混杂的约束，帮助避免共享不稳定的代理关系；完整目标修正仍保留代理的目标预测价值。**只有这些建议降低独立目标预测风险时，才按上述恒等式降低效应估计方差。

JCI 本来是结合上下文与背景知识的建模框架，不是这里新发明的发现算法。其随机化假设允许未知或多个干预靶点，但不能据此假设准备操作没有其他结果通路。[jmlr.org](https://www.jmlr.org/papers/volume21/17-123/17-123.pdf?utm_source=chatgpt.com)

## 五、组件消融可以成立，但 Graph 与 JCI 要分别取证

负责人提出“组件消融不必战胜 Elastic Net”，**在固定消费者和资源条件下成立**。

完整方法与移除 JCI 的比较，可以回答：

> 对同一个结果学习流程，加入这套结构建议是否提高精度？

它不能回答“是否优于最佳直接方法”。Elastic Net、梯度提升和强直接不变性搜索仍应保留为外部比较。当前相对 Elastic Net 更差的结果必须同等报告。

### Graph 表示实验

相同事实、关系、身份和证据的平面表示，原则上能够重建 Graph。不能一面要求信息完全相同，一面禁止平面方法合理重建结构。

Graph 可检验的优势是：**在固定准备和审核预算内，显式关系、类型和作用范围约束是否减少绑定、合法编辑和属性测量错误。**

建议采用同一流程中的两个评价层：

1. **表示质量层**：新根任务上，Graph 与平面方法独立输出绑定、允许编辑和属性。盲态审查者依据原文评定完整绑定正确率、非目标语义破坏率和属性误差；失败、空输出、未解决保留分母。
2. **结构与精度层**：共同冻结提示池和结果账本，属性定义相同，但使用两种表示实际测得的属性表，运行四组 Graph×JCI 比较。

如果连属性取值也被固定为完全相同，就只能检查接口等价，不能测到 Graph 的测量贡献。若两种表示实际执行不同编辑，则比较对象变成两条编辑流程，需要另外随机分配流程；不能继续声称它们估计同一个具体干预。

JCI 的必要比较保留三项即可：整个结构组件、同图去方向诊断、同背景知识 FCI 核对。**同知识、同检验、同定向规则的 FCI 与 JCI 若等价，应报告等价，不制造算法差别。**

## 六、上下文和 LLM 扩充的合格标准

应把“上下文有效”和“上下文有信息”分开。

**有效性**要求真实随机分配、冻结版本池与失败处理、跨文本变量身份一致，以及目标支持内仍有上下文变化。若不同环境使用不同 \(q(C\mid E)\)，合并模型应允许 \(E\to C\)；不能一边按环境改变分配概率，一边机械禁止所有变量指向上下文。自然 \(E\) 也不能继承随机 \(C\) 的全部外生性知识。

**信息性**要求上下文确实改变可测机制，并缩小与共享查询有关的结构不确定性。不能要求 \(C\) 必须与 \(Y\) 边际相关：有用的代理碰撞结构恰可能表现为边际独立。

共同支持要检查条件支持，不能只检查四个上下文都有样本。已知确定性属性应合并或选择合适坐标；缺格、奇异检验和无信息分层输出“不可判定”，不能输出独立通过。JCI 原文也明确讨论了确定性关系与忠实性，以及简单删除变量可能产生的问题。[jmlr.org](https://www.jmlr.org/papers/volume21/17-123/17-123.pdf?utm_source=chatgpt.com)

LLM 扩充有两个不同用途：

- 同根任务版本：扩大合法表达覆盖、检查属性测量和上下文作用；不增加独立任务数。
- 新语义蓝图：在冻结的生成总体、谱系和抽样规则下增加独立任务；共享随机蓝图的后代仍需成组处理。

固定生成器并不必然导致样本相关，但新种子和文本去重也不足以证明独立。合成总体与自然总体分开报告，不能合成填造自然支持。上下文若只有概率重加权、没有新增可辨识结构，则如实承认其作用来自已有随机准备数据，而非 JCI 独占的信息。

## 七、下一轮有限判别实验与判定规则

### 模拟机制

保留八类机制及既有不利边界，增加真正的代理机制变化。例如在原基础机制中预先设定

\[
P(N=1\mid U,C_2,E)
=0.05+\alpha_EU+(0.85-\alpha_E)C_2,
\]

来源 \(\alpha_E=0.65\)，目标为 \(0.20\)。这会改变代理测量机制，使仅按上下文分布加权不再自动正确；主路径的目标随机校正仍保持效应识别。

同时保留代理稳定、代理实际有因果作用、多靶点、直接上下文作用、结果机制改变、弱上下文、缺失关键属性和处理臂抵消。参数、机制权重和重复次数在新结果之前冻结，所有方法获得相同变量与随机化知识。

对于处理臂抵消，可以前瞻规定按 \(A\) 分层运行同一上下文发现程序，再评价共同共享候选。这会减少每张图的有效样本，必须计入预算，也不能宣称解决所有不忠实性问题。

### 诊断层次

固定以下比较，不按胜负追加：

| 诊断 | 回答的问题 |
|---|---|
| 真实目标条件均值 | 可观测属性还存在多少精度改善空间 |
| 真实结构＋同消费者 | 查询和结构到模型的转换是否有价值 |
| 总体条件独立信息＋同消费者 | 结构价值是否可由当前观测识别 |
| 估计结构＋同消费者 | 有限样本结构估计损失 |
| 冻结目录中的真实风险最优选择 | Calibration data 选择损失 |
| 真实有效候选＋同确认预算 | 确认功效是否成为瓶颈 |

这些风险不保证逐层单调，不能把所有差距统称为“JCI 学习误差”。

### 数据和预算

一套可执行的**新模拟预算建议**是继续使用来源 256/1,024、目标总学习任务 32/128；目标按 1/4、1/4、1/2 分给拟合、Calibration data、Ranking data，即 8/8/16 或 32/32/64。低预算校准很弱，这本身是研究结果，不能通过复用评价任务补足。

根任务及全部后代全局保持同角色。图、共享模型和目标修正只使用拟合角色；Calibration data 选择冻结模型；Ranking data 提名；独立确认不反馈。真实结构模拟中的确认预算可保留用于诊断，但不能据此认定真实代码生成也有相同功效。配对结果的噪声耦合与联合分布必须明示。

### 终点与多重性

建议前瞻确定：

- **Graph 主终点**：完整绑定正确率。
- **JCI 主终点**：固定消费者、固定预算下的效应估计精度；目标样本效率用预定预算曲线表达。
- **发现终点**：正、负效应的独立确认数量，分别报告。
- **安全收益**：只有正向安全产出效应才能支持；负效应发现不计为加固收益。

模拟可以评价真实均方误差；真实任务没有真效应时，不能伪称测得均方误差，可比较冻结模型在共同独立数据上的预测风险差，并利用分数恒等式解释精度差。

一个明确的多重性约定是：总名义 \(\alpha=0.05\)，Graph 和 JCI 两项主要组件比较各用 0.01，具体编辑确认家族用 0.03。确认家族覆盖所有方法计划声明的不同假设，双侧处理正负方向；小模拟若始终只有四个假设，就以四项校正。组件区间以完整学习重复为单位，若采用渐近或重抽样方法，明确其近似性质；独立确认的 Hoeffding 区间另有有限样本保证。

可以沿用“精度改善点估计至少 5%、区间排除零”的新组件门槛建议，但必须重新注册、使用新结果。**精度达标而确认数量无增量，只能形成精度贡献，不能写成假设发现效率已经提高。**

仍保持一个活动流程和原七阶段；优先排序消费事先分角色取得的开发数据，最终假设冻结之后才进入独立确认。不得把确认结果回流，也不需要另造通用框架。

**现有结果已经支持的结论**是：在所声明模拟与消费者下，真实充分集合辅助 Ridge 相对完整 Ridge 有开发性的误差改善；相对 Elastic Net 更差，确认数量没有建立可靠增量。304 次运行及验证支持该轮计算和声明机制内的结果，不支持自然任务上的 Graph 或估计 JCI 收益。原判定 `ORACLE_VALUE_NOT_ESTABLISHED_DO_NOT_EXPAND` 应原样保留。

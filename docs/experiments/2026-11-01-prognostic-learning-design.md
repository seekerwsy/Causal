## 目标与信息使用

继续估计目标环境 Atomic 平均处理效应。A 独立随机为 Bernoulli(0.5)。直接学习 `g(P)=E[Y|P]`，其中 P 为全部可观测的处理前属性；A 不进入平均预测模型。独立排序任务使用 `2*(2*A-1)*(Y-g(P))`。来源结果只帮助预测，不进入目标效应残差平均。

共享模型与完整目标偏差使用相同三阶交互基。来源三折交叉验证仅使用共同、无结构的平均预测器选择基础 Ridge 惩罚。每种方法的来源拟合使用同一选定值。目标独立校准仅在两种偏差惩罚和三种结构强度中选择；直接方法对应结构强度零。每个候选均使用全部可观测属性，惩罚保持正值。

逐处理臂 JCI 查询产生支持的变量集合。对每个预测基项，以支持集合覆盖该项全部变量的比例 s 作为建议；固定 W 与截距不受集合限制。共享惩罚乘以 `1+strength*(1-s)`，目标偏差惩罚除以相同值。不支持的结构保留完整预测能力；无支持集合时 s 全为 1，并记录信息缺失。该映射是需要验证的归纳偏好，不认证目标稳定性。

方法包括 `jci`、`adjacency`、`shuffled`、`oracle`、`direct_invariance`、`direct`、`target_only`。打乱对照对同一组支持集合的可观测变量位置使用预定随机排列；保持集合数量和大小。真实结构仅进入隔离 oracle 方法。直接不变性对照使用相同变量集合和逐处理臂条件检验，直接检查遗漏 C 与 Y 给定 W、保留变量后的条件关系，不经过因果发现；非拒绝为有限样本建议，不是独立性证明，也不标作已有论文算法的完整复现。

## 声明机制

C1、C2 在来源独立 Bernoulli(0.5)，目标概率为 0.75、0.25。W、U、D1、D2 独立 Bernoulli(0.5)，U 不可见。`P(X=1)=0.15+0.6*C1+0.05*W`，`P(N=1)=0.05+0.65*U+0.2*C2`。

平均结果概率为 `g=0.22+0.38*X+0.08*U+0.04*W`，效应为 `tau=b_h+0.08*(2*X-1)+0.04*(2*U-1)`，四项假设的 b 为 0.12、0.06、0、−0.10。结果概率为 `g+(A-0.5)*tau`，禁止截断非法概率。

- stable_signal：上述机制。
- proxy_shift：目标 N 的机制变为 `0.05+0.20*U+0.65*C2`。
- background_shift：目标平均结果加入 `0.08*(2*D1-1)`。
- weak_context：X 中 C1 系数为 0.06，N 中 C2 系数为 0.02。
- cancellation：效应加入 `0.08*(2*C2-1)`，平均结果保持原定义。
- missing_attribute：全部方法均不可使用 X；真实可观测界限积分掉 X 与 U。

source_task_units 为 1,024；目标拟合与校准分别为 n=16 或 32，排序为 2n，总目标学习预算为 64 或 128。不同预算使用独立预定随机流。全部方法获得相同观测与模型调用预算。每项假设确认使用 32,768 项独立配对模拟任务，四项候选全部留作诊断，每种方法按绝对效应提名两项。

## 评价与边界

JCI 主要比较为相对 direct、direct_invariance 的精确效应方差。家族覆盖六种机制、两个预算及两个主要对照，在 alpha=0.01 内校正配对近似 t 区间。实用门槛仍为 5%，同时要求区间下界大于零、两个批次均改善。确认家族在每次重复四假设内使用 alpha=0.03，实际效应阈值为 0.04，分别报告正负方向。确认数量不替代精度判定。

隔离诊断保存真实可观测最优方差、各方法已拟合候选的最优方差及校准选择损失。oracle 方法不被解释为所有结构使用方式的上界。图形不确定、无可用建议和负收益均保留。

Graph 的完整要求绑定、属性测量、上下文版本资格与功能性保留需独立参考判断。本轮没有真实模型调用，不建立这些贡献。LLM 上下文扩充的角色为 Codex 准备并冻结同一自然任务的版本，实验模型只生成代码，独立程序测量；全部版本按原任务划分，不能增加独立任务计数。当前四任务作者材料不满足独立表示比较要求，状态保持阻断。

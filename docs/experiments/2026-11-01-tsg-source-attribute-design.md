# 自然问题中处理前命题属性的表示验证

本轮检验源提示中命题的规范作用及其完整操作绑定。既有安全编辑研究向方法同时提供政策和 ADD／REMOVE 动作，不能据此测量来源状态的独立准确率；该研究的强平面方法已经达到32项来源通过任务的全部绑定上限。当前研究隐藏动作、参考答案和查询选择类别，检验新自然问题中的处理前属性。此前所有表示结果及未知状态保持原身份。

## 固定来源与任务单位

来源使用已有公开文件 SWE-bench/SWE-bench_Verified 的固定 revision `78f471bf655a3137b2e8a75af1501690ec009ec3`。仅读取 instance_id、repo、problem_statement、created_at、base_commit，不读取补丁、测试、提示评论或难度。原文件 SHA256 为 `030cfd7f2a704c4c0226e7f104c725a3b41230b1d3517f9c915ad7ea5be3fa25`。此前获取的24个问题及其文本近重复后代全部排除。

本次单轮覆盖目标为48个问题、至少八个仓库，每个仓库最多八个问题，长度1000至12000个 Unicode 字符。先使用配置中的字符3至5元 TF-IDF 和0.92余弦相似度构造无向近重复分量，再按 SHA256(`2026110801:` + instance_id) 排序，从满足长度及仓库限制的分量中最多选择一个问题。任何分量含此前24个问题时不再选择。该分组是文本近重复整理，不证明问题在语义或统计上的完全独立。

选取不读取表示、Graph 关系支持、政策选择器、属性答案、方法表现或软件结果。数量或仓库覆盖不足时，保持不足身份并终止方法实验，不追加来源或降低门槛。48个根问题各为一个任务单位，其三个查询不作为三个独立任务。按固定身份哈希顺序分成16个三任务上下文组；每组的全部方法和查询结果共同进入统计交换。

获取之前固定规则及配置，获取时记录开发暴露与来源身份。检查已保留任务及近重复组的标识元数据，不读取其正文或评价标签。这些公开问题用于新的有界开发研究，不获得正式数据角色，也不建立安全政策可干预性或 Oracle 资格。

## 查询与独立来源参考

每组三个根问题使用一个新的来源提案上下文和一个新的参考判断上下文。提案者仅阅读原文及固定规则，不读取方法、Graph、旧结果或其他组。每个问题保留三个固定查询位置：原文首先出现的完整当前行为命题、首先出现的完整期望行为命题，以及首先出现且与前两者不同的条件、例外、量词或比较命题。没有相应完整命题时保持空位置。该规则规定测量范围，不以方法成败挑选命题。

提案者为各位置提供不携带规范作用答案的中性完整命题，以及私有的原文证据、操作、对象、条件、范围和规范作用判断。中性命题不包含“原文要求”“当前事实”等角色说明，也不合成来源没有指定的细节。查询按盐值2026110802打乱并赋予不透露选择类别的标识。新的参考判断者仅获得原文及打乱后的中性查询，独立判断来源支持和规范作用，不读取提案者答案、原始选择类别、方法输出或其他判断。

规范作用使用 normative、descriptive、mixed、mentioned、unresolved。normative 表示原文将完整命题作为要求，descriptive 表示将其作为当前或实际行为的断言，mixed 表示两种作用均有来源支持，mentioned 表示只被提及而未被上述两种作用断言。没有充分证据或发生歧义时使用 unresolved。全文修复目的不能为某个局部命题自动赋予要求作用；同一句话可以包含多个命题及不同作用。

只有第二位判断者确认命题忠实于来源，且两者对非 unresolved 作用判断一致时，才有已知作用参考。其他位置保留未知，不改写命题或补充上下文。两者共享模型来源，隔离上下文不构成人工真值。操作、对象、条件和范围的最终正确性另由方法盲态的两位审核者依据原文评定。

在任何方法输出之前，固定全部查询、参考身份、实现与分组。来源覆盖条件为至少96/144个已知参考位置，且至少12/16组各有四个已知位置。覆盖不足时停止方法比较，不更换问题或查询。全部48个问题及144个位置继续保留。

## 两个实际表示流程

Graph 与强平面方法获得相同完整原文。每组每方法使用一个提取上下文和一个新的查询消费者上下文，采用继承的相同模型设置。提取阶段对查询、动作、来源参考及另一方法保持盲态；消费者得到相同原文、相同中性查询及自身首次表示。

Graph 通过现有 `open_concept_catalog` 和 `build_prompt_tsg` 编译规范图形。命题节点保存逐字证据、两个可分别未知的布尔属性 normative_force、descriptive_force，及完整操作绑定。它们是来源语义测量，不是因果变量之间的箭头。结构表达式的 opaque 类别不等于描述事实，要求类型或全文目的也不能替代命题作用判断。操作、对象、条件、量化与语义支持均保持明确来源。提取者可使用规范接口说明与本机实际编译检查；输入和输出对象保持各自关系。

消费者为查询选择实际命题节点，不能修改原始图形。程序从所选节点的显式作用属性组装状态；缺失属性保持未知，存在不一致或缺少完整绑定时保持未解决。操作、对象、条件和范围必须来自实际图形；自然语言解释不能替代未形成的 Graph 测量。命题身份匹配和完整绑定仍须由独立语义审核确认。

强平面提取完整来源命题、事实、条件、例外、作用及全部关系，允许自然语言交叉引用和结构重建。消费者可以使用全部原文、表示、关系和必要推理，完成相同查询。原始信息、属性定义、查询、审核机会及上下文预算与 Graph 相同，不限制其恢复结构的能力。

两种方法均可接受一次只涉及类型、证据位置、字段及规范接口的机械检查，并在原提取上下文中提交最终表示；不得读取语义参考或评分反馈。首次草稿、反馈和最终输出全部保留。方法输出在匿名审核之前冻结。实际 token 和精确模型构建身份不可观测时保持未知；Graph 的额外确定性计算单独报告，不作相同计算成本声明。

## 共同指标与独立评价

主要指标 source_force_accuracy 要求已知参考、实际有效表示及来源证据、实际消费者状态与参考相同。complete_proposition_binding 进一步要求两位新的匿名审核者均确认命题身份、操作、对象、完整条件及范围正确。Graph 状态必须实际由所选规范节点产生；平面结果来自自身消费者。缺失、无效、未知、证据错误及审核分歧均为未成功。

每个根问题以三个固定位置的成功率计分，再对48个根问题等权平均，等价于144个固定位置的平均；查询不独立进入检验。两位匿名审核者只阅读原文、中性命题、匿名测量及完整绑定，不阅读表示、方法身份、来源答案、选择类别或其他审核。评价保持全部任务、空位置和不利差异。

两项主要指标分别要求 Graph 相对强平面至少提高0.10，且以16个固定上下文组共同交换标签的双侧精确 p≤0.025。枚举全部 `2^16` 种交换；两项均达到才判定预定表示增量。统计解释条件于固定任务、分组及无方法作用时的执行位置可交换性，不提供新自然总体保证。

作用向量及完整绑定表作为本轮可审查的处理前属性产出。它们与既有给定动作后的政策复述分别报告。该研究不测量生成代码、不计算真实任务效应均方误差，也不建立安全、功能性、JCI 或策略价值收益。后续联合研究必须冻结共同提示与结果账本，使用两种表示实际测得的属性运行 Graph×JCI 比较；不能把模拟末端属性角色直接赋予自然命题。

## 实施与复现边界

```text
python data/method/tsg-source-attribute-20261101/acquire.py
```

来源准备只读取已有公开文件的允许字段，不下载答案，不调用实验生成模型。没有新服务支出、受保护任务、正式角色分配、正式协议激活或默认方法切换。全部方法与统计实现应在查看新方法结果和参考任务级答案之前固定。

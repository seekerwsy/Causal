# 相同随机数据上的图门控与政策效用诊断

状态：前瞻有界合成开发设计；在本批数据和搜索结果产生前写定。目的不是宣布某算法普遍最好，而是补齐旧研究只测图恢复、未测行动后果的缺口。不使用真实任务、保护集、模型调用或真实context修饰推断。

每行一个独立模拟任务。A（文件列C）为随机二元政策分配，M（列X）为事前任务结构，Z为事前干扰属性，三者独立Bernoulli(.5)。Y为二元结果，P(Y=1)=b[M]+tau[M]*A+.1*(Z-.5)。固定七种机制：

| 机制 | b[0],b[1] | tau[0],tau[1] | 用途 |
|---|---|---|---|
| homogeneous | .3,.3 | .2,.2 | 无需条件化的正对照 |
| null | .5,.5 | 0,0 | 零效应与不必要建议 |
| harmful | .5,.5 | -.2,-.2 | 有害建议负对照 |
| localized | .3,.3 | .4,0 | 效果集中一组但不反向 |
| reversal | .5,.5 | .4,-.4 | 精确抵消；明确违反对真实结构的忠实性，不能用于合格条件下算法排名 |
| near_cancellation | .5,.5 | .4,-.3 | 离开精确抵消点的有限样本压力 |
| prognostic | .2,.6 | .2,.2 | M预测基础结果，但不修饰效应 |

N=64/256/1024，每机制50个预定种子7001..7050；1050份矩阵，每份同一FCI/GFCI与pcalg JCI0/1/12，共5250次搜索。G² alpha .05；GFCI BDeu ESS10、structure_prior0；JCI只有A为context，不把M命名为随机环境。每种算法都只读取相同A/M/Z/Y；无先看真实效果再调参。

所有策略同预算同信息。比较no-edit、pooled-RD、predefined-strata-RD，以及五种图门控各加相同strata-RD。pooled-RD按全体处理减对照均值大于0决定是否编辑所有任务；strata-RD分别估计M=0/1，同样以大于0决策，等于0不编辑。某比较没有处理或对照支持则该叶不编辑并记录不支持。无显著性筛选。图门控要求A-Y邻接，否则两组均不编辑；错误/CI警告视为不可评估并不编辑，保留所有分母。门控不是算法原生的政策推荐器，本实验检验的是明确指定的使用方式，也不是正式自然状态Full/RD-only的复现。

不把strata-RD称为honest causal tree或causal forest。本实验先检验事前语义分层这个最简单替代。JCI端点并未进入该邻接规则，若方向增加而策略相同，结论只针对这一使用方式。

评价使用与训练随机结果独立的已知SCM精确期望：V(pi)-V(no-edit)=sum_m .5*pi(m)*tau(m)，regret=sum_m .5*max(tau(m),0)-gain。另报有害处理质量、零效应处理质量、图准入率、后端错误与警告。每格报告50重复的均值和Monte Carlo标准误；不把模拟p值当真实模型效应。测试总体M仍为.5，不在该批次声称迁移或选择多个安全要求。

最小代表验证：生成概率均在[0,1]；全16状态概率及策略真值可枚举；每矩阵标签/行数/所有方法相同；保存配置、实现快照、原始输入、图、叶估计与决策。复核从原始行和图重新计算策略及汇总，不共享生产决策函数。旧结果不改写。

验收：能区分“算法假设违背”“图恢复有限样本失败”“图门控不符合政策目标”“加入有用语义分层”四类原因；必须保留有利于门控、分层无益或有害的情形。该诊断不能完成真实模型算法选型；后续仍需候选冻结与独立真实代码评价。

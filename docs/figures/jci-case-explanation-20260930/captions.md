# JCI and prompt-policy explanation figures

These explanatory figures describe existing exploratory evidence. They do not activate a research protocol, change a frozen result, or establish a new confirmatory finding.

## Figure 1

**What JCI adds: resolving an internal causal endpoint.** (a) The synthetic `soft_direct` mechanism has directed edges C to X, X to Y, and Z to Y. C and Z are independent Bernoulli variables, and the Bernoulli response logits are −1 + 2C for X and −2 + 2X + 1.2Z for Y. The probabilities of X = 1 are approximately 0.27 and 0.73 in the two contexts. The displayed ground truth is used to evaluate discovery and is not supplied as the answer to the algorithms. (b–c) Both algorithms receive the same observed variables and data. At 1,000 independent synthetic rows per dataset, FCI-JCI0 retains an unresolved circle at X in all 20 repetitions, while FCI-JCI1 and FCI-JCI12 each recover the X-to-Y endpoint pair in all 20 repetitions. JCI1 alone supplies the observed orientation increment in this example. The pairwise diagrams display only the queried edge, not the complete learned PAG. A directed PAG edge provides ancestral information under the assumed model class and discovery assumptions; this figure does not identify an internal language-model mechanism. (d) JCI1 excludes causes of C among the system variables, and JCI2 additionally excludes latent common causes between C and the system. At 200 rows, each JCI setting recovers the correct endpoint pair in 16 of 20 repetitions. These counts describe this synthetic mechanism and do not define a general sample-size threshold.

Evidence: [structural-query-evidence](../../experiments/2026-09-29-structural-query-evidence.md), including the `soft_direct/1000` and `soft_direct/200` table rows. Frozen algorithm outputs: `results/graph-guided-20260929/historical-backend-replay/searches.jsonl`; independent check: the same directory's `independent-verification.json`. The report identifies the generating function `make_rows`, truth function `truth`, scoring function `score`, and frozen implementation identities.

## Figure 2

**Case 74: prompt-policy evidence and the current JCI query.** (a) A simplified, explanatory semantic sketch connects user-provided content, HTML output, and the source's HTML safety requirement. It is not an exact reproduction of the frozen TSG. Its lines express prompt semantics. (b) In the actual Raw-prepared REMOVE policy, the retained-requirement condition P has four requests that pass the finite safety checks, and the removed-requirement condition N has four requests with unsafe DOM-feature witnesses. Ordinary functionality checks pass in both conditions. Representative implementations use `html.escape` and direct insertion, respectively. These observations are limited to the frozen checks and do not establish unrestricted browser-execution safety or a population-level effect. Four generation requests per condition belong to one task, and repeated nominal versions do not establish wording robustness. The panel's arrows connect assigned conditions to observed measurements. (c) The subsequent structural analysis defines X as the preassigned policy-family indicator, not the requirement's state in an individual edited prompt. Therefore X remains one for both conditions of this REMOVE policy. (d) In the ten-task policy-family panel with common temporal background and G-squared tests, JCI12 resolves the C-side endpoint of C–Y in three of 32 request resamples. This orientation uses the known assignment assumptions; all primary-safety searches lack an X–Y adjacency. The 32 resamples reuse the same tasks, and panel (d) is a panel-level result rather than a causal-discovery run on Case 74 alone. The current real-data result has not demonstrated additional identification of a semantic factor's effect.

Evidence: [preparation and generation report](../../experiments/2026-09-29-tsg-preparation-repair.md), the Case74 Raw policy row and request-level observations; [causal comparison report](../../experiments/2026-09-29-causal-comparison-results.md), the variable definitions and common-background endpoint comparison. Representative N requests are `0100/0110/0152/0178`; `0100/code.py` directly inserts input, and `0043/code.py` provides a P example using `html.escape`. Structural outputs are frozen in `results/graph-guided-20260929/targeted-causal-structure/searches.jsonl`; independent verification is `results/graph-guided-20260929/targeted-causal-independent-verification.json`.

## Visual reference and editable sources

The minimalist causal-node layouts, serif typography, and panel lettering are informed by Figures 1 and 2 in Mooij, Magliacane, and Claassen, *Joint Causal Inference from Multiple Contexts*, JMLR 21(99), 2020, pp. 3 and 7: https://www.jmlr.org/papers/v21/17-123.html. The present figures are original explanatory compositions with project-specific evidence. Blue highlights context or newly resolved orientation; green and terracotta distinguish the two measured policy conditions.

The `.mmd` files are editable Mermaid diagram sources. `render.mjs` renders their layouts, adds the standard mixed PAG endpoints using SVG markers, and assembles labels into fully vector SVG and PDF artifacts. The English PNG previews are rendered at twice the SVG dimensions. SVG text remains editable. The renderer uses Mermaid 11.14.0 from the local Slidev installation and a local headless Edge browser; paths to rendering dependencies are explicit in the source. The figures are explanatory artifacts outside the active manuscript.
